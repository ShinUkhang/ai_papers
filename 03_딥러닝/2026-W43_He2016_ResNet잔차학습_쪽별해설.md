# p.1 해설 — 초록과 서론: "깊을수록 학습이 어렵다"

**① 초록** — 더 깊은 신경망은 학습이 어렵다는 문제에서 출발. 층이 입력 $x$를 기준으로 한 **잔차 함수**를 배우도록 바꾸면 최적화가 쉬워지고, 깊이를 늘릴수록 정확도가 오른다. 152층(VGG의 8배)으로 ImageNet 2015 1위, 앙상블 top-5 오류 3.57%.
→ 🔎 *reformulate the layers as learning residual functions* 에 밑줄.

**② 서론 첫 문단** — 깊은 CNN은 저·중·고수준 특징을 층마다 쌓아 올린다. 최근 결과들은 **깊이가 결정적**이라는 것을 보여준다(16~30층).

**③ 오른쪽 단: 두 가지 장애물**
- **기울기 소실/폭발** — 정규화된 초기화와 배치 정규화로 상당 부분 해결됨.
- **성능 저하(degradation)** — 층을 늘리면 정확도가 포화되다가 오히려 떨어짐. 그런데 이것은 **과적합이 아니다**: 훈련 오차 자체가 커지기 때문.

**④ Figure 1** — 20층 vs 56층 "plain" 망. 56층이 **훈련 오차와 테스트 오차 모두** 더 높음.
→ 🔎 그래프에서 *training error* 곡선을 꼭 확인. 이것이 논문 전체의 출발점.

**⑤ 마지막 문단의 사고 실험** — 얕은 망 + 항등 사상 층들을 붙이면 깊은 망을 "구성"할 수 있으므로, 깊은 망은 *적어도* 얕은 망만큼은 좋아야 한다. 그런데 실제 최적화기는 그 해를 찾지 못한다.

| 용어 | 뜻 |
|---|---|
| degradation | 성능 저하 (깊을수록 훈련 오차↑) |
| vanishing gradient | 기울기 소실 |
| constructed solution | 구성적 해 (항등 층 추가) |

# p.2 해설 — 핵심 아이디어: $F(x)+x$

**① Figure 2 (잔차 블록)** — 두 개의 가중치 층 $F(x)$ 옆으로 **지름길**이 $x$를 그대로 전달하고, 둘을 더한 뒤 ReLU.

**② 핵심 문단** — 원하는 함수를 $H(x)$라 할 때, 층들이 $H$를 직접 배우게 하지 않고
$$F(x) := H(x) - x$$
를 배우게 한다. 원래 함수는 $F(x)+x$로 복원된다.
→ 🔎 *if an identity mapping were optimal, it would be easier to push the residual to zero* — 논문에서 가장 중요한 한 문장.

**③ 지름길 연결(shortcut)** — 항등 지름길은 **추가 파라미터도, 계산량도 0**. 기존 SGD·역전파 그대로 학습 가능.

**④ 실험 예고** — (1) 깊은 ResNet은 최적화가 쉽고 plain 망은 깊어질수록 훈련 오차↑, (2) ResNet은 깊이를 늘려 정확도 이득. CIFAR-10에서도 같은 현상 → 특정 데이터셋만의 문제가 아님.

**⑤ 오른쪽 단: 관련 연구 (2절)**
- **잔차 표현**: 영상 검색의 VLAD, Fisher 벡터, 편미분방정식의 **멀티그리드** 방법 — 잔차를 다루면 최적화가 빨라진다는 오랜 지혜.
- **지름길 연결**: 오래된 아이디어. 동시대의 **Highway Network**는 게이트로 지름길을 열고 닫지만, ResNet의 지름길은 **항상 열려 있고** 파라미터가 없음.

# p.3 해설 — 3.1 잔차 학습, 3.2 항등 지름길

**① 3.1 첫 문단** — 비선형 층들이 복잡한 함수 $H(x)$를 근사할 수 있다면, $H(x)-x$도 근사할 수 있다(입출력 차원이 같다는 가정). 표현력은 같지만 **학습의 쉬움**이 다르다.
→ Cybenko 보편 근사 정리와 연결: "표현 가능성"과 "학습 가능성"은 다른 문제!

**② 사전조건화(preconditioning)** — 실제로 항등 사상이 최적일 리는 없지만, 최적 함수가 **0보다 항등에 더 가깝다면** 항등을 기준으로 한 작은 수정(perturbation)을 찾는 편이 쉽다. Fig. 7에서 실제로 잔차 함수의 응답이 작다는 것을 보임.
→ 🔎 *precondition* 에 밑줄 — 수치해석 용어. 문제를 풀기 쉬운 형태로 바꾸는 것.

**③ 3.2 식 (1)**
$$y = F(x, \{W_i\}) + x$$
2층 예시: $F = W_2\,\sigma(W_1 x)$, 덧셈 후 두 번째 비선형성 적용.

**④ 식 (2): 차원이 다를 때**
$$y = F(x,\{W_i\}) + W_s x$$
$W_s$는 차원을 맞추는 선형 사영. 차원이 같을 땐 항등이 충분하고 경제적.

**⑤** $F$가 층 하나뿐이면 $y = W_1x + x$로 사실상 선형층 → 이점이 없음. 그래서 **2~3층**을 한 블록으로.

# p.5 해설 — Table 1과 Figure 4: 결정적 실험

**① Table 1** — 18/34/50/101/152층 구조표. 50층부터는 3층짜리 **병목 블록**(1×1→3×3→1×1). FLOPs: 18층 1.8억 → 152층 113억.

**② Figure 4 ⭐ 가장 중요한 그림**
- **왼쪽(plain)**: 34층(빨강)이 18층보다 훈련 오차가 **높다** → 성능 저하.
- **오른쪽(ResNet)**: 34층이 18층보다 **낮다** → 깊이의 이득 회복.
→ 🔎 가는 선 = 훈련 오차, 굵은 선 = 검증 오차. 두 그래프의 빨강/파랑 순서가 **뒤바뀐 것**에 표시하기.

**③ 4.1 plain 망 분석** — plain-34의 문제는 **기울기 소실 때문이 아니다**: 배치 정규화로 순전파 신호의 분산이 0이 아니고, 역전파 기울기 크기도 정상. 저자 추측: 깊은 plain 망은 **수렴 속도가 지수적으로 느릴** 수 있다.
→ 🔎 *unlikely to be caused by vanishing gradients* — 흔한 오해를 바로잡는 문장.

# p.6 해설 — 표 2~5와 병목 블록

**① Table 2** — top-1 오류: plain-18 27.94 / plain-34 28.54 (더 나쁨!) vs ResNet-18 27.88 / ResNet-34 25.03 (3.5%p 개선).

**② 세 가지 관찰 (본문)**
1. 잔차 학습으로 상황이 **역전**: 34층 ResNet이 18층보다 좋다.
2. 같은 34층끼리 비교하면 ResNet이 훨씬 좋다 → 깊은 망에서 잔차 학습의 효과 입증.
3. 18층에선 정확도가 비슷하지만 ResNet이 **더 빨리 수렴**.

**③ 항등 vs 사영 지름길 (Table 3)** — (A) 0-채움, (B) 차원 늘 때만 사영, (C) 모든 지름길 사영. C > B > A 이지만 차이는 **작다** → 성능 저하 해결의 핵심은 사영이 아니라 **지름길 그 자체**. 메모리·계산 절약을 위해 이후 C는 쓰지 않음.

**④ Figure 5: 병목 설계** — 1×1(차원 축소, 256→64) → 3×3 → 1×1(복원, 64→256). 계산량은 2층 블록과 비슷.
→ 병목 블록에서는 **항등 지름길이 특히 중요**: 사영을 쓰면 고차원 양 끝을 연결하므로 비용이 2배.

**⑤ Table 4, 5** — 단일 모델 top-5 4.49%(152층), 앙상블 3.57% → ILSVRC 2015 1위.

# p.7 해설 — 50/101/152층과 CIFAR-10

**① 더 깊은 ResNet** — 34층의 2층 블록을 3층 병목 블록으로 교체 → 50층(38억 FLOPs). 101층·152층으로 확장해도 152층(113억)이 **VGG-16/19(153/196억)보다 가볍다**.
→ 🔎 "깊이 ≠ 계산량" — 깊지만 좁게 설계한 결과.

**② 결과** — 50/101/152층 모두 34층보다 확연히 좋고 **성능 저하가 관찰되지 않음**.

**③ 4.2 CIFAR-10 실험 설계** — 목적은 최고 성능이 아니라 **극단적으로 깊은 망의 행동** 관찰. 32×32 입력, 특징 맵 크기 {32, 16, 8}, 필터 {16, 32, 64}, 총 $6n+2$ 층. 지름길은 모두 항등(옵션 A) → 잔차망과 plain 망의 **파라미터 수가 완전히 같음**.
→ 공정한 비교를 위한 실험 설계에 주목.

**④ 학습 설정** — 가중치 감쇠 0.0001, 모멘텀 0.9, 학습률 0.1에서 32k·48k 반복에 1/10, 64k에서 종료. $n = 3, 5, 7, 9$ → 20, 32, 44, 56층. 110층은 처음 학습률 0.01로 **워밍업** 후 0.1.

# p.8 해설 — 층 응답 분석과 1000층 실험

**① Figure 6** — 왼쪽: plain은 깊을수록 오류↑ (plain-110은 60% 초과라 표시도 안 됨). 가운데: ResNet은 깊을수록 오류↓. 오른쪽: 110층과 **1202층**.

**② Table 6** — ResNet-110: 6.43% 오류(당시 최고 수준), 파라미터 170만.

**③ Figure 7: 층 응답 분석 ⭐ 이론적으로 중요** — 각 3×3 층 출력(BN 후, 덧셈 전)의 표준편차. ResNet의 응답이 plain보다 **전반적으로 작다** → 3.1절의 가설(잔차 함수는 0에 가깝다) 지지. 더 깊을수록 개별 층의 수정은 더 작아짐.
→ 🔎 *residual functions might be generally closer to zero* 에 밑줄. 이것이 "작은 수정을 쌓는다 = 미분방정식의 오일러 스텝" 관점의 근거.

**④ 1000층 넘기** — 1202층도 최적화 어려움 없이 훈련 오차 0.1% 미만. 그러나 테스트 오차 7.93%로 110층보다 나쁨 → **과적합**(데이터가 작아서). 저자들은 맥스아웃·드롭아웃 같은 강한 정규화를 쓰지 않았음을 밝힘.
→ 성능 저하(최적화 문제)와 과적합(일반화 문제)의 **구분**이 다시 등장 — 이번 주 Zhang·Belkin 논문과 연결!

**⑤ 4.3 PASCAL·COCO 검출** — VGG-16을 ResNet-101로 바꾸기만 해도 COCO mAP 28% 상대 개선 → **좋은 표현은 다른 과제로 일반화**된다.
