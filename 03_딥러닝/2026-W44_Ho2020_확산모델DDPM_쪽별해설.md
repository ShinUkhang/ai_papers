# p.1 해설 — 초록과 서론: 확산 모델로 고품질 이미지를

**① 초록 ⭐** — **확산 확률 모델**로 고품질 이미지 합성. 확산 모델 = **비평형 열역학**에서 영감을 받은 **잠재 변수 모델**. 최고 결과는 확산 모델과 **잡음 제거 점수 매칭 + 랑주뱅 동역학** 사이의 새로운 연결로 설계한 **가중 변분 경계**로 학습해서 얻었다.
→ 🔎 *weighted variational bound* 와 *denoising score matching with Langevin dynamics* 에 밑줄.

**② 덤으로** — 점진적 **손실 압축 해제** 방식을 자연스럽게 허용 = **자기회귀 디코딩의 일반화**.

**③ 성적** — 비조건부 CIFAR-10: **Inception 점수 9.46**, **FID 3.17** (당시 최고). LSUN 256×256: ProgressiveGAN과 비슷한 품질.
→ ✍️ FID는 낮을수록 좋다. 생성 이미지와 실제 이미지의 **특징 분포 사이 거리**라는 뜻을 메모해 두자.

**④ 서론** — GAN, 자기회귀 모델, 흐름(flow), **VAE**(지난주!) 모두 놀라운 이미지·음성 샘플을 만들었다. 에너지 기반 모델과 **점수 매칭**도 GAN급 이미지를 냄.

**⑤ 그림 1** — CelebA-HQ 256×256 얼굴(왼쪽), 비조건부 CIFAR-10(오른쪽) 생성 샘플.

**⑥ 학회** — NeurIPS 2020, 밴쿠버.

→ ✍️ 지금까지 배운 생성 모델(VAE, GAN, 자기회귀=트랜스포머 언어모델)을 표로 정리하고, 확산 모델이 들어갈 칸을 비워 두자. 이 논문을 다 읽으면 채울 수 있다.

# p.2 해설 — 그래프 모형과 배경: 정방향·역방향 과정

**① 그림 2 ⭐** — $\mathbf x_T\to\cdots\to\mathbf x_t\to\mathbf x_{t-1}\to\cdots\to\mathbf x_0$ (역방향 $p_\theta$, 생성) / 반대 방향 $q(\mathbf x_t|\mathbf x_{t-1})$ (정방향, 잡음 추가).
→ ✍️ 이 그림을 노트에 크게 그리고, 왼쪽 끝에 "순수 잡음", 오른쪽 끝에 "사진"이라 적자.

**② 확산 모델이란** — 변분 추론으로 학습된 **매개변수화된 마르코프 사슬**. 사슬의 전이는 **확산 과정**(신호가 사라질 때까지 잡음을 조금씩 더하는 사슬)을 **거꾸로** 되돌리도록 학습. 잡음이 작은 가우시안이면 역방향도 **조건부 가우시안**으로 충분.

**③ 기여** — 확산 모델이 고품질 샘플을 낼 수 있음을 **처음** 보임 + 특정 매개변수화가 **잡음 제거 점수 매칭**(학습) 및 **어닐링된 랑주뱅 동역학**(샘플링)과 동치임을 밝힘. 로그 가능도는 경쟁력이 낮음.

**④ 식 (1) 역방향 과정**
$$p_\theta(\mathbf x_{0:T}):=p(\mathbf x_T)\prod_{t=1}^Tp_\theta(\mathbf x_{t-1}|\mathbf x_t),\quad p_\theta(\mathbf x_{t-1}|\mathbf x_t)=\mathcal N(\boldsymbol\mu_\theta(\mathbf x_t,t),\Sigma_\theta(\mathbf x_t,t))$$

**⑤ 식 (2) 정방향 과정 ⭐**
$$q(\mathbf x_t|\mathbf x_{t-1}):=\mathcal N\big(\mathbf x_t;\sqrt{1-\beta_t}\,\mathbf x_{t-1},\beta_tI\big)$$
VAE와의 차이: 근사 사후분포 $q$가 **고정**되어 있다 (학습하지 않음).

**⑥ 식 (3)** — 음의 로그 가능도의 변분 경계 $L$ (= VAE의 ELBO).

**⑦ 식 (4) 닫힌 형식 ⭐⭐** — $\alpha_t=1-\beta_t$, $\bar\alpha_t=\prod_{s=1}^t\alpha_s$:
$$q(\mathbf x_t|\mathbf x_0)=\mathcal N\big(\mathbf x_t;\sqrt{\bar\alpha_t}\,\mathbf x_0,(1-\bar\alpha_t)I\big)$$
→ 🔎 크게 밑줄. 임의의 $t$로 **한 번에** 점프!
→ ✍️ $t=2$일 때 직접 유도: $\mathbf x_2=\sqrt{\alpha_2}(\sqrt{\alpha_1}\mathbf x_0+\sqrt{1-\alpha_1}\boldsymbol\epsilon_1)+\sqrt{1-\alpha_2}\boldsymbol\epsilon_2$ 의 분산은? ($\alpha_2(1-\alpha_1)+1-\alpha_2=1-\alpha_1\alpha_2$ ✓)

# p.3 해설 — 분산 감소된 경계와 역방향 평균 (식 5–10)

**① 식 (5) ⭐** — $L$을 KL 발산들로 다시 쓰기:
$$L=\mathbb E_q\Big[\underbrace{D_{KL}(q(\mathbf x_T|\mathbf x_0)\|p(\mathbf x_T))}_{L_T}+\sum_{t>1}\underbrace{D_{KL}(q(\mathbf x_{t-1}|\mathbf x_t,\mathbf x_0)\|p_\theta(\mathbf x_{t-1}|\mathbf x_t))}_{L_{t-1}}\underbrace{-\log p_\theta(\mathbf x_0|\mathbf x_1)}_{L_0}\Big]$$

**② 식 (6)–(7) 정방향 사후분포** — $\mathbf x_0$을 알면 계산 가능한 가우시안:
$$\tilde{\boldsymbol\mu}_t=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}\mathbf x_0+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\mathbf x_t,\qquad\tilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t$$
→ 모든 KL이 **가우시안 대 가우시안** → 몬테카를로 대신 **닫힌 식**(라오–블랙웰화).

**③ 3.1 $L_T$** — $\beta_t$를 상수로 고정 → $q$에 학습 매개변수 없음 → $L_T$는 **상수**, 무시.

**④ 3.2 분산** — $\Sigma_\theta=\sigma_t^2I$ 고정. $\sigma_t^2=\beta_t$와 $\sigma_t^2=\tilde\beta_t$ 결과 비슷 (데이터가 $\mathcal N(0,I)$일 때 / 한 점일 때 각각 최적인 두 극단).

**⑤ 식 (8)**
$$L_{t-1}=\mathbb E_q\Big[\frac1{2\sigma_t^2}\|\tilde{\boldsymbol\mu}_t(\mathbf x_t,\mathbf x_0)-\boldsymbol\mu_\theta(\mathbf x_t,t)\|^2\Big]+C$$
→ 가장 단순한 선택: $\boldsymbol\mu_\theta$가 $\tilde{\boldsymbol\mu}_t$를 예측.

**⑥ 식 (9)–(10) 재매개변수화** — $\mathbf x_t(\mathbf x_0,\boldsymbol\epsilon)=\sqrt{\bar\alpha_t}\mathbf x_0+\sqrt{1-\bar\alpha_t}\boldsymbol\epsilon$ 대입:
$$\mathbb E\Big[\frac1{2\sigma_t^2}\Big\|\frac1{\sqrt{\alpha_t}}\Big(\mathbf x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\boldsymbol\epsilon\Big)-\boldsymbol\mu_\theta(\mathbf x_t,t)\Big\|^2\Big]$$
→ 🔎 식 (10)에 밑줄 — 다음 쪽 "ε 예측"의 출발점. VAE의 재매개변수화 트릭과 같은 아이디어!

# p.4 해설 — ε 예측과 두 알고리즘 ⭐⭐

**① 알고리즘 1 (학습)**
1. $\mathbf x_0\sim q(\mathbf x_0)$ 2. $t\sim\mathrm{Uniform}(\{1..T\})$ 3. $\boldsymbol\epsilon\sim\mathcal N(0,I)$
4. $\nabla_\theta\|\boldsymbol\epsilon-\boldsymbol\epsilon_\theta(\sqrt{\bar\alpha_t}\mathbf x_0+\sqrt{1-\bar\alpha_t}\boldsymbol\epsilon,t)\|^2$ 로 경사하강

**② 알고리즘 2 (샘플링)** — $\mathbf x_T\sim\mathcal N(0,I)$; $t=T..1$: $\mathbf z\sim\mathcal N(0,I)$ ($t=1$이면 0),
$$\mathbf x_{t-1}=\frac1{\sqrt{\alpha_t}}\Big(\mathbf x_t-\frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\boldsymbol\epsilon_\theta(\mathbf x_t,t)\Big)+\sigma_t\mathbf z$$
→ 🔎 두 알고리즘 상자 전체에 밑줄. 이 논문의 **전부**.

**③ 식 (11) 매개변수화** — $\boldsymbol\mu_\theta=\frac1{\sqrt{\alpha_t}}(\mathbf x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\boldsymbol\epsilon_\theta(\mathbf x_t,t))$, $\boldsymbol\epsilon_\theta$ = $\mathbf x_t$에서 $\boldsymbol\epsilon$을 예측하는 신경망. 샘플링은 $\boldsymbol\epsilon_\theta$를 데이터 밀도의 **학습된 기울기**로 쓰는 **랑주뱅 동역학**을 닮음.

**④ 식 (12)** — 
$$\mathbb E\Big[\frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}\|\boldsymbol\epsilon-\boldsymbol\epsilon_\theta(\cdot,t)\|^2\Big]$$
= **여러 잡음 수준의 잡음 제거 점수 매칭**. "점수 매칭을 닮은 목표 최적화 = 랑주뱅식 사슬을 변분 추론으로 맞추기".

**⑤ 세 가지 선택지** — $\tilde{\boldsymbol\mu}$ 예측 / **ε 예측** / $\mathbf x_0$ 예측(초기 실험에서 품질 나쁨). 4절에서 비교.

**⑥ 3.3 데이터·디코더** — 픽셀 $\{0..255\}$ → $[-1,1]$. 마지막 단계는 이산 디코더(식 13): 가우시안을 픽셀 칸 $[x-\frac1{255},x+\frac1{255}]$에서 적분 → 변분 경계가 **무손실 부호 길이**가 됨.
→ ✍️ 알고리즘 1을 파이썬 10줄로 써 보자 (신경망은 `eps_model(x_t, t)`로 가정).

# p.5 해설 — 단순화된 목표와 실험 설정

**① 표 1 (CIFAR-10)** — 
| 모델 | IS | FID | NLL |
|---|---|---|---|
| StyleGAN2+ADA (조건부) | 10.06 | 2.67 | – |
| NCSN | 8.87 | 25.32 | – |
| **Ours ($L_{simple}$)** | **9.46** | **3.17** | ≤3.75 |
| Ours ($L$, 고정 Σ) | 7.67 | 13.51 | ≤3.70 |
→ 비조건부 중 최고, 조건부 모델들보다도 좋음.

**② 표 2 (절제 실험)** — $\tilde{\boldsymbol\mu}$ 예측은 진짜 경계 $L$에서만 작동, 단순 MSE로는 불안정. ε 예측 + $L_{simple}$ = **9.46 / 3.17**.

**③ 식 (14) $L_{simple}$ ⭐⭐**
$$L_{\text{simple}}(\theta):=\mathbb E_{t,\mathbf x_0,\boldsymbol\epsilon}\Big[\big\|\boldsymbol\epsilon-\boldsymbol\epsilon_\theta(\sqrt{\bar\alpha_t}\mathbf x_0+\sqrt{1-\bar\alpha_t}\boldsymbol\epsilon,t)\big\|^2\Big]$$
→ 🔎 크게 밑줄. 식 (12)의 **가중치를 버린** 것.

**④ 왜 가중치를 버리면 좋은가** — 작은 $t$(아주 약한 잡음 제거, 쉬운 일)의 가중치를 **낮추고**, 큰 $t$의 **어려운** 잡음 제거에 집중 → 샘플 품질 향상.

**⑤ 4절 설정 ⭐** — $T=1000$, $\beta_t$: $10^{-4}$ → $0.02$ **선형**. $L_T=D_{KL}(q(\mathbf x_T|\mathbf x_0)\|\mathcal N(0,I))\approx10^{-5}$ bits/dim. 역방향 신경망 = **U-Net**(PixelCNN++ 계열) + 그룹 정규화, 시간 $t$는 **트랜스포머 사인파 위치 임베딩**으로 입력, 16×16 해상도에서 **셀프 어텐션**.
→ ai_life **03 CNN**: U-Net은 "줄였다가 다시 키우는" 합성곱망.

**⑥ 4.1** — FID는 관례대로 학습 집합 기준 3.17, 시험 집합 기준 5.24.

→ ✍️ $\beta_t$ 선형 스케줄에서 $\bar\alpha_{1000}$을 대략 계산해 보자: $\log\bar\alpha_T=\sum\log(1-\beta_t)\approx-\sum\beta_t\approx-1000\times0.01=-10$, 즉 $\bar\alpha_T\approx e^{-10}$ — 신호가 사실상 0.

# p.6 해설 — LSUN 샘플, 절제 실험, 점진적 부호화

**① 그림 3·4** — LSUN 교회 (FID 7.89), LSUN 침실 (FID 4.90).

**② 알고리즘 3·4 (전송/수신)** — $\mathbf x_T$부터 $\mathbf x_0$까지 차례로 "보내기". 수신자는 $p_\theta$만 알고 있으면 됨. 총 기대 부호 길이 = 식 (5).

**③ 4.2 절제 ⭐** — (a) $\tilde{\boldsymbol\mu}$ 예측은 진짜 변분 경계에서만 잘 됨. (b) 역방향 **분산을 학습**하면 불안정, 품질 나쁨 → 고정이 낫다. (c) ε 예측은 경계로 학습하면 $\tilde{\boldsymbol\mu}$와 비슷, $L_{simple}$로 학습하면 **훨씬 좋음**.
→ 🔎 *learning reverse process variances … leads to unstable training* 에 밑줄.

**④ 4.3 점진적 부호화** — 학습/시험 부호 길이 차 ≤ 0.03 bits/dim → **과적합 아님**. 하지만 다른 가능도 기반 모델보다 부호 길이는 경쟁력 낮음.

**⑤ 손실 압축기로서 ⭐** — $L_1+\cdots+L_T$ = **전송률(rate)**, $L_0$ = **왜곡(distortion)**. 최고 품질 CIFAR-10 모델: 전송률 **1.78** bits/dim, 왜곡 **1.97** bits/dim (0–255 척도 RMSE **0.95**). 무손실 부호 길이의 **절반 이상**이 **눈에 안 보이는 왜곡**을 기술하는 데 쓰임.
→ 🔎 *More than half of the lossless codelength describes imperceptible distortions* 에 밑줄.

→ ✍️ RMSE 0.95 (0–255 척도)는 픽셀 밝기 1 정도의 차이다. 사람 눈에 보일까? 이 사실이 "가능도는 낮은데 샘플은 예쁜" 이유를 어떻게 설명하나?

# p.7 해설 — 점진적 생성과 자기회귀와의 연결

**① 중간 예측 (식 15) ⭐** — 수신자는 어느 시점 $t$에서든
$$\hat{\mathbf x}_0=\big(\mathbf x_t-\sqrt{1-\bar\alpha_t}\,\boldsymbol\epsilon_\theta(\mathbf x_t)\big)/\sqrt{\bar\alpha_t}$$
로 원본을 추정 (식 4를 $\mathbf x_0$에 대해 푼 것!).
→ ✍️ 식 (4)의 재매개변수화 $\mathbf x_t=\sqrt{\bar\alpha_t}\mathbf x_0+\sqrt{1-\bar\alpha_t}\boldsymbol\epsilon$ 에서 식 (15)를 직접 유도하자.

**② 그림 5** — 전송률–왜곡 곡선: 저전송률 구간에서 왜곡이 **가파르게** 감소 → 대부분의 비트가 눈에 안 보이는 왜곡에 할당됨.

**③ 점진적 생성 ⭐** — 샘플링 도중 $\hat{\mathbf x}_0$를 보면 **큰 구조가 먼저, 세부가 나중**에 나타남 (그림 6). 그림 7: 같은 $\mathbf x_t$에서 여러 번 샘플 — $t$가 작으면 세부만 다르고, 크면 큰 구조만 공유. "개념적 압축"의 힌트.
→ 🔎 *Large scale image features appear first and details appear last* 에 밑줄. ai_life **03 CNN**에서 "얕은 층 = 윤곽, 깊은 층 = 세부"와 비교해 보자.

**④ 자기회귀 디코딩과의 연결 (식 16)**
$$L=D_{KL}(q(\mathbf x_T)\|p(\mathbf x_T))+\mathbb E_q\Big[\sum_{t\ge1}D_{KL}(q(\mathbf x_{t-1}|\mathbf x_t)\|p_\theta(\mathbf x_{t-1}|\mathbf x_t))\Big]+H(\mathbf x_0)$$
사고 실험: $T$ = 데이터 차원, 정방향이 $t$번째 좌표를 **가리는(mask)** 과정이라면…

# p.8 해설 — 확산 = 일반화된 자기회귀, 보간, 관련 연구

**① 자기회귀 결론 ⭐** — 그 설정에서 $p_\theta$ 학습 = 좌표 $t+1..T$는 그대로 복사, $t$번째 좌표를 예측 → **자기회귀 모델 학습**과 같다. 따라서 가우시안 확산 = 데이터 좌표 재배열로는 표현할 수 없는 **일반화된 비트 순서**의 자기회귀 모델. 가우시안 잡음이 가리기(masking)보다 이미지에 더 자연스러울 것. $T$는 데이터 차원과 무관(32×32×3보다 작은 1000).
→ 🔎 *a kind of autoregressive model with a generalized bit ordering* 에 밑줄. 지난주 트랜스포머(자기회귀)와 연결!

**② 그림 8 / 4.4 보간** — 두 이미지 $\mathbf x_0,\mathbf x_0'$를 $q$로 $\mathbf x_t,\mathbf x_t'$로 부호화 → 선형 보간 $\bar{\mathbf x}_t=(1-\lambda)\mathbf x_t+\lambda\mathbf x_t'$ → 역과정으로 복원. 자세·피부톤·머리·표정·배경은 부드럽게 변하지만 **안경은 아님**. $t$가 크면 거칠고 다양한 보간, $t=1000$이면 새 샘플.
→ ✍️ 원문은 $\bar{\mathbf x}_t=(1-\lambda)\mathbf x_0+\lambda\mathbf x_0'$로 인쇄되어 있지만 문맥상 잠재변수 $\mathbf x_t,\mathbf x_t'$의 보간이다 — 그림 8 왼쪽 도식으로 확인해 보자.

**③ 5절 관련 연구** — 흐름·VAE와 비슷해 보이지만, $q$에 매개변수가 없고 최상위 잠재 $\mathbf x_T$가 데이터와 **상호정보량 ≈ 0**. ε 예측 → 점수 매칭 + 어닐링된 랑주뱅(NCSN, Song & Ermon)과 연결. 하지만 확산 모델은 로그 가능도 계산이 쉽고, 샘플러를 **변분 추론으로 직접** 학습. 역방향 함의: 어떤 가중 점수 매칭 = 랑주뱅식 샘플러의 변분 추론.

# p.14 해설 — 부록 A (2)와 부록 B 실험 세부

**① 식 (22)** — (21)을 KL 발산으로 묶으면 식 (5) 완성: $L_T+\sum_{t>1}L_{t-1}+L_0$.

**② 식 (23)–(26) 다른 형태** — 계산은 못 하지만 4.3절 논의용: 베이즈로 $q(\mathbf x_{t-1}|\mathbf x_t)$(**$\mathbf x_0$ 조건 없음**)을 쓰면
$$L=D_{KL}(q(\mathbf x_T)\|p(\mathbf x_T))+\mathbb E_q\Big[\sum_{t\ge1}D_{KL}(q(\mathbf x_{t-1}|\mathbf x_t)\|p_\theta(\mathbf x_{t-1}|\mathbf x_t))\Big]+H(\mathbf x_0)$$
→ ✍️ 식 (5)와 (26)의 차이를 한 줄로: 하나는 $\mathbf x_0$을 아는 사후분포, 하나는 모르는 진짜 역과정과 비교.

**③ 부록 B 구조 ⭐** — PixelCNN++의 **U-Net**(Wide ResNet 기반), 가중치 정규화 → **그룹 정규화**. 32×32 모델은 해상도 4단계(32→4), 256×256은 6단계. 해상도마다 잔차 블록 2개, 16×16에서 **셀프 어텐션**. 시간 $t$는 **사인파 위치 임베딩**을 각 잔차 블록에 더함. 매개변수: CIFAR-10 **3,570만**, LSUN·CelebA-HQ **1억 1,400만**, 대형 침실 약 **2억 5,600만**.

**④ 계산 비용** — TPU v3-8. CIFAR: 배치 128에서 초당 21스텝, **80만 스텝 10.6시간**, 256장 샘플링 17초. 256² 모델: 128장 샘플링 **300초**.
→ 🔎 *300 seconds* 에 밑줄 — 1000단계 샘플링의 느림 (→ DDIM의 동기).

**⑤ 하이퍼파라미터** — $\beta_t$: 상수/선형/2차 중 **선형**($10^{-4}\to0.02$, $T=1000$ 탐색 없이). CIFAR 드롭아웃 0.1 (없으면 PixelCNN++식 과적합 흔적). 좌우 뒤집기. **Adam** 학습률 $2\times10^{-4}$ (256²는 $2\times10^{-5}$).

# p.15 해설 — 부록 B·C·D: 세부, NCSN과의 차이, 잠재 구조

**① 나머지 설정** — 배치 128(CIFAR)/64. 모델 매개변수의 **EMA**(감쇠 0.9999). 한 번 학습, 학습 중 **최소 FID** 시점 보고. 5만 샘플로 IS/FID.
→ ✍️ 매개변수 EMA는 Adam의 $m_t$와 같은 지수이동평균이다 (Reddi 외 해설 참고). 무엇을 평균하는지가 다를 뿐.

**② 부록 C: NCSN과의 차이 ⭐**
1. U-Net + 셀프 어텐션 (NCSN은 RefineNet), 모든 층에 $t$ 입력
2. 정방향마다 $\sqrt{1-\beta_t}$로 **축소** → 분산이 커지지 않음 (NCSN은 생략)
3. 정방향이 신호를 **완전히 파괴**($D_{KL}\approx0$) + $\beta_t$가 매우 작음 → 샘플링 시 **분포 이동 방지**
4. 랑주뱅식 샘플러의 계수(학습률·잡음 크기)가 $\beta_t$에서 **엄밀히 유도** → 샘플러를 변분 추론으로 **직접** 학습 (NCSN은 사후에 손으로 설정)
→ 🔎 4번에 밑줄.

**③ 부록 D: 잠재 구조와 확률성** — 사전분포와 랑주뱅 모두 확률적. 같은 중간 잠재 $\mathbf x_t$($t\in\{1000,750,500,250\}$)에서 사슬을 **분기**: $\mathbf x_{1000}$에서 분기하면 전혀 다른 샘플, 더 진행 후 분기하면 **성별·머리색·안경·채도·자세·표정**을 공유 → $\mathbf x_{750}$ 같은 중간 잠재가 눈에 안 보여도 이 속성들을 **부호화**하고 있음.

**④ 거친→세밀한 보간 (그림 9 설명)** — 보간 전 확산 단계를 늘리면 원본 구조가 더 많이 파괴되고 모델이 역과정에서 채워 넣음.

→ 🔎 *nearest neighbors* 에 밑줄 — 본문 4.3의 "과적합 아님" 주장의 시각적 근거.

**③ 두 거리의 차이** — 픽셀 거리는 밝기·배경색이 비슷한 이미지를, 인셉션 특징 거리는 **의미적으로** 비슷한(표정·자세) 이미지를 찾는다.

→ ✍️ 이번 주 Nakkiran(이중 하강)과 지난주 Zhang(외우기) 관점에서, "모델이 데이터를 외우는가?"를 생성 모델에선 어떻게 판정하는지 비교해 보자.
→ ✍️ 저작권 관점: 학습 데이터와 아주 비슷한 이미지가 생성된다면 어떤 문제가 생길까?

# p.19 해설 — 그림 13: CIFAR-10 생성 샘플

**① 그림 13** — 비조건부 CIFAR-10 생성 샘플 (32×32, 클래스 정보 없이 생성).

**② 관찰 포인트**
- CIFAR-10의 10개 클래스(비행기·자동차·새·고양이·사슴·개·개구리·말·배·트럭)가 고루 나타나는지
- 32×32 저해상도에서도 물체의 **형태와 배경**이 일관됨
- 이 샘플들의 FID가 **3.17**

→ ✍️ 샘플 중 무작위로 20개를 골라 사람이 클래스를 맞혀 보자. 몇 개가 "무엇인지 알 수 없음"인가? 이것이 IS(인셉션 점수)가 재려는 것이다 — 분류기가 **확신 있게**, 그리고 **다양하게** 분류할수록 높다.
→ ai_life **02 물체인식**: 학생들이 직접 만든 분류기로 이 생성 이미지들을 분류해 보는 활동.

**③ IS 정의 메모**
$$\mathrm{IS}=\exp\Big(\mathbb E_{\mathbf x}\big[D_{KL}(p(y|\mathbf x)\,\|\,p(y))\big]\Big)$$
개별 이미지는 확신($p(y|\mathbf x)$ 뾰족), 전체는 다양($p(y)$ 평평)할수록 큼.
