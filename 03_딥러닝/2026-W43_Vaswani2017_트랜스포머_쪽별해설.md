# p.1 해설 — 초록: 어텐션만으로 충분하다

**① 맨 위 안내문** — 구글은 출처를 밝히면 이 논문의 **표와 그림을 언론·학술 목적으로 복제**하는 것을 허락한다고 적혀 있다.

**② 초록** — 기존 시퀀스 변환(번역 등) 모델은 **인코더–디코더** 구조의 복잡한 RNN 또는 CNN이고, 최고 모델들은 둘을 **어텐션**으로 연결한다. 이 논문은 **순환과 합성곱을 완전히 버리고** 어텐션만으로 만든 단순한 구조 **트랜스포머**를 제안.
- 품질은 더 좋고, **병렬화**가 쉬워 학습 시간이 훨씬 짧다
- WMT 2014 영→독: **BLEU 28.4** (앙상블 포함 기존 최고보다 2 이상 향상)
- WMT 2014 영→불: 단일 모델 최고 **BLEU 41.8**, GPU 8개로 3.5일
- 영어 구문 분석에도 잘 일반화
→ 🔎 *dispensing with recurrence and convolutions entirely* 에 밑줄.

**③ 각주: 저자 기여** — 저자 순서는 **무작위**. Jakob: RNN을 셀프 어텐션으로 대체하자는 제안. Ashish·Illia: 첫 트랜스포머 설계·구현. **Noam: 스케일드 닷-프로덕트 어텐션, 멀티-헤드 어텐션, 파라미터 없는 위치 표현** 제안. Niki: 수많은 변형 실험. Llion: 초기 코드와 시각화. Lukasz·Aidan: tensor2tensor 구현.
→ 한 논문의 아이디어가 어떻게 팀으로 나뉘어 만들어지는지 보여주는 드문 각주.

# p.2 해설 — 1절 서론, 2절 배경, 3절 시작

**① RNN의 한계 ⭐** — RNN, LSTM, GRU가 언어 모델링·번역의 표준. RNN은 위치 $t$의 은닉 상태 $h_t$를 $h_{t-1}$과 입력으로 계산 → **본질적으로 순차적** → 한 예제 안에서 병렬화 불가. 문장이 길면 메모리 제약으로 더 문제.
→ 🔎 *This inherently sequential nature precludes parallelization* 에 밑줄.

**② 어텐션** — 입력·출력에서 **거리에 상관없이** 의존성을 모델링. 하지만 대부분 RNN과 함께 쓰임.

**③ 트랜스포머의 제안** — 순환을 버리고 어텐션만으로 입력–출력의 **전역 의존성**을 포착. P100 GPU 8개로 **12시간** 학습만에 번역 최고 성능.

**④ 2절 배경: CNN 기반 시도** — Extended Neural GPU, ByteNet, ConvS2S는 CNN으로 병렬 계산. 하지만 두 위치를 연결하는 연산 수가 거리에 따라 증가 (ConvS2S는 선형, ByteNet은 로그) → 먼 의존성 학습이 어렵다. 트랜스포머는 이를 **상수**로 줄인다 (대신 평균화로 해상도가 떨어지는데, 이를 **멀티-헤드**로 보완).

**⑤ 셀프 어텐션** — **한 시퀀스 안의** 서로 다른 위치를 연결해 그 시퀀스의 표현을 계산. 독해, 요약, 함의 등에서 이미 성공.

**⑥ 3절 모델 구조 시작** — 인코더: 입력 $(x_1,\dots,x_n)$ → 연속 표현 $z = (z_1,\dots,z_n)$. 디코더: $z$로부터 출력 $(y_1,\dots,y_m)$ 을 **한 번에 하나씩** 생성. 매 단계 이전 출력을 입력으로 쓰는 **자기회귀(auto-regressive)**.

# p.3 해설 — Figure 1: 트랜스포머 구조 ⭐

**① Figure 1 ⭐ 이 그림을 손으로 그려 보세요** — 왼쪽 = 인코더, 오른쪽 = 디코더.
- 아래: 입력 임베딩 + **위치 인코딩**
- 인코더 블록 ×N: 멀티-헤드 어텐션 → Add & Norm → 피드포워드 → Add & Norm
- 디코더 블록 ×N: **마스크드** 멀티-헤드 어텐션 → Add & Norm → (인코더 출력과의) 멀티-헤드 어텐션 → Add & Norm → 피드포워드 → Add & Norm
- 위: 선형 → 소프트맥스 → 출력 확률

**② 3.1 인코더** — 동일한 층 $N = 6$개. 각 층에 하위층 2개: (1) 멀티-헤드 셀프 어텐션, (2) 위치별 완전연결 피드포워드. 각 하위층에 **잔차 연결** + **층 정규화**:
$$\mathrm{LayerNorm}\big(x + \mathrm{Sublayer}(x)\big)$$
잔차 연결을 위해 모든 출력 차원은 $d_{\text{model}} = 512$.
→ 🔎 잔차 연결은 이번 주 **ResNet 논문**의 $F(x)+x$ 그대로! 참고문헌 [11]이 바로 He 외.

**③ 디코더** — 역시 $N = 6$. 세 번째 하위층: 인코더 출력에 대한 멀티-헤드 어텐션. 디코더의 셀프 어텐션은 **뒤쪽 위치를 보지 못하도록 마스킹** + 출력 임베딩을 한 칸 밀기 → 위치 $i$의 예측은 $i$ 미만의 출력에만 의존.
→ "미래를 커닝하지 못하게" 하는 장치. GPT 같은 생성 모델의 핵심.

**④ 3.2 어텐션의 정의** — 어텐션 = **질의(query)** 와 **키–값(key–value) 쌍**들을 출력으로 사상하는 함수. 출력 = 값들의 **가중합**, 가중치 = 질의와 각 키의 **호환성 함수**.

# p.4 해설 — 스케일드 닷-프로덕트 어텐션 ⭐ 가장 중요한 쪽

**① Figure 2** — 왼쪽: 스케일드 닷-프로덕트 어텐션 (MatMul → Scale → Mask(선택) → SoftMax → MatMul). 오른쪽: 여러 어텐션을 **병렬**로 돌리는 멀티-헤드.

**② 3.2.1 식 (1) ⭐ 반드시 손으로 계산해 보기**
$$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
질의·키 차원 $d_k$, 값 차원 $d_v$. 질의와 모든 키의 내적 → $\sqrt{d_k}$로 나눔 → 소프트맥스 → 값의 가중치.
→ ✍️ $Q, K, V$ 를 $3\times2$ 행렬로 잡고 직접 계산해 보세요.

**③ 두 종류의 어텐션**
- **덧셈형**: 은닉층 하나짜리 피드포워드로 호환성 계산
- **곱셈형(내적)**: 이 논문 방식에서 스케일만 뺀 것. 고도로 최적화된 **행렬곱**으로 구현 가능 → 훨씬 빠르고 메모리 효율적

**④ 왜 $\sqrt{d_k}$로 나누나? ⭐ 확률 계산** — $d_k$가 크면 스케일 없는 내적은 덧셈형보다 나쁘다. 내적 값이 커져 소프트맥스가 **기울기가 극히 작은 영역**으로 밀려나기 때문.
**각주 4**: $q, k$의 성분이 평균 0, 분산 1인 독립 확률변수이면
$$\mathbb E[q\cdot k] = 0,\qquad \mathrm{Var}(q\cdot k) = \sum_{i=1}^{d_k}\mathrm{Var}(q_ik_i) = d_k$$
→ $\sqrt{d_k}$로 나누면 분산이 1로 맞춰진다.
→ 🔎 각주 4에 크게 표시. 이 논문에서 가장 "수학적인" 한 줄.

**⑤ 3.2.2 멀티-헤드 시작** — $d_{\text{model}}$ 차원 하나로 어텐션 하는 대신, $Q,K,V$를 **$h$번 서로 다른 학습된 선형 사영**으로 $d_k, d_k, d_v$ 차원에 보내 병렬로 어텐션.

# p.5 해설 — 멀티-헤드, 세 가지 어텐션, FFN, 임베딩

**① 멀티-헤드 어텐션**
$$\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^O,\quad \mathrm{head}_i = \mathrm{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$
서로 다른 **표현 부분공간**의 정보를 동시에 볼 수 있음. 헤드가 하나면 평균화가 이를 방해.
설정: $h = 8$, $d_k = d_v = d_{\text{model}}/h = 64$ → 전체 계산량은 단일 헤드와 비슷.

**② 3.2.3 어텐션의 세 가지 쓰임 ⭐**
| 종류 | 질의 출처 | 키·값 출처 |
|---|---|---|
| 인코더–디코더 어텐션 | 이전 디코더 층 | **인코더 출력** |
| 인코더 셀프 어텐션 | 이전 인코더 층 | 이전 인코더 층 |
| 디코더 셀프 어텐션 | 이전 디코더 층 | 이전 디코더 층 (**자기 위치까지만**) |
마스킹 방법: 소프트맥스 입력에서 금지된 연결을 **$-\infty$** 로 설정 → $e^{-\infty} = 0$.

**③ 3.3 위치별 피드포워드**
$$\mathrm{FFN}(x) = \max(0,\ xW_1 + b_1)W_2 + b_2 \tag{2}$$
각 위치에 **따로, 동일하게** 적용. = 커널 크기 1인 합성곱 두 개. $d_{\text{model}} = 512$, 내부 차원 $d_{ff} = 2048$.

**④ 3.4 임베딩과 소프트맥스** — 학습된 임베딩으로 토큰 → $d_{\text{model}}$ 차원 벡터. 두 임베딩 층과 소프트맥스 직전 선형층이 **같은 가중치 행렬을 공유**. 임베딩에는 $\sqrt{d_{\text{model}}}$을 곱함.

# p.6 해설 — Table 1, 위치 인코딩, 4절 왜 셀프 어텐션인가

**① Table 1 ⭐** — $n$ = 시퀀스 길이, $d$ = 표현 차원, $k$ = 합성곱 커널, $r$ = 제한된 이웃 크기.
| 층 | 층당 복잡도 | 순차 연산 | 최대 경로 길이 |
|---|---|---|---|
| 셀프 어텐션 | $O(n^2 d)$ | $O(1)$ | $O(1)$ |
| 순환(RNN) | $O(n d^2)$ | $O(n)$ | $O(n)$ |
| 합성곱 | $O(k n d^2)$ | $O(1)$ | $O(\log_k n)$ |
| 제한된 셀프 어텐션 | $O(r n d)$ | $O(1)$ | $O(n/r)$ |

**② 3.5 위치 인코딩 ⭐** — 순환도 합성곱도 없으므로 **순서 정보를 주입**해야 한다. 임베딩에 같은 차원의 위치 인코딩을 **더한다**:
$$PE_{(pos,2i)} = \sin\!\big(pos/10000^{2i/d_{\text{model}}}\big),\qquad PE_{(pos,2i+1)} = \cos\!\big(pos/10000^{2i/d_{\text{model}}}\big)$$
파장은 $2\pi$부터 $10000\cdot2\pi$까지 **등비수열**.
→ 🔎 *for any fixed offset k, PE_{pos+k} can be represented as a linear function of PE_pos* 에 밑줄.
→ ✍️ 덧셈정리로 증명해 보세요: $\sin(a+b) = \sin a\cos b + \cos a\sin b$ → $(\sin, \cos)$ 쌍에 **회전 행렬**을 곱한 것.

**③ 학습된 위치 임베딩과 비교** — 거의 같은 결과 (Table 3 (E)). 사인 버전을 고른 이유: 학습 때보다 **긴 시퀀스로 외삽**할 수 있을지도 몰라서.

**④ 4절: 세 가지 기준** — (1) 층당 총 계산 복잡도, (2) 병렬화 가능한 양 (최소 순차 연산 수), (3) 장거리 의존성 사이의 **경로 길이** — 짧을수록 학습이 쉽다.

# p.7 해설 — 셀프 어텐션의 장점, 5절 학습

**① 복잡도 비교** — 셀프 어텐션은 $n < d$ 일 때 RNN보다 빠르다. 번역 모델의 문장 표현(단어 조각, BPE)은 대부분 이 경우. 아주 긴 시퀀스는 이웃 $r$로 **제한**하면 되지만 경로 길이가 $O(n/r)$로 늘어남.
→ 오늘날 거대 언어모델의 "긴 문맥" 문제가 바로 이 $O(n^2)$ 에서 나온다.

**② 합성곱과 비교** — 커널 폭 $k<n$ 인 합성곱 층 하나로는 모든 위치 쌍이 연결되지 않음 → $O(n/k)$ 층(연속 커널) 또는 $O(\log_k n)$ 층(팽창 합성곱) 필요. 분리 가능 합성곱도 $k=n$ 이면 셀프 어텐션 + 피드포워드와 같은 복잡도.

**③ 해석 가능성** — 어텐션 분포를 들여다보면 헤드마다 **다른 일**을 하고, 많은 헤드가 문장의 **문법·의미 구조**와 관련된 행동을 보인다 (부록 그림).

**④ 5절 학습 데이터** — WMT 2014 영–독 약 **450만** 문장 쌍, 바이트 쌍 인코딩(BPE) 공유 어휘 약 37,000 토큰. 영–불 **3,600만** 문장, 단어 조각 32,000. 배치당 원문·번역문 각 약 25,000 토큰.

**⑤ 하드웨어** — NVIDIA P100 GPU 8개. 기본 모델: 스텝당 0.4초, 10만 스텝 = **12시간**. 큰 모델: 스텝당 1.0초, 30만 스텝 = **3.5일**.

**⑥ 최적화기 ⭐** — **Adam** ($\beta_1 = 0.9$, $\beta_2 = 0.98$, $\epsilon = 10^{-9}$) — 이번 주 Adam 논문! 학습률 스케줄 (식 3):
$$lrate = d_{\text{model}}^{-0.5}\cdot\min\big(step^{-0.5},\ step\cdot warmup^{-1.5}\big),\quad warmup = 4000$$
처음 4000 스텝은 **선형 증가(워밍업)**, 이후 스텝의 **역제곱근**으로 감소.
→ ✍️ 두 항이 같아지는 지점이 $step = warmup$ 임을 확인해 보세요.

# p.14 해설 — 부록 Figure 4: 대용어 해소

**① Figure 4** — 역시 5번째 층의 두 헤드(5번, 6번). **대용어 해소(anaphora resolution)** — 대명사가 무엇을 가리키는지 찾는 일 — 에 관여하는 것으로 보인다.
- **위**: 헤드 5의 전체 어텐션
- **아래**: 단어 **'its'** 에서 나가는 어텐션만 따로 (헤드 5, 6)

**② 관찰** — 'its'의 어텐션이 **매우 날카롭다**(한두 단어에 집중). 'its'가 가리키는 명사(문장에서는 법/Law)에 집중.

**③ 의미** — 아무도 "대명사를 해소하라"고 가르치지 않았는데, 번역을 잘하기 위해 모델이 스스로 이런 기능을 **학습**했다.
→ 🔎 이것이 "표현 학습(representation learning)"의 힘.

**✍️ ai_life 연결** — **04 자연어처리·AI 에이전트** 단원에서 학생들에게 "it/its가 무엇을 가리킬까?" 퀴즈를 내고, 이 그림과 비교해 보면 좋은 활동이 됩니다.
