## 한 줄 요약
**MLP는 '노드'에 고정된 활성화 함수를 두고 '엣지'의 선형 가중치를 학습하지만, KAN은 거꾸로 '엣지'마다 학습 가능한 1변수 함수(B-스플라인)를 두고 노드는 더하기만 한다 — 콜모고로프–아놀드 표현 정리에서 영감을 받은 이 구조는 작은 과학 문제에서 더 정확하고, 무엇보다 학습된 함수를 '눈으로 읽어' 수식을 찾을 수 있다.**

## 왜 중요한가
지난주 Cybenko(1989), 이번 주 Hornik(1989)은 **보편 근사 정리(UAT)** 로 MLP를 정당화했습니다. Hornik 논문 서론이 "함수마다 다른 미지의 변환이 필요해 실용성이 없다"고 밀어냈던 **콜모고로프(1957) 중첩 정리**를, 35년 뒤 이 논문이 **깊이와 폭을 일반화**하고 **역전파로 학습**하여 되살렸습니다. 공개 직후 수백 편의 후속 연구를 낳은 최근 논문으로, (1) 근사 이론(차원의 저주를 피하는 스케일링 $\ell\propto N^{-4}$), (2) 해석 가능성(학습된 활성화 함수 → 기호 수식), (3) AI-과학자 협업(매듭 이론·앤더슨 국소화 재발견)을 한 번에 보여 줍니다. 수학을 좋아하는 학생에게 "AI가 공식을 찾아 준다"는 체험을 줄 수 있는 좋은 소재입니다.

## 핵심 내용

### 1. 두 정리의 대비 (그림 0.1)
| | MLP | KAN |
|---|---|---|
| 정리 | 보편 근사 정리 | 콜모고로프–아놀드 표현 정리 |
| 얕은 식 | $f(\mathbf x)\approx\sum_{i=1}^{N(\epsilon)}a_i\sigma(\mathbf w_i\cdot\mathbf x+b_i)$ | $f(\mathbf x)=\sum_{q=1}^{2n+1}\Phi_q\big(\sum_{p=1}^n\phi_{q,p}(x_p)\big)$ |
| 노드 | 고정 활성화 $\sigma$ | 더하기만 |
| 엣지 | 학습 가능한 **수(가중치)** | 학습 가능한 **함수** |
| 깊은 식 | $W_3\circ\sigma\circ W_2\circ\sigma\circ W_1$ | $\Phi_3\circ\Phi_2\circ\Phi_1$ |

### 2. 콜모고로프–아놀드 정리 (식 2.1)
$[0,1]^n$ 위의 연속함수는 **1변수 연속함수들과 덧셈**만으로 정확히 표현된다 — "진짜 다변수 함수는 덧셈뿐". 하지만 내부 함수가 **매끄럽지 않거나 프랙털**일 수 있어 기계학습에선 "이론적으로만 옳고 실용성 없다"고 여겨졌다.

### 3. KAN 층과 깊은 KAN (식 2.2–2.7)
KAN 층 = **1변수 함수의 행렬** $\Phi=\{\phi_{q,p}\}$. 원래 정리는 $[n,2n+1,1]$ 모양의 2층 KAN. 층을 쌓으면 깊은 KAN:
$$x_{l+1,j}=\sum_{i=1}^{n_l}\phi_{l,j,i}(x_{l,i}),\qquad \mathrm{KAN}(\mathbf x)=(\Phi_{L-1}\circ\cdots\circ\Phi_0)\mathbf x$$
각 활성화: $\phi(x)=w_b\,\mathrm{silu}(x)+w_s\sum_ic_iB_i(x)$ (잔차 기저 + B-스플라인).

### 4. 근사 이론 (정리 2.1, KAT) ⭐
$f$가 매끄러운 KA 표현을 가지면, 격자 크기 $G$의 $k$차 B-스플라인으로
$$\|f-(\Phi^G_{L-1}\circ\cdots\circ\Phi^G_0)\mathbf x\|_{C^m}\le C\,G^{-k-1+m}$$
→ 오차율이 **입력 차원과 무관** = 차원의 저주를 피함. 스케일링 지수 $\alpha=k+1=4$ (3차 스플라인) — 기존 이론($\alpha=(k+1)/d$ 등)보다 크다.

### 5. 정확도와 해석 가능성의 도구
- **격자 확장**: 작은 KAN을 학습한 뒤 스플라인 격자만 촘촘히 → 처음부터 재학습 없이 키우기 (계단식 손실 곡선)
- **희소화**(L1 + 엔트로피) → **가지치기** → **기호화**(`fix_symbolic`) → 수식 출력. 예: $\exp(\sin(\pi x)+y^2)$ 를 데이터만으로 복원
- 외부 자유도(연결 구조, MLP처럼) + 내부 자유도(1변수 함수, 스플라인처럼)

### 6. 결과
- 장난감·특수함수·파인만 방정식·편미분방정식에서 같은 매개변수 수 대비 더 낮은 오차 (파레토 프런티어)
- 포아송 방정식: 2층 폭 10 KAN이 4층 폭 100 MLP보다 **100배 정확**, **100배 적은 매개변수**
- 스플라인의 **국소성** → 연속 학습에서 파국적 망각 회피 (장난감 예)
- 매듭 이론: DeepMind의 $[3\times10^5]$ 매개변수 MLP(78%) 대신 $\approx200$개 매개변수 KAN(81.6%)
- 앤더슨 국소화의 이동도 경계(mobility edge) 공식 재발견

### 7. 한계 (저자 스스로)
같은 매개변수 수에서 **학습이 약 10배 느림**, 대규모(언어 모델 등)에서의 효과는 미검증, 깊은 KA 표현의 수학적 이론은 미완. "빨리 학습해야 하면 MLP, 해석 가능성·정확도가 중요하고 작은 과학 문제면 KAN" (그림 6.1).

## 생각해볼 질문
1. Hornik 논문은 콜모고로프 정리를 "함수마다 다른 미지의 변환이 필요하다"는 이유로 실용적이지 않다고 했다. KAN은 이 비판에 어떻게 답하는가?
2. $xy=\frac{(x+y)^2-(x-y)^2}{4}$ 를 이용해 곱셈을 $[2,2,1]$ KAN으로 손으로 그려 보자. 각 엣지에는 어떤 1변수 함수가 놓이나?
3. 상대론적 속도 합성 $\frac{u+v}{1+uv}=\tanh(\operatorname{arctanh}u+\operatorname{arctanh}v)$ 가 왜 **2층** KAN으로 충분한가? KAN이 "rapidity" 개념을 스스로 발견할 수 있다는 것은 과학 교육에 어떤 의미가 있을까?
4. 학습이 10배 느린데도 쓸 가치가 있는 상황은? ai_life 수업에서는?
