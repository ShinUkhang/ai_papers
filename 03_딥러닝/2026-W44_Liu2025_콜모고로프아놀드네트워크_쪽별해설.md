# p.1 해설 — 초록과 그림 0.1: MLP를 뒤집다

**① 초록 ⭐** — **콜모고로프–아놀드 표현 정리**에서 영감을 받은 **KAN**을 MLP의 대안으로 제안. MLP는 **노드**("뉴런")에 **고정** 활성화, KAN은 **엣지**("가중치")에 **학습 가능한** 활성화. KAN엔 **선형 가중치가 전혀 없다** — 모든 가중치가 **스플라인**으로 매개변수화된 1변수 함수로 대체.
→ 🔎 *learnable activation functions on edges* 와 *no linear weights at all* 에 밑줄.

**② 주장** — 작은 규모 AI+과학 과제에서 **정확도**와 **해석 가능성** 모두 MLP보다 우수. 작은 KAN이 큰 MLP와 비슷하거나 더 정확, 더 빠른 **신경 스케일링 법칙**. 수학·물리의 두 예에서 과학자의 "협력자"로 법칙을 (재)발견.

**③ 그림 0.1 ⭐⭐**
| | MLP | KAN |
|---|---|---|
| 정리 | 보편 근사 정리 | 콜모고로프–아놀드 정리 |
| 얕은 식 | $\sum_{i=1}^{N(\epsilon)}a_i\sigma(\mathbf w_i\cdot\mathbf x+b_i)$ | $\sum_{q=1}^{2n+1}\Phi_q\big(\sum_{p=1}^n\phi_{q,p}(x_p)\big)$ |
| 깊은 식 | $(W_3\circ\sigma_2\circ W_2\circ\sigma_1\circ W_1)(\mathbf x)$ | $(\Phi_3\circ\Phi_2\circ\Phi_1)(\mathbf x)$ |
→ ✍️ 왼쪽 식은 지난주 Cybenko 식 (1)과 같다! 오른쪽과 나란히 노트에 옮겨 적자.

**④ 소속·학회** — MIT, 칼텍, 노스이스턴대, NSF IAIFI. **ICLR 2025** 채택.

# p.2 해설 — 서론: MLP는 최선인가?

**① MLP의 지위** — 보편 근사 정리 덕분에 비선형 함수 근사의 기본 모델. 하지만 **트랜스포머**에서 MLP가 임베딩 외 매개변수의 거의 전부를 차지하면서 (어텐션보다) **해석하기 어렵다**.

**② KAN의 아이디어** — MLP처럼 완전연결 구조. 차이: 활성화가 **엣지**에, 학습 가능, 스플라인. 노드는 들어온 신호를 **더하기만**. "비싸지 않을까?" → 보통 KAN은 **훨씬 작은** 계산 그래프로 충분.

**③ 선행 연구** — 콜모고로프 정리로 신경망을 만드는 연구는 있었지만 대부분 **깊이 2, 폭 $2n+1$** 에 머물렀고 역전파 같은 현대 기법을 못 썼다. 이 논문의 기여: **임의의 폭과 깊이**로 일반화 + 현대 딥러닝 맥락에서 부활 + AI+과학 실험.

**④ 핵심 직관 ⭐** — KAN = **스플라인과 MLP의 결합**.
| | 장점 | 약점 |
|---|---|---|
| 스플라인 | 저차원에서 정확, 국소 조정, 해상도 전환 | **차원의 저주** (합성 구조 활용 불가) |
| MLP | 특징 학습으로 차원의 저주 완화 | 1변수 함수 최적화가 부정확 |
KAN은 "**바깥은 MLP, 안은 스플라인**" → 합성 구조(외부 자유도)와 1변수 함수(내부 자유도)를 모두 학습.
→ 🔎 *MLPs on the outside and splines on the inside* 에 밑줄.

**⑤ 예 (식 1.1)** — $f=\exp\big(\frac1N\sum_{i=1}^N\sin^2(x_i)\big)$.
→ ✍️ 이 함수를 "1변수 함수 + 덧셈 + 1변수 함수"로 분해해 보자: 안쪽 $\sin^2(x_i)$, 덧셈, 바깥 $\exp(\cdot/N)$.

# p.3 해설 — 논문 구성과 콜모고로프–아놀드 정리

**① 그림 2.1** — 두 위대한 수학자 **안드레이 콜모고로프**와 **블라디미르 아놀드**에게 헌정. "수학적으로 탄탄, 정확, 해석 가능".

**② 식 1.1의 교훈** — 스플라인은 $N$이 크면 차원의 저주로 실패, ReLU MLP는 지수·사인 근사가 비효율적, KAN은 둘 다 잘 함 (그림 3.1).

**③ 구성** — 2절: 구조·수학적 기초·단순화·격자 확장 / 3절: 정확도(데이터 적합, 스케일링, 편미분방정식) / 4절: 해석 가능성과 과학적 발견(매듭 이론, 앤더슨 국소화) / 5절: 관련 연구 / 6절: 토론. 코드: `pip install pykan`.
→ ✍️ 집에서 pykan을 설치하고 README의 첫 예제를 돌려 보자.

**⑤ 2.1 정리 시작 ⭐** — 아놀드와 콜모고로프: 유계 영역 위의 다변수 연속함수 $f$는 **1변수 연속함수들의 유한 합성**과 **덧셈**이라는 이항 연산으로 쓸 수 있다.
→ 🔎 이 문장에 밑줄 — 힐베르트 13번째 문제의 해결 (지난주 Cybenko 해설 p.304 참고).

# p.4 해설 — 정리의 내용과 "사형 선고", 그리고 낙관

**① 그림 2.2** — 왼쪽: 신경망을 흐르는 활성화의 기호. 오른쪽: 활성화 함수를 **B-스플라인**으로 매개변수화 → 거친 격자 ↔ 촘촘한 격자 전환.

**② 식 (2.1) ⭐⭐** — 매끄러운 $f:[0,1]^n\to\mathbb R$에 대해
$$f(\mathbf x)=f(x_1,\dots,x_n)=\sum_{q=1}^{2n+1}\Phi_q\Big(\sum_{p=1}^n\phi_{q,p}(x_p)\Big)$$
$\phi_{q,p}:[0,1]\to\mathbb R$, $\Phi_q:\mathbb R\to\mathbb R$. "**진짜 다변수 함수는 덧셈뿐**".
→ 🔎 크게 밑줄. $n=2$이면 안쪽 함수 $2\times5=10$개, 바깥 함수 5개.

**③ 사형 선고** — 고차원 함수 학습 = 다항식 개수의 1D 함수 학습? 하지만 이 1D 함수들이 **매끄럽지 않거나 프랙털**일 수 있어 실제로 학습 불가 → "이론적으로 옳지만 실용적으로 쓸모없다"(Poggio, Girosi).

**④ 저자들의 낙관 ⭐** — (1) 원래 식의 2층·$2n+1$에 얽매일 필요 없음 → **임의 폭·깊이**로 일반화. (2) 과학과 일상의 함수는 대개 **매끄럽고 희소한 합성 구조**를 가진다. 최악보다 **전형적** 경우를 보는 물리학자의 사고방식.

**⑤ 2.2 KAN 구조** — 식 (2.1)을 명시적으로 매개변수화한 신경망. 각 1D 함수를 **B-스플라인 곡선**(국소 기저함수의 학습 가능한 계수)으로 → 2층, 중간 폭 $2n+1$, 활성화가 엣지에, 노드는 덧셈.

# p.5 해설 — KAN 층의 정의와 깊은 KAN

**① 원형의 한계** — 2층 KAN은 매끄러운 스플라인으로 임의 함수를 근사하기엔 **너무 단순**. 더 넓고 깊게! 그런데 깊은 KA 정리의 "일반화판"은 (저자들이 아는 한) 아직 없다.

**② 돌파구: MLP와의 유비 ⭐** — MLP는 층(선형 변환 + 비선형)을 정의하면 쌓을 수 있다. 그렇다면 "**KAN 층이란 무엇인가?**" → 1D 함수의 행렬:
$$\Phi=\{\phi_{q,p}\},\quad p=1..n_{in},\ q=1..n_{out}\quad(2.2)$$
원래 정리 = 안쪽 층($n\to2n+1$) + 바깥 층($2n+1\to1$)의 **합성**. 더 깊게 = 그냥 **KAN 층을 더 쌓기**!
→ 🔎 *simply stack more KAN layers!* 에 밑줄.

**③ 기호** — 모양 $[n_0,n_1,\dots,n_L]$ (2.3). 층 $l$과 $l+1$ 사이에 $n_ln_{l+1}$개의 활성화 $\phi_{l,j,i}$ (2.4).

**④ 순전파 (2.5) ⭐**
$$x_{l+1,j}=\sum_{i=1}^{n_l}\tilde x_{l,j,i}=\sum_{i=1}^{n_l}\phi_{l,j,i}(x_{l,i})$$

**⑤ 행렬 형태 (2.6)–(2.7)** — $\mathbf x_{l+1}=\Phi_l\mathbf x_l$ (함수 행렬을 "곱한다"는 것은 각 성분에 함수를 적용 후 행별로 더하기). $\mathrm{KAN}(\mathbf x)=(\Phi_{L-1}\circ\cdots\circ\Phi_0)\mathbf x$.
→ ✍️ $[2,3,1]$ KAN을 그리고 엣지 6+3=9개에 $\phi$ 이름을 붙여 보자. MLP $[2,3,1]$의 가중치 9개와 같은 자리!

# p.6 해설 — 구현 요령: 잔차 활성화, 초기화, 격자 갱신

**① 식 (2.8)** — 출력이 1차원일 때 펼쳐 쓴 식 (중첩 합 $L$겹) — 번거로우므로 층 추상화가 더 깔끔. 원래 정리 = $[n,2n+1,1]$ 모양의 2층 KAN. 모든 연산이 **미분 가능** → 역전파로 학습.

**② MLP 비교 (2.9)** — $\mathrm{MLP}(\mathbf x)=(W_{L-1}\circ\sigma\circ\cdots\circ\sigma\circ W_0)\mathbf x$. MLP는 선형 $W$와 비선형 $\sigma$를 **분리**, KAN은 $\Phi$ 하나로 **합침**.
→ 🔎 이 대비 문장에 밑줄.

**③ 요령 1: 잔차 활성화 ⭐**
$$\phi(x)=w_b\,b(x)+w_s\,\mathrm{spline}(x),\quad b(x)=\mathrm{silu}(x)=\frac{x}{1+e^{-x}},\quad\mathrm{spline}(x)=\sum_ic_iB_i(x)$$
$b(x)$는 ResNet의 **잔차 연결**과 비슷한 역할. $w_b,w_s$는 중복이지만 크기 조절용.

**④ 요령 2: 초기화** — $w_s=1$, $\mathrm{spline}\approx0$ ($c_i\sim\mathcal N(0,0.1^2)$), $w_b$는 **자비에 초기화**.

**⑤ 요령 3: 격자 갱신** — 스플라인은 유계 구간에서만 정의되는데 학습 중 활성화 값이 밖으로 나갈 수 있음 → 입력 활성화에 맞춰 격자를 **즉석 갱신**.

→ ✍️ silu를 그려 보자. ReLU와 무엇이 다른가? (매끄럽고, 음수에서 살짝 내려갔다 0으로)
→ ai_life **01 선형회귀**: $\sum c_iB_i(x)$ 는 "기저함수들의 선형결합" — 다항식 회귀 $\sum a_ix^i$ 와 같은 구조!

# p.7 해설 — 매개변수 수와 근사 이론 (정리 2.1)

**① 매개변수 수 ⭐** — 깊이 $L$, 폭 $N$, $k$차 스플라인($k=3$), 격자 $G$구간:
$$\text{KAN: }O(N^2L(G+k))\sim O(N^2LG),\qquad\text{MLP: }O(N^2L)$$
KAN이 더 비싸 보이지만 보통 **훨씬 작은 $N$** 으로 충분 → 매개변수 절약 + 일반화 + 해석. 1D 문제에서 $N=L=1$ KAN = 그냥 스플라인 근사.

**② 2.3 매끄러움과 깊이** — 2층 $2n+1$ 표현은 매끄럽지 않을 수 있지만 **깊은** 표현은 매끄러울 수 있다. 예:
$$f(x_1,x_2,x_3,x_4)=\exp\big(\sin(x_1^2+x_2^2)+\sin(x_3^2+x_4^2)\big)\quad(2.13)$$
→ $[4,2,1,1]$ (3층) KAN으로 매끄럽게 표현, 2층으로는 아닐 수도.
→ ✍️ 각 층에 어떤 1D 함수가 놓이는지 적어 보자: 1층 $x_i^2$, 2층 $\sin$, 3층 $\exp$.

**③ 정리 2.1 (KAT) ⭐⭐** — $f=(\Phi_{L-1}\circ\cdots\circ\Phi_0)\mathbf x$ 이고 각 $\Phi_{l,i,j}$가 $(k+1)$번 연속 미분 가능하면, $k$차 B-스플라인 $\Phi^G_{l,i,j}$가 존재하여 $0\le m\le k$에 대해
$$\|f-(\Phi^G_{L-1}\circ\cdots\circ\Phi^G_0)\mathbf x\|_{C^m}\le C\,G^{-k-1+m}\quad(2.15)$$
$\|g\|_{C^m}$ = $m$계까지 도함수 크기의 최댓값.
→ 🔎 (2.15)에 크게 밑줄.

**④ 증명 시작** — 고전 1D B-스플라인 이론(de Boor) + 유계 영역에서 연속함수의 균등 유계성 → 각 층을 하나씩 스플라인으로 바꿀 때 오차 $\le CG^{-k-1+m}$. 잔차 $R_l$ 정의.

# p.8 해설 — 차원의 저주를 피하다, 스케일링 법칙 비교

**① 증명 완성** — $f-(\Phi^G\text{들의 합성})=R_{L-1}+\cdots+R_0$ (**망원 합**), 각 $\|R_l\|\le CG^{-k-1+m}$ → (2.15).

**② 의미 ⭐** — 오차율이 **입력 차원과 무관** → **차원의 저주를 이긴다**! 1D 함수만 스플라인으로 근사하므로 당연. $m=0$이면 $L^\infty$ 정확도 → RMSE 스케일링 지수 $k+1$. 단 상수 $C$는 표현(따라서 차원)에 의존 — 미래 과제.

**③ 신경 스케일링 법칙** — $\ell\propto N^{-\alpha}$ ($\ell$: 테스트 RMSE, $N$: 매개변수 수).
| 이론 | $\alpha$ |
|---|---|
| Sharma & Kaplan (고유 차원 $d$) | $(k+1)/d$ — 차원의 저주 |
| Michaud 외 (최대 인자 수 2) | $(k+1)/2$ |
| Poggio 외 (합성 희소성) | $m/2$ |
| **KAN** (매끄러운 KA 표현) | $k+1=$ **4** (3차 스플라인) |
→ 🔎 *α = 4 which is the largest and best scaling exponent* 에 밑줄.

**④ KAT vs UAT ⭐** — UAT: 오차 $\epsilon$을 위해 뉴런 $N(\epsilon)$개면 된다지만 $N(\epsilon)$이 어떻게 커지는지 **보장 없음**, 경우에 따라 $d$에 대해 **지수적**. (지난주 Cybenko 마지막 쪽 "천문학적인 수의 항", Hornik p.364 "남은 과제"와 연결!)
→ ✍️ $\alpha=4$이면 매개변수를 2배로 할 때 오차는 몇 분의 1? ($2^{-4}=1/16$) MLP의 $\alpha=1$이면? ($1/2$)

# p.9 해설 — 격자 확장 (그림 2.3)

**① 그림 2.3 ⭐** — $f(x,y)=\exp(\sin(\pi x)+y^2)$ 적합.
- 위 왼쪽 $[2,5,1]$ / 위 오른쪽 $[2,1,1]$ KAN의 학습 동역학: 격자를 늘릴 때마다 손실이 **뚝 떨어졌다가 정체** → **계단** 모양
- 아래 왼쪽: 테스트 RMSE가 격자 크기 $G$에 대해 **스케일링 법칙**
- 아래 오른쪽: 학습 시간이 $G$에 대해 완만히 증가
→ 🔎 "interpolation threshold" 표시선에 주목 — 이번 주 Nakkiran의 **보간 임계점**과 같은 개념!

**② KAT와 UAT의 차이의 원인** — KAN은 함수의 **본질적으로 저차원인 표현**을 활용, MLP는 아님. 소볼레프·베소프 같은 일반 함수공간에선 비선형 $n$-폭 이론상 차원의 저주를 **절대** 못 이김 → 그래서 **합성 구조**를 가진 "착한" 함수에 집중.

**③ 2.4 격자 확장 (정확도를 위해)** — 스플라인은 격자를 촘촘히 할수록 임의로 정확. MLP엔 "세밀화" 개념이 없다 — 폭·깊이를 키우면 좋아지지만 스케일링이 **느리고**, 크기마다 **따로 학습**해야 해서 비쌈. KAN은 작은 것을 학습한 뒤 **격자만 촘촘히** → 처음부터 재학습 불필요.

# p.10 해설 — 격자 확장의 방법과 장난감 예

**① 방법 ⭐** — 구간 $[a,b]$, $k$차 B-스플라인. 거친 격자 $G_1$구간: 격자점 $\{t_0=a,\dots,t_{G_1}=b\}$ + 양쪽으로 $k$개씩 확장. 기저 $G_1+k$개, $i$번째 $B_i$는 $[t_{-k+i},t_{i+1}]$에서만 0이 아님 (**국소성**).
$$f_{coarse}=\sum_{i=0}^{G_1+k-1}c_iB_i(x),\qquad f_{fine}=\sum_{j=0}^{G_2+k-1}c'_jB'_j(x)$$
$c'_j$는 $f_{fine}$과 $f_{coarse}$의 거리를 최소화 → **최소제곱**으로.
→ ai_life **01 선형회귀**의 최소제곱이 여기서도!

**② 계단 손실** — $[2,5,1]$, 격자 3에서 시작해 LBFGS 200스텝마다 늘려 1000까지. 세밀화 때마다 학습 손실이 더 빨리 감소 (1000에선 최적화 실패). 테스트 손실은 **U자** — 편향–분산 절충.

**③ 보간 임계점 예측 ⭐** — 학습 표본 1000개, $[2,5,1]$의 매개변수 $15G$ → 임계점 $G=1000/15\approx67$, 실험값 $G\sim50$과 대략 일치.
→ ✍️ $15G$는 어디서? 엣지 $2\times5+5\times1=15$개 × 격자당 계수 약 $G$개.

**④ 작은 KAN이 더 잘 일반화** — 과제가 $[2,1,1]$로 정확히 표현되므로 $[2,1,1]$을 학습 → 더 낮은 테스트 손실, 더 뚜렷한 계단, 임계점이 더 큰 $G$로 이동. "구조를 모르면 최소 모양을 어떻게 찾나?" → 2.5절.

**⑤ 스케일링** — $[2,1,1]$의 테스트 RMSE $\propto G^{-3}$ (이론 $G^{-4}$). 경계 효과로 일부 표본 오차가 큼 → **중앙값**으로 보면 $G^{-4}$에 가까움.

# p.11 해설 — 외부·내부 자유도, 희소화 정규화

**① 외부 vs 내부 자유도 ⭐** — 노드 연결의 **계산 그래프** = 외부 자유도(MLP엔 있고 스플라인엔 없음): 다변수 **합성 구조** 학습. 활성화 함수 안의 **격자점** = 내부 자유도(스플라인엔 있고 MLP엔 없음): **1변수 함수** 학습. KAN은 둘 다.
→ 🔎 *external versus internal degrees of freedom* 에 밑줄.

**② 2.5 해석 가능성** — 데이터 구조에 맞는 KAN 모양을 모른다 → 충분히 큰 KAN에서 시작해 **희소화 정규화** 학습 후 **가지치기**.

**③ 희소화 ⭐** — MLP의 L1 정규화를 두 가지로 수정: (1) 선형 가중치가 없으니 **활성화 함수의 L1 노름**을 정의, (2) L1만으론 부족 → **엔트로피** 정규화 추가.
$$|\phi|_1\equiv\frac1{N_p}\sum_{s=1}^{N_p}|\phi(x^{(s)})|\quad(2.17),\qquad|\Phi|_1\equiv\sum_{i,j}|\phi_{i,j}|_1\quad(2.18)$$
$$S(\Phi)\equiv-\sum_{i,j}\frac{|\phi_{i,j}|_1}{|\Phi|_1}\log\frac{|\phi_{i,j}|_1}{|\Phi|_1}\quad(2.19)$$
$$\ell_{total}=\ell_{pred}+\lambda\Big(\mu_1\sum_l|\Phi_l|_1+\mu_2\sum_lS(\Phi_l)\Big)\quad(2.20),\ \ \mu_1=\mu_2=1$$
→ ✍️ 엔트로피를 줄이면 왜 희소해지나? (크기가 몇 개 엣지에 **몰려야** 엔트로피가 작다 — 균등하면 최대)

# p.17 해설 — 파인만 비교 방법과 "rapidity의 재발견"

**① 네 가지 신경망**
1. **사람이 만든 KAN**: 기호 식을 KA 표현으로 재작성. 예: $xy=\frac{(x+y)^2-(x-y)^2}4$ → $[2,2,1]$
2. 가지치기 없는 KAN: 폭 5, 깊이 $\{2..6\}$
3. 가지친 KAN: (2)에서 희소화·가지치기
4. MLP: 폭 5, 깊이 $\{2..6\}$, 여러 활성화
→ ✍️ 곱셈 항등식을 확인하고 $[2,2,1]$ KAN을 그려 보자: 1층 엣지에 $\pm x$, $\pm y$(선형), 2층 엣지에 $\pm\frac14(\cdot)^2$.

**② 결과** — MLP와 KAN이 **평균적으로 비슷**. 파인만 데이터는 변수 의존이 매끄럽거나 단조라 너무 쉬운 듯 (특수함수와 대조).

**③ 자동 발견 KAN이 더 작다 ⭐** — 최소/최고 가지친 모양이 대개 사람이 만든 것보다 작음 → KA 표현이 생각보다 **효율적**. 하지만 정보가 작은 공간에 압축돼 해석이 미묘해질 수도.

**④ 상대론적 속도 합성 ⭐⭐** — $f(u,v)=\frac{u+v}{1+uv}$. 사람은 곱셈 2층 + 역수 1층 + 곱셈 2층 = **5층**이라 생각. 자동 발견은 **2층**! 돌이켜보면 **rapidity** $a=\operatorname{arctanh}u$, $b=\operatorname{arctanh}v$:
$$\frac{u+v}{1+uv}=\tanh(\operatorname{arctanh}u+\operatorname{arctanh}v)$$
→ 물리 개념을 모르는 척해도 KAN에서 **직접 발견**할 수 있다.
→ 🔎 이 식에 크게 밑줄. ✍️ $\tanh$의 덧셈정리 $\tanh(a+b)=\frac{\tanh a+\tanh b}{1+\tanh a\tanh b}$ 로 직접 확인하자.

# p.18 해설 — 3.4 편미분방정식, 3.5 연속 학습

**① 그림 3.3** — 포아송 방정식: 예측 해와 참 해 사이의 $L^2$ 제곱 오차, $H^1$ 제곱 오차. 1·2번째: 학습 동역학, 3·4번째: 매개변수 수에 대한 스케일링. KAN이 더 빨리 수렴, 더 낮은 손실, 더 가파른 스케일링.

**② 3.4 포아송 방정식 ⭐** — $\Omega=[-1,1]^2$에서 $u_{xx}+u_{yy}=f$, 경계에서 $u=0$. $f=-\pi^2(1+4y^2)\sin(\pi x)\sin(\pi y^2)+2\pi\sin(\pi x)\cos(\pi y^2)$ → 참 해 $u=\sin(\pi x)\sin(\pi y^2)$.
**PINN** 손실: $\text{loss}_{pde}=\alpha\,\text{loss}_i+\text{loss}_b$ (내부 점 $n_i=10000$, 경계 점 $n_b=800$, $\alpha=0.01$).

**③ 결과 ⭐** — 2층 폭 10 KAN이 4층 폭 100 MLP보다 **100배 정확**($10^{-7}$ vs $10^{-5}$ MSE)하고 **100배 적은 매개변수**($10^2$ vs $10^4$).
→ 🔎 이 문장에 밑줄. 단서: KAN 학습이 **약 10배 느림**, 참 해가 기호 식이라 KAN에 유리한 비교일 수 있음.

**④ 3.5 연속 학습** — **파국적 망각**: 신경망이 과제 1 다음 과제 2를 배우면 과제 1을 금방 잊는다. 사람은 그렇지 않다 — 뇌는 공간적으로 국소화된 **기능 모듈**…

→ ✍️ 직접 확인: $u=\sin(\pi x)\sin(\pi y^2)$ 를 두 번 미분해 $u_{xx}+u_{yy}$가 위의 $f$가 되는지 검산해 보자 (연쇄법칙 연습!).

# p.21 해설 — 깊은 합성, 4.2 비지도 발견

**① (e) 계속** — 학습 후 4차 의존성과 $\tanh$ 의존성이 모두 나타남. 4.4절 국소화 상전이의 단순판.

**④ 왜 비지도인가** — 지도학습은 입력/출력 분할이 필요: 가능한 분할 $2^d-2$가지! DeepMind 매듭 연구는 signature를 **손으로** 목표로 골랐다.
→ ✍️ $d=18$이면 분할 방법은 몇 가지? ($2^{18}-2=262{,}142$)

**⑤ 방법 ⭐** — **대조 학습**처럼: 양성 표본 = 실제 데이터, 음성 표본 = 각 특징을 학습 집합 전체에서 **무작위 섞기**(분포 유지). $g(\mathbf x_{real})=1$, $g(\mathbf x_{fake})=0$ 학습. $g=\sigma\circ f$, $\sigma(x)=\exp(-\frac{x^2}{2w^2})$ (폭 좁은 가우시안) → $f(\mathbf x_{real})\approx0$. 마지막 활성화를 가우시안으로 고정한 $[\dots,1,1]$ KAN.

# p.22 해설 — 비지도 장난감 결과, 4.3 매듭 이론

**① 그림 4.2** — 6차원 데이터: $(x_1,x_2,x_3)$ 종속($x_3=\exp(\sin x_1+x_2^2)$), $(x_4,x_5)$ 종속($x_5=x_4^3$), $x_6$ 독립. 시드 0 → $x_1,x_2,x_3$ 관계 발견, 시드 2024 → $x_4,x_5$ 관계 발견. 현재는 **무작위성**(시드)에 의존 — 체계적 방법은 미래 과제.

**② 4.3 매듭 이론 ⭐** — 저차원 위상수학. **매듭** $K$ = $S^1$을 $S^3$에 매장. 주변 공간의 변형으로 바꿀 수 있으면 위상적으로 동치 $[K]=[K']$. **위상 불변량** $f$: $f(K)\ne f(K')$이면 $[K]\ne[K']$.
- 기하적 불변량: 쌍곡 매듭의 **쌍곡 부피**
- 대수적 불변량: **존스 다항식**
→ 🔎 *topological invariants* 에 밑줄.

**③ 기계학습과 매듭** — 강화학습으로 리본성 확인[46], 지도학습 + 수학자로 대수적·기하적 불변량을 잇는 **새 정리**(DeepMind, Davies 외 2021, *Nature*)[45].

**④ DeepMind의 결과** — (1) 신경망 기여도 분석: signature $\sigma$는 주로 meridinal distance $\mu$(실수 $\mu_r$, 허수 $\mu_i$)와 longitudinal distance $\lambda$에 의존. (2) 수학자들이 기울기(slope) $\mathrm{Re}(\lambda/\mu)$와의 상관을 찾아 정리를 증명.

→ ✍️ 신발 끈 매듭과 고리 매듭을 그려 보고, "끊지 않고 하나를 다른 것으로 바꿀 수 있는가"가 위상 동치라는 뜻임을 설명해 보자.

**① 그림 4.4** — 매듭 데이터 비지도 모드: 세 수학적 관계 재발견. $\lambda\in\{10^{-2},10^{-3}\}$, 여러 시드 → 세 군집.

# p.26 해설 — 4.4 앤더슨 국소화와 이동도 경계

**① 앤더슨 국소화 ⭐** — 양자계의 **무질서**가 전자 파동함수를 **국소화**시켜 수송을 멈추는 현상. 1·2차원에선 무한소의 무질서로도 모든 고유상태가 지수적으로 국소화. 3차원에선 임계 에너지(**이동도 경계, mobility edge**)가 확장 상태와 국소 상태를 가름 → 고체의 **금속–부도체 전이**, 광소자의 빛 국소화 이해에 중요.

**② 준주기 모형** — 저차원에서 무작위 대신 **준주기성**을 넣어도 이동도 경계 생김 → 해석적 이동도 경계 연구가 활발.

**③ 세 모형**
| 모형 | KAN의 역할 |
|---|---|
| 모자이크 모형 (MM) | 이동도 경계를 에너지의 1D 함수로 정확히 추출 |
| 일반화 오브리–앙드레 (GAAM) | KAN 공식이 참 식과 가까움 |
| 수정 오브리–앙드레 (MAAM) | 사람이 가설을 주고 KAN이 빠르게 검증하는 **협업** |

**④ 국소화의 척도** — 역참여비 $\mathrm{IPR}_k=\frac{\sum_n|\psi^{(k)}_n|^4}{(\sum_n|\psi^{(k)}_n|^2)^2}$, 그리고 **프랙탈 차원** $D_k=-\frac{\log\mathrm{IPR}_k}{\log N}$. $D_k=0$: 국소, $D_k=1$: 확장.
→ ✍️ 파동함수가 한 칸에만 있으면 IPR은? (1 → $D=0$, 국소) $N$칸에 고르게 퍼지면? ($1/N$ → $D=1$, 확장)

# p.28 해설 — 표 5와 GAAM

**① 표 5** — GAAM·MAAM의 참 식과 KAN 발견 식들. GAAM 참: $\alpha E+2(\lambda-1)=0$. MAAM은 자동 모드(긴 식, $\sin$·$\arctan$·$\exp$ 범벅)에서 수동 단계(3, 4A, 4B)로 갈수록 **짧아짐**.
→ 🔎 MAAM-KAN auto 행과 step 4B 행의 길이를 비교하자.

**② GAAM** — 준주기 퍼텐셜 $V_n=2\lambda\frac{\cos(2\pi nb+\phi)}{1-\alpha\cos(2\pi nb+\phi)}$ ($\alpha\in(-1,1)$), $b$ = 황금비. 이동도 경계 닫힌 식: $\alpha E=2(1-\lambda)$.

**③ 데이터** — $\phi,\alpha,\lambda$ 무작위 표본($t=1$), 고유값과 프랙탈 차원 계산. 질서 매개변수 $g(\alpha,E,\lambda,\phi)=\alpha E+2(\lambda-1)$.

**④ Alice의 진행 ⭐** — $[4,2,1,1]$ KAN (자동 가지치기로든 추측으로든). 마지막 활성화를 시그모이드로, 희소화 학습 → **98.7%** (그림 4.6(a) 1단계). 관찰: $\phi$가 **전혀 쓰이지 않음** → 이동도 경계는 $\phi$와 무관 (식 4.8과 일치). 나머지 활성화는 거의 선형 또는 2차…

→ ✍️ KAN이 "어떤 입력을 안 쓰는지" 보여 주는 것만으로도 과학적 정보가 된다. 이것을 Touretzky의 "투명성(transparency)"과 연결해 보자.

# p.29 해설 — GAAM 마무리, MAAM: 사람의 지혜가 더 필요할 때

**① GAAM 마무리** — 자동 기호 맞춤(라이브러리를 선형·2차로 제한) → 이미 기호적인 신경망, **98.9%**(오히려 약간 향상). `symbolic_formula`로 $g$의 식 획득 → 작은 항을 지우고 계수를 정수로 맞추면 참 식에 가까워짐.

**② 기호 회귀였다면 ⭐** — 운 좋으면 정답, 대부분은 쓸모없는 결과, 과정을 "디버깅"할 수 없고, 기호 항 라이브러리를 **미리** 줘야 함. KAN은 사전 정보 없이 먼저 **단서**를 보고, 그다음 사람이 가설을 세워 구현. "바로 정답을 주진 않아도 **항상 쓸모 있는 것**을 돌려준다".
→ 🔎 *KANs will always return something useful* 에 밑줄.

**③ MAAM** — 지수적으로 감소하는 결합 $t$, 퍼텐셜 $V_n=\lambda\cos(2\pi nb+\phi)$, 이동도 경계 닫힌 식 $\lambda\cosh p=E+t=E+t_1e^{p}$ ($t_1\equiv te^{-p}=1$).

**④ Alice의 진행** — $[4,2,1,1]$로 75%(불충분) → $[4,3,1,1]$로 **98.4%**. $\phi$ 무시됨 (식 4.11과 일치). 자동 기호 회귀(큰 라이브러리) → 복잡한 식, 97.1%. 단순한 식을 원하면 **수동 모드**: $[4,3,1,1]\to[4,2,1,1]$ 가지치기(97.7%), $p$ 외 활성화를 선형·2차로 고정(97.7%). 이후 두 갈래:
- 4A: $p$ 의존이 $\cosh$라고 추측 → 96.9%
- 4B: 모른다면 단순하게 2차로…

# p.30 해설 — 그림 4.6, 단순함–정확도의 손잡이, 관련 연구

**① 그림 4.6** — GAAM·MAAM 이동도 경계를 찾는 사람–KAN 협업. 게으르게(자동 모드) 또는 적극적으로(수동 모드).

**② 4B 결과** — 2차로 가정 → **95.4%**. 둘 다 해 보면: $\cosh$가 정확도에 유리, 2차가 단순함에 유리. 수동 조작을 많이 할수록 식이 단순(정확도는 약간 희생).
→ 🔎 KAN의 **"손잡이(knob)"**: 단순함과 정확도 사이를 사용자가 조절 — 때로는 단순함이 정확도까지 높임.

**③ 5절 관련 연구: KA 정리와 신경망** — 연결 자체는 새롭지 않지만[66, 67, 9–14, …], 내부 함수의 병적 행동 때문에 비관적이었고 대부분 원래의 2층 $2n+1$에 머물렀으며 **역전파 이전**의 것도 많음. 일반화 가법 모형(GAM), 그래프 신경망, 커널 기계와도 연결.

**④ 기여 재확인** — 콜모고로프 신경망을 **임의 폭·깊이**로 일반화, 현대 딥러닝 흐름 속에 부활, AI+과학의 **기초 모델** 가능성.

**⑤ 신경 스케일링 법칙** — 테스트 손실이 모델 크기·데이터·계산량에 대해 **거듭제곱 법칙** (Kaplan 외 [73] 등).

→ ✍️ ai_life 활동 아이디어: 같은 데이터에 "정확하지만 긴 식"과 "단순하지만 덜 정확한 식"을 보여 주고 학생에게 고르게 하기 — 오컴의 면도날(Saltzer 결론!)과 연결.

# p.31 해설 — 관련 연구: 스케일링, 해석, 활성화, 기호 회귀, PINN

**① 스케일링 법칙의 기원** — 고유 차원, 과제 양자화, 자원 이론, **랜덤 특징**(Bahri 외, 이번 주 Lee 2019의 저자들!), 합성 희소성, 최대 인자 수. 이 논문의 기여: 매끄러운 KA 표현이 있으면 고차원 함수가 **1D 함수처럼** 스케일링(최선의 경우). 언어 모델 같은 복잡한 과제에도 성립할까? — 열린 질문.

**② 기계적 해석 가능성(MI)** — **수동적** MI: 이미 학습된 신경망 이해. **능동적** MI: 본질적으로 해석 가능한 구조·학습법 설계. KAN은 **능동적**.

**③ 학습 가능한 활성화** — 다항식, 스플라인, SiLU, 신경망 등으로 매개변수화한 선행 연구. KAN은 B-스플라인. (부록 B: LAN)

**④ 기호 회귀** — 유전 알고리즘(Eureqa, GPLearn, PySR), 신경망 기반(EQL, OccamNet), 물리 영감(AI Feynman), 강화학습. KAN은 신경망 기반과 가장 비슷하지만, 기호로 고정하기 **전에** 활성화를 **연속적으로** 학습한다는 점이 다름.

**⑤ PINN·PINO** — 3.4절처럼 편미분방정식 손실에서 MLP를 KAN으로 대체 가능. Deep Ritz, PINN, FNO, DeepONet.

**⑥ AI for Math** — 풀린 매듭 판별, 리본 매듭, 불변량 예측과 관계 발견.

→ ✍️ "수동적 vs 능동적 해석 가능성"을 자동차에 비유해 보자: 엔진을 뜯어 분석하기 vs 처음부터 투명한 엔진 만들기.

# p.32 해설 — 6절 토론: 수학·알고리즘·응용의 과제

**① 수학적 측면 ⭐** — 정리 2.1은 예비 분석일 뿐, 이해는 매우 제한적. KA 정리는 $[n,2n+1,1]$이라는 **아주 제한된** 부분집합에 해당. 깊은 KAN의 경험적 성공이 수학적으로 무언가 근본적인 것을 뜻할까? "**더 깊은**" KA 표현의 일반화 정리, 활성화의 매끄러움과 깊이의 관계, "**콜모고로프–아놀드 깊이**"로 함수 부류를 분류할 수 있을까?
→ 🔎 *"Kolmogorov-Arnold depth"* 에 밑줄 — 수학 연구 주제!

**② 알고리즘 측면**
1. **정확도**: 스플라인 대신 방사 기저 함수 등, 적응적 격자
2. **효율**: 활성화가 모두 달라 **배치 계산**을 못 씀 → 그룹으로 묶는 "다중 헤드"로 MLP와 KAN 사이 보간
3. **혼합**: KAN의 두 차이 (i) 엣지 위 활성화, (ii) 학습 가능 활성화 — 어느 쪽이 핵심? (부록 B의 LAN은 (ii)만)
4. **적응성**: 스플라인의 국소성으로 다중격자·다중척도 방법

**③ 응용 측면** — 나비에–스토크스, 밀도범함수 이론 등. 트랜스포머의 MLP를 KAN으로 바꾼 **"칸스포머(kansformer)"**.

**④ AI+과학의 "언어 모델"로서 KAN ⭐** — LLM이 혁명적인 이유: 자연어를 쓰는 누구에게나 유용. **과학의 언어는 함수**. KAN은 해석 가능한 함수로 이루어져 있어 KAN을 보는 것은 **함수라는 언어로 대화하는 것**.
→ 🔎 *The language of science is functions* 에 밑줄.

# p.33 해설 — AI 과학자인가, 과학자를 돕는 AI인가 (그림 6.1)

**① 패러다임 질문 ⭐** — "**AI 과학자**를 원하는가, **과학자를 돕는 AI**를 원하는가?" 완전 자동 AI 과학자의 본질적 어려움: 인간의 선호를 정량화하기 어렵다 — 분야마다 "단순하다", "해석 가능하다"의 기준이 다름. 그래서 과학의 언어(함수)로 말하고 개별 과학자의 귀납 편향과 쉽게 상호작용하는 AI가 바람직.
→ 🔎 *Do we want AI scientists, or do we want AI that helps scientists?* 에 크게 밑줄 — ai_life 수업의 마무리 토론 질문으로 최고.

**② 최대 병목: 느린 학습** — 같은 매개변수 수에서 MLP보다 **약 10배 느림**. 효율 최적화를 열심히 하지 않았으므로 근본적 한계보다는 **공학적 문제**로 봄.

**③ 그림 6.1: KAN을 쓸까 MLP를 쓸까? ⭐** — 빨리 학습해야 하면 **MLP**. 해석 가능성·정확도가 중요하고 느린 학습이 큰 문제가 아니면 **KAN**을 시도 — 적어도 작은 규모 AI+과학 문제에서.
→ ✍️ 그림 6.1의 결정 트리를 노트에 옮겨 그리자.

**④ 감사의 글** — Tomaso Poggio 등, NSF IAIFI 지원.

→ ✍️ 이번 주 Touretzky의 Big Idea 5(사회적 영향)와 연결: "AI가 과학자를 대체"와 "AI가 과학자를 돕는다" 중 학생들은 어떤 미래를 원하는지 토론해 보자.

**④ 장단점 ⭐**
| LAN의 장점 | LAN의 단점 |
|---|---|
| 개념이 더 단순 (MLP에서 활성화만 학습) | 덜 해석 가능 (가중치 행렬은 MLP처럼 읽기 어려움) |
| 더 잘 확장 (활성화 매개변수 $N$ vs KAN $N^2$) | KAN보다 덜 정확 (MLP보단 정확) |

# p.43 해설 — LAN의 해석 가능성, B.3 이미지 적합

# p.49 해설 — 그림 F.1: 최고 특수함수 KAN

**① 그림 F.1** — 15개 특수함수(타원함수·타원적분·베셀·르장드르·구면조화)마다 **테스트 RMSE가 가장 낮은** KAN.

**② 보는 포인트** — 특수함수는 기초함수로 닫힌 식이 없는 경우가 많다. 그런데도 KAN은 $[2,2,1]$, $[2,3,2,1]$ 같은 **작은** 구조로 근사 → 2변수 특수함수를 "1변수 함수 몇 개 + 덧셈"으로 분해한 셈 (p.15의 "1D 조회표" 아이디어).
→ 🔎 구면조화 $(m=0,n=1)$의 $[2,1,1]$ KAN — 가장 단순한 것 중 하나 — 을 찾아 표시하자.

→ ✍️ 구면조화 $Y_1^0\propto\cos\theta$ 는 한 변수만의 함수다. 그런데 왜 입력이 2개인 $[2,1,1]$이 필요할까? (데이터의 두 입력 중 하나만 쓰이고 나머지는 거의 0인 엣지가 될 것 — 그림에서 확인!)
→ ✍️ 베셀 함수 $J_\nu(x)$는 진동하며 감쇠한다. KAN 엣지 중 이런 모양의 활성화를 찾아보자.
