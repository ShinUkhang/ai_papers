# 📚 AI Life 논문 서재

원리와 수학으로 읽는 인공지능 — 매주 10편의 논문을 한국어 리뷰지(PDF)로 정리합니다.
[AI Life 커리큘럼](https://shinukhang.github.io/ai_life/)의 이론 심화 자료입니다.

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `00_주간_읽기목록` | 주차별 읽기 목록 · 요일별 계획 · 주간 리뷰지 |
| `00_참고도서` | 참고 도서 추천 (무료 공개 원서 PDF 링크 포함) |
| `01_인공지능_수학` | 근사 이론, 최적화, 학습 이론 |
| `02_기계학습` | 일반화, 확률 모델 |
| `03_딥러닝` | 신경망 구조 |
| `04_컴퓨터_교육` | 컴퓨팅 사고력, AI 교육 |
| `05_네트워크` | 인터넷과 통신의 원리 |
| `tools` | `md2pdf.py`(리뷰 → 인쇄용 PDF), `build_index.py`(서재 페이지 생성) |

## 읽는 방법
1. 이번 주 읽기 목록 PDF로 순서를 확인
2. 각 논문의 **한국어 리뷰지 PDF**로 핵심 수식과 개념을 먼저 파악
3. 리뷰지의 **원문 PDF 링크**로 원문을 받아 밑줄 치며 읽기
4. 주말에 주간 리뷰지 작성

> 원문 PDF는 저작권 때문에 이 저장소에 올리지 않고, 각 리뷰지에 합법적인 무료 공개 링크(arXiv, 저자 홈페이지 등)로 연결합니다.
