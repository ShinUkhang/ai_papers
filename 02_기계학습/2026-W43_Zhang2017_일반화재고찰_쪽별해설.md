# p.1 해설 — 초록과 서론: 무엇이 일반화를 결정하는가?

**① 초록** — 거대한 신경망이 **훈련 성능과 테스트 성능의 차이가 놀랍게 작다**. 기존 설명은 (a) 모델족의 성질, (b) 정규화 기법. 체계적인 실험으로 이 둘이 **설명에 실패함**을 보인다:
- 최신 CNN은 SGD로 **무작위 레이블도 쉽게 맞춘다**
- 명시적 정규화를 해도 질적으로 같음
- 이미지를 **완전한 무작위 잡음**으로 바꿔도 맞춘다
- 이론: 파라미터 수가 데이터 수를 넘자마자 **깊이 2 신경망도 완벽한 유한 표본 표현력**을 가짐
→ 🔎 *easily fit a random labeling of the training data* 에 밑줄. 논문의 핵심 한 줄.

**② 서론 첫 문단** — 신경망은 학습 표본보다 파라미터가 **훨씬 많은데도** 일반화 오차(훈련 오차와 테스트 오차의 차이)가 작다. 동시에 일반화를 못 하는 구조도 쉽게 만들 수 있다. **무엇이 둘을 가르는가?**

**③ 통계적 학습 이론의 도구들** — 일반화 오차를 통제하는 복잡도 척도:
| 척도 | 출처 |
|---|---|
| VC 차원 | Vapnik (1998) |
| 라데마허 복잡도 | Bartlett & Mendelson (2003) |
| 균등 안정성 | Bousquet & Elisseeff (2002) 등 |
파라미터가 많으면 이론상 **정규화가 필요**. 조기 종료처럼 **암묵적** 정규화도 있음.

**④ 문제 제기** — 기존 관점은 일반화 성능이 **극적으로 다른** 신경망들을 구별하지 못한다.

# p.2 해설 — 핵심 발견 요약

**① 무작위화 검정 ⭐** — 비모수 통계의 **무작위화 검정**(randomization test)을 변형. 진짜 레이블을 무작위 레이블로 바꾼 데이터로 표준 구조들을 학습.
> **심층 신경망은 무작위 레이블을 쉽게 맞춘다.**

→ 훈련 오차 0, 테스트 오차는 우연 수준. 모델·크기·하이퍼파라미터·최적화기를 **하나도 바꾸지 않고** 레이블만 섞어서 일반화 오차를 크게 만들 수 있다.

**② 세 가지 함의**
1. 신경망의 **유효 용량**은 데이터 전체를 **암기**하기에 충분하다.
2. 무작위 레이블에서도 최적화는 **여전히 쉽다** — 학습 시간이 진짜 레이블보다 **작은 상수배**만 늘어난다.
3. 레이블 무작위화는 **데이터 변환일 뿐**, 학습 문제의 다른 성질은 그대로.

**③ 무작위 픽셀** — 이미지 자체를 가우시안 잡음으로 바꿔도 CNN은 훈련 오차 0. 잡음 정도를 0에서 1까지 바꾸면 일반화 오차가 **꾸준히 나빠짐** → 신경망은 남은 **신호**를 잡으면서 **잡음 부분은 무차별적으로 외운다**.

**④ 명시적 정규화의 역할 ⭐**
> **명시적 정규화는 일반화를 개선할 수 있지만, 필요하지도 충분하지도 않다.**

볼록 경험적 위험 최소화에서는 정규화가 자명한 해를 막는 **필수** 장치이지만, 딥러닝에서는 **조정용 매개변수**에 가깝다.

**⑤ 유한 표본 표현력** — 파라미터 $p = 2n + d$ 인 **2층 ReLU 망**이 $d$차원 표본 $n$개의 **어떤 레이블도** 표현. 이전 결과(Livni 외)는 $O(dn)$. 깊이 $k$로 하면 층당 $O(n/k)$.

# p.3 해설 — 암묵적 정규화, 관련 연구, 2절 시작

**① 암묵적 정규화** — 신경망은 거의 항상 **SGD의 출력**으로 모델을 고른다. 선형 모델에서 SGD는 항상 **작은 노름의 해**로 수렴 → **알고리즘 자체가 정규화**. 작은 데이터셋에서는 정규화 없는 가우시안 커널 방법도 잘 일반화.

**② 균등 안정성의 한계** — Hardt 외(2016)는 SGD 단계 수로 일반화 오차를 상한. 하지만 균등 안정성은 **레이블과 무관한** 알고리즘의 성질 → 진짜 레이블(일반화 잘 됨)과 무작위 레이블(안 됨)을 **구별할 수 없다**.
→ 🔎 *independent of the labeling of the training data* 에 밑줄.

**③ 표현력 연구와의 차이** — Cybenko(1989)부터 이어진 보편 근사 정리들은 **모집단 수준**(전체 정의역에서 어떤 함수를 표현하는가). 이 논문은 **유한 표본 $n$개**에 대한 표현력.
→ 이번 주 Cybenko 논문과 연결!

**④ 크기와 무관한 상한** — Bartlett(1998): 시그모이드 망의 fat-shattering 차원을 가중치의 $\ell_1$ 노름으로 상한 → **망 크기와 무관한** 일반화 상한. 하지만 ReLU에서는 $\ell_1$ 노름이 정보를 주지 못함. Neyshabur 외(2014): **망 크기는 주된 용량 통제가 아니다**.

**⑤ 2절 유효 용량** — 후보 구조를 진짜 데이터와 무작위 레이블 데이터 **둘 다로** 학습. 무작위 레이블에서는 학습이 불가능하므로 학습이 수렴하지 않거나 크게 느려질 것이라 예상했지만 — **놀랍게도 거의 영향이 없었다**.

# p.5 해설 — 결과와 기존 이론의 한계

**① 왜 무작위 픽셀이 더 빠른가** — 무작위 픽셀 입력들은 같은 클래스의 자연 이미지들보다 **서로 더 떨어져 있어서** 임의의 레이블 할당이 더 쉽다.

**② ImageNet** — 무작위 레이블 100만 개(1000 클래스)에서 top-1 훈련 정확도 **95.20%**. 하이퍼파라미터 조정 없이! 명시적 정규화를 켜도 약 90%.

**③ 부분 오염** — 모든 오염 수준에서 훈련 집합을 완벽히 맞춤. 오염이 1에 가까워지면 일반화 오차 → **90%** (CIFAR10 무작위 추측 수준).

**④ 라데마허 복잡도와 VC 차원 ⭐ 수학적 핵심**
$$\hat{\mathfrak R}_n(\mathcal H) = \mathbb E_\sigma\Big[\sup_{h\in\mathcal H}\frac1n\sum_{i=1}^n\sigma_i\,h(x_i)\Big],\quad \sigma_i\in\{\pm1\}\ \text{균등 무작위}$$
→ 이 정의는 **무작위 $\pm1$ 레이블을 맞추는 능력** = 바로 이 논문의 무작위화 검정! 신경망이 무작위 레이블을 완벽히 맞추므로 $\hat{\mathfrak R}_n(\mathcal H)\approx 1$ → **자명한 상한**이라 쓸모없는 일반화 한계.
→ 🔎 *This definition closely resembles our randomization test* 에 밑줄.

**⑤ VC 차원, fat-shattering 차원** — 같은 논리. Bartlett의 $\ell_1$ 노름 상한은 ReLU에 적용 불가, Neyshabur 외의 다른 노름 일반화도 관찰을 설명하지 못함.

**⑥ 균등 안정성** — 표본 하나를 바꿨을 때 알고리즘이 얼마나 민감한가. 알고리즘만의 성질이라 **데이터·레이블 분포를 고려하지 않음**. 더 약한 안정성 개념은 일반화 오차 상한과 동치이지만 활용이 어렵다.

**② 3절: 정규화의 고전적 역할** — 파라미터가 데이터보다 많을 때 과적합을 완화하는 표준 도구. 원래 가설 공간이 너무 크지만, 정규화가 학습을 **관리 가능한 복잡도의 부분집합**으로 제한. 노름에 벌점을 주면 유효 라데마허 복잡도가 극적으로 줄어든다.

**③ 딥러닝에서는 다르다** — 드롭아웃과 가중치 감쇠를 켜도 InceptionV3는 무작위 훈련 집합을 거의 완벽히 맞춤. 단 **AlexNet은 가중치 감쇠를 켜면 무작위 레이블에서 수렴 실패**.

**④ 비교한 정규화 기법**
- **데이터 증강**: 무작위 자르기, 밝기·채도·색상·대비 변화
- **가중치 감쇠**: $\ell_2$ 정규화 = 가중치를 유클리드 공 안으로 제한하는 것과 동치
- **드롭아웃**: 층 출력을 무작위로 0으로 (ImageNet의 Inception V3만 사용)

**④ 배치 정규화** — 미니배치 안에서 층 응답을 정규화. 정규화용으로 설계되진 않았지만 보통 일반화를 개선. BN을 모두 뺀 "Inception w/o BatchNorm"으로 실험.

# p.8 해설 — 4절 유한 표본 표현력, 5절 선형 모델

**① BN 결과** — 학습 동역학은 안정화하지만 일반화 효과는 **3~4%** 뿐.

**② 정규화 요약** — 잘 조정하면 일반화를 도울 수 있지만, **일반화의 근본 원인은 아닐 것**. 모든 정규화를 빼도 잘 작동하므로.

**③ 4절: 유한 표본 표현력** — 기존 결과(Cybenko 등)는 거의 모두 **모집단 수준**: 같은 파라미터 수로 전체 정의역에서 어떤 함수를 표현할 수 있는가. 예: 깊이 $k$가 $k-1$보다 일반적으로 강력.

**④ 저자들의 관점** — 실제로 중요한 것은 **크기 $n$인 유한 표본** 위의 표현력. 모집단 결과를 균등 수렴으로 옮기면 표본 수가 입력 차원에 다항적, 깊이에 **지수적**으로 커야 해서 비현실적.

**⑤ 정의와 정리 1 ⭐**
신경망 $C$가 "크기 $n$ 표본의 임의의 함수를 표현한다" ⟺ 모든 $S\subseteq\mathbb R^d$ ($|S|=n$)와 모든 $f:S\to\mathbb R$ 에 대해 $C(x)=f(x)\ \forall x\in S$ 인 가중치가 존재.
> **정리 1.** ReLU 활성화와 $2n+d$ 개 가중치를 가진 2층 신경망이 존재하여 $d$차원 표본 $n$개 위의 임의의 함수를 표현한다.
증명은 부록 C (p.13–14).

**⑥ 5절: 선형 모델로 돌아가기** — 선형 모델도 일반화의 원천을 이해하기 쉽지 않다. 경험적 위험 최소화 $\min_w \frac1n\sum_i \mathrm{loss}(w^\top x_i, y_i)$. $d\ge n$ 이고 데이터 행렬 $X$ ($n\times d$)의 랭크가 $n$ 이면 $Xw=y$ 의 해가 **무한히 많다**. 그렇다면 모든 전역 최솟값이 똑같이 일반화하는가?

# p.9 해설 — SGD가 고르는 해: 최소 노름 ⭐

**① 곡률로는 구별 불가** — 선형 모델에서 제곱 손실의 헤시안은 $\frac1n X^\top X$ 로 **$w$와 무관** → 모든 최적해의 곡률이 같다. 게다가 모든 전역 최적해에서 헤시안이 **퇴화**.
→ "평평한 최솟값이 일반화를 잘한다"는 설명이 선형에서는 통하지 않음.

**② SGD의 해 ⭐ 직접 유도하기** — SGD 업데이트 $w_{t+1} = w_t - \eta_t e_t x_{i_t}$. $w_0 = 0$ 이면
$$w = \sum_{i=1}^n\alpha_i x_i = X^\top\alpha\quad(\text{데이터의 생성 공간 안})$$
여기에 $Xw = y$ 를 더하면 $XX^\top\alpha = y$ — **유일한 해**. 내적만 쓰므로 = **커널 트릭**!

**③ 커널 실험** — 그람 행렬 $K = XX^\top$ 를 만들고 $K\alpha = y$ 를 풀면 끝.
| 데이터 | 전처리 | 테스트 오차 |
|---|---|---|
| MNIST | 없음 | **1.2%** |
| MNIST | 가보 웨이블릿 | **0.6%** |
| CIFAR10 | 가우시안 커널 | 46% |
| CIFAR10 | 무작위 합성곱망(필터 32,000개) | 17% (ℓ2 추가 시 15%) |
→ MNIST는 정규화를 추가해도 **개선 없음**!

**④ 최소 노름 해석** — 이 커널 해는 $Xw=y$ 의 **최소 $\ell_2$ 노름 해**와 동치: $w = X^\top(XX^\top)^{-1}y$. 일반화 못 하는 해는 쉽게 만들 수 있다(예: 무작위 중심의 가우시안 커널) — 그런 해들은 노름이 훨씬 크다.

**⑤ 하지만 최소 노름도 예측력이 없다 ⭐** — MNIST 전처리 없음: 노름 ≈ 220, 웨이블릿: 노름 ≈ **390**인데 테스트 오차는 **절반**. → 최소 노름은 일반화 이야기의 **아주 작은 조각**일 뿐.
→ 🔎 *only a very small piece of the generalization story* 에 밑줄.

**⑥ 6절 결론 시작** — 유효 용량을 정의하고 이해하는 단순한 실험 틀을 제시.

**③ 보조정리 1 ⭐ 선형대수 연습** — 번갈아 놓인 수열 $b_1<x_1<b_2<x_2<\cdots<b_n<x_n$ 에 대해
$$A = \big[\max\{x_i - b_j,\ 0\}\big]_{ij}$$
는 **최대 랭크**이고 최소 고윳값은 $\min_i(x_i - b_i)$.
**증명**: $i<j$ 이면 $x_i < b_j$ 라서 성분이 0 → **하삼각 행렬**. 대각 성분 $x_i - b_i > 0$ → 가역. 하삼각 행렬의 고윳값은 대각 성분. ∎

**④ 정리 1 증명 시작** — 함수
$$c(x) = \sum_{j=1}^n w_j\max\{\langle a, x\rangle - b_j,\ 0\}$$
는 깊이 2 ReLU 망 ($a\in\mathbb R^d$, $b,w\in\mathbb R^n$ → 파라미터 $2n+d$). 표본 $z_i$가 서로 다르므로 $x_i = \langle a, z_i\rangle$ 가 $b$들과 **번갈아 놓이도록** $a$, $b$를 고를 수 있다.

# p.14 해설 — 증명 마무리, 깊이와 폭의 교환, 부록 D·E

**① 정리 1 증명 완료** — $c(z_i) = (Aw)_i$ 이고 보조정리 1에 의해 $A$가 가역 → $w = A^{-1}y$ 로 풀면 $c(z_i) = y_i$. ∎
→ ✍️ $n=3$, $d=1$ 인 작은 예를 직접 만들어 $A$를 써 보세요.

**② 깊이와 폭의 교환** — 깊이 2는 폭이 클 수밖에 없지만, $[0,1]$을 $b$개 구간으로 나눠 층 $j$가 구간 $I_j$의 점들만 담당하게 하면 층당 $O(n/b)$ 노드. 마지막에 입력이 어느 구간에 속하는지 고르는 **멀티플렉서**(근사 지시함수의 합)를 붙임.
> **따름정리 1.** 모든 $k\ge2$ 에 대해 깊이 $k$, 폭 $O(n/k)$, 가중치 $O(n+d)$ 인 ReLU 망이 크기 $n$ 표본 위의 임의의 함수를 표현한다.
