# p.1 해설 — 초록과 서론: "큰 모델은 나쁘다"?

**① 초록 ⭐** — 다양한 현대 딥러닝 과제에서 **이중 하강**이 나타난다: 모델 크기를 키우면 성능이 **먼저 나빠졌다가 다시 좋아진다**. 모델 크기뿐 아니라 **학습 에폭 수**에 대해서도. 이를 **유효 모델 복잡도(EMC)** 로 통합하고 일반화된 이중 하강을 추측. 또 학습 표본을 늘리면(심지어 **4배**) 테스트 성능이 **나빠지는** 영역을 찾았다.
→ 🔎 *increasing (even quadrupling) the number of train samples actually hurts* 에 밑줄.

**② 그림 1** — 왼쪽: CIFAR-10 + **15% 레이블 잡음**, ResNet18의 폭을 바꿀 때 학습/테스트 오차. 오른쪽: 에폭별 테스트 오차. Adam, 4K 에폭. 폭 64 = 표준 ResNet18.
→ ✍️ 그림 1 왼쪽에서 학습 오차가 0이 되는 폭과 테스트 오차 정점의 폭이 같은지 확인하자.

**③ 편향–분산 절충** — 고전 통계(Hastie 외): 복잡한 모델은 편향↓ 분산↑. 임계를 넘으면 분산이 지배해 **"큰 모델이 나쁘다"**.

**④ 현대 신경망은 다르다** — 수백만 매개변수로 **무작위 레이블도 외우는데**(Zhang 외, 지난주) 작은 모델보다 훨씬 잘한다. 실무 통념은 **"큰 모델이 좋다"**.
→ 🔎 *more than enough to fit even random labels* 에 밑줄 — 지난주와 연결!

**⑤ 각주** — Nakkiran은 OpenAI 인턴 중 Sutskever와 연구. **Mikhail Belkin**과 Chris Olah에게 감사 → 지난주 Belkin 논문의 직접적 후속.

# p.2 해설 — 두 영역과 주요 기여

**① 그림 2 ⭐** — 왼쪽: (모델 크기 × 에폭) 평면의 테스트 오차. **가로선** = 모델 방향 이중 하강, **세로선** = 에폭 방향 이중 하강. 오른쪽: 학습 오차. ResNet18, CIFAR-10, 15% 잡음, 데이터 증강, Adam 최대 4K 에폭.
→ ✍️ 그림 2 왼쪽에서 "밝은 띠(높은 오차)"가 어디를 따라 놓여 있는지 형광펜으로 그려 보자.

**② 학습 시간 논쟁, 그리고 유일한 합의** — 조기 종료가 좋은 경우도, 학습 오차 0까지 가는 게 좋은 경우도. 모두 동의하는 단 하나: **"데이터는 많을수록 좋다"**.

**③ 두 영역** — **과소 매개변수**(복잡도 < 표본 수): 고전적 **U자**. 복잡도가 **보간**(학습 오차 ≈ 0)할 만큼 크면: 복잡도를 늘릴수록 테스트 오차 **감소**. Belkin 외(2018)가 처음 일반적으로 제기하고 **"이중 하강"** 이라 명명.

**④ 기여 1** — 이중 하강은 과제·구조·최적화 방법에 걸쳐 **견고한** 현상.

**⑤ 기여 2: EMC ⭐** — 학습 절차가 학습 오차 ≈ 0을 달성하는 **최대 표본 수**. 데이터 분포·구조뿐 아니라 **학습 절차**에 의존, 특히 학습 시간을 늘리면 EMC가 증가 → **에폭 방향 이중 하강**. 따름결과: 조기 종료는 **임계 매개변수화** 모델이라는 좁은 영역에서만 도움.
→ 🔎 *early stopping only helps in the relatively narrow parameter regime* 에 밑줄.

**⑥ 기여 3: 표본 비단조성** — 정점은 EMC = 표본 수 근처 → 표본을 늘리면 정점이 **오른쪽 이동** → 때로 **더 많은 데이터가 더 나쁘다** (그림 3: 표본 **4.5배**).

# p.3 해설 — EMC의 정의와 일반화된 가설

**① 그림 3** — IWSLT'14 독→영 번역, 트랜스포머 크기($d_{model}$)별 테스트 손실(토큰당 perplexity). 18k 표본 곡선은 대체로 4k보다 낮지만 **오른쪽으로 이동** → 어떤 크기에서는 18k가 **더 나쁨**.

**② 학습 절차 $\mathcal T$** — 표본 집합 $S=\{(x_1,y_1),\dots,(x_n,y_n)\}$ → 분류기 $\mathcal T(S)$.

**③ 정의 1 ⭐⭐**
$$\mathrm{EMC}_{\mathcal D,\epsilon}(\mathcal T):=\max\{n\mid\mathbb E_{S\sim\mathcal D^n}[\mathrm{Error}_S(\mathcal T(S))]\le\epsilon\}$$
→ 🔎 이 식에 크게 밑줄. "평균 학습 오차가 $\epsilon$ 이하가 되는 가장 큰 $n$".

**④ 가설 1 (비형식적) ⭐**
| 영역 | 조건 | 유효 복잡도↑ 하면 |
|---|---|---|
| 과소 | EMC ≪ $n$ | 테스트 오차 ↓ |
| 과대 | EMC ≫ $n$ | 테스트 오차 ↓ |
| 임계 | EMC ≈ $n$ | ↓ 일 수도 ↑ 일 수도 |

**⑤ 비형식성 인정** — $\epsilon$을 원리적으로 고를 방법 없음(휴리스틱 **0.1**), "충분히 작다/크다"의 정식화도 없음. 보간 임계점 주변에 **임계 구간**이 있고 그 폭은 분포·절차에 의존 — 아직 완전히 이해 못 함.

**⑥ 검증 방법** — 보간 임계점을 **매개변수 수, 학습 길이, 레이블 잡음 양, 표본 수**로 이동시키며 실험.

→ ✍️ ai_life **01 선형회귀**에서 점 5개에 대해 "4차 다항식"의 EMC는? (5 — 점 5개를 정확히 지나는 다항식이 있다)

# p.4 해설 — 세 결과 요약, 관련 연구, 실험 설정

**① 모델 방향 (5절)** — CIFAR-10/100, IWSLT'14, CNN·ResNet·트랜스포머, SGD·Adam, 증강·정규화 모두에서. **정점은 체계적으로 보간 임계점**. "큰 모델이 더 나쁜" 현실적 설정 제시.

**② 에폭 방향 (6절)** — 큰 모델의 테스트 오차: 감소 → (임계 부근) 증가 → 학습 끝에서 **다시 감소**. "**더 오래 학습하면 과적합을 바로잡을 수 있다**".
→ 🔎 *training longer can correct overfitting* 에 밑줄.

**③ 표본 방향 (7절)** — 임계 영역에서 긴 **고원**(데이터를 늘려도 안 좋아짐, CIFAR-10 CNN) 또는 **정점**(IWSLT'14 트랜스포머: 더 많은 데이터가 해롭다).

**④ 레이블 잡음에 대해** — 잡음이 있을 때 가장 뚜렷하지만, 잡음 없이도 정점: CIFAR-100 ResNet(그림 4a), CNN(그림 20), IWSLT'14 트랜스포머(그림 8). 무잡음에선 **고원**, 잡음을 넣으면 **정점**으로 발전.

**⑤ 관련 연구** — Belkin 외(2018)가 일반 현상으로 제안. 선형 최소제곱 이론: Hastie 외, Bartlett 외, Mei & Montanari 등. 이 논문의 차별점: (1) 매개변수 수를 넘어 **학습 절차**까지 EMC로 통합, (2) 현대 관행 전반에 대한 광범위한 실증.

**⑥ 실험 설정 (4절)**
| 계열 | 크기 조절 |
|---|---|
| ResNet18 | 층 폭 $[k,2k,4k,8k]$, 표준 $k=64$ |
| 5층 CNN | 합성곱 4층 $[k,2k,4k,8k]$ + 완전연결, $k=64$면 증강 시 90% 이상 |
| 트랜스포머 | 6층 인코더–디코더, $d_{model}$, $d_{ff}=4d_{model}$ |
→ ai_life **03 CNN**: "폭 $k$"가 무엇인지(필터 수) 그림으로 그려 보자.

# p.5 해설 — 최적화 설정과 모델 방향 이중 하강

**② 레이블 잡음 $p$** — 확률 $1-p$로 정답, 아니면 **균등 무작위 오답**. 잡음은 **한 번만** 샘플(에폭마다 바뀌지 않음). 그림 1은 잡음 분포의 테스트 오차, 나머지는 깨끗한 분포 기준(서로 선형 변환 관계).

**③ 그림 4 ⭐** — (a) CIFAR-100: 잡음 **없이도** 정점. (b) CIFAR-10: 잡음 없으면 보간점 근처 **고원**, 잡음을 넣으면 **정점**으로.
→ 🔎 그림 4(b)의 잡음 0%, 10%, 20% 곡선을 비교해 정점 위치가 어디로 가는지 화살표로 표시.

**④ 5절 요지** — 끝까지 학습(고정된 큰 스텝 수)할 때 모델 크기를 키우면, 임계 영역에서 독특한 행동, 종종 잡음과 함께 두드러지는 **정점**.

**⑤ 보간 임계점을 오른쪽으로 미는 것들 ⭐** — 레이블 잡음 추가, **데이터 증강**, 표본 수 증가 → 정점도 **더 큰 모델 쪽**으로 이동. (적대적 학습에서도 강건 오차의 정점 — 부록 그림 26)

**⑥ 논의** — 메커니즘의 완전한 이해는 열린 문제. 하지만 **선형 모델**에서도 유사 현상이 이론적으로 분석됨 → 비슷한 메커니즘일 것.

**⑦ 직관 시작** — 보간 임계점 크기에서는 학습 데이터를 맞추는 모델이 **사실상 하나**뿐이고, 그 모델은 잡음에 매우 **민감**…

# p.6 해설 — 데이터 증강, SGD vs Adam, 그리고 직관

**① 그림 5** — 5층 CNN, CIFAR-10, (a) 증강 없음 (b) 증강 있음. 증강은 보간 임계점을 **오른쪽**으로 → 정점도 이동. SGD 50만 스텝.
→ ✍️ 데이터 증강은 왜 EMC를 바꾸는가? (같은 모델이 "외워야 할" 데이터가 사실상 많아진다)

**② 그림 6** — SGD vs Adam (CIFAR-10, 잡음·증강 없음). 둘 다 이중 하강, 정점 위치는 최적화기에 따라 다를 수 있음 → EMC가 **학습 절차에 의존**한다는 증거.

**③ 그림 7** — 잡음 없는 CIFAR-100 CNN에서도 **정점**.

**④ 직관 완성 ⭐⭐** — 임계점: 모델이 학습 데이터를 **겨우** 맞추므로, 약간의 잡음·오지정 레이블까지 맞추도록 강제하면 **전역 구조가 파괴**되어 테스트 오차가 크다. (부록 그림 28: 임계 영역에서 **앙상블**이 크게 도움 → 잡음 민감성의 증거)
과대 매개변수: 학습 데이터를 맞추는 모델이 **많아서**, SGD가 잡음을 **"외우면서(흡수하면서)"** 도 분포에서 잘 작동하는 모델을 찾는다.
→ 🔎 *"memorizes" (or "absorbs") the noise while still performing well* 에 밑줄.

**⑤ 선형 모델에서는 이론적으로 정당화** — 잡음 없이도(Mei & Montanari 2019) 일어나며, 참 분포 구조와 모델 계열 사이에 **오지정**이 있을 때마다…

→ ✍️ 지난주 Jacot(NTK)의 "무한 폭에서는 커널 회귀" 관점으로, 과대 매개변수 영역에서 SGD가 고르는 해는 어떤 성질(최소 노름?)을 가질지 생각해 보자.

# p.7 해설 — 트랜스포머와 에폭 방향 이중 하강

**① 그림 8** — 다중 헤드 어텐션 인코더–디코더 트랜스포머, 8만 스텝, 레이블 스무딩 교차 엔트로피. IWSLT'14 독→영(16만 문장), WMT'14 영→불(20만 문장으로 축소). 테스트 손실 = 토큰당 perplexity. → 잡음 없이도 모델 방향 정점.
→ ai_life **04 자연어처리**: 지난주 Vaswani(트랜스포머)와 연결.

**② 6절 에폭 방향 이중 하강 ⭐** — 학습 시간을 늘리면 **EMC가 증가** → 충분히 큰 모델은 학습 도중 과소 → 과대 매개변수로 **넘어간다**.

**③ 그림 9 ⭐⭐** — ResNet18, CIFAR-10, 20% 잡음, Adam, 증강. 세 영역:
| 모델 크기 | 에폭에 따른 테스트 오차 |
|---|---|
| 작은 모델 | 단조 감소 (끝까지 과소) |
| **중간** 모델 | 고전적 **U자** — 조기 종료가 유리 |
| 큰 모델 | **감소 → 증가 → 다시 감소** |
→ 🔎 그림 9 왼쪽의 세 곡선에 각각 "작음/중간/큼"을 적어 두자.

**④ 견고성** — 데이터셋·구조·최적화기·학습률 스케줄에 걸쳐 (부록 E.1). 잡음이 정점을 강조.

**⑤ 통념 수정** — 통념: (1) 일반화 격차가 작은 함수 학습 → (2) 과적합으로 테스트 오차 증가. 실제로는 어떤 영역에서 테스트 오차가 **다시 감소**하여 첫 최솟값보다 **더 낮아질** 수도 (그림 10, 10% 잡음).

# p.8 해설 — 에폭 방향 결과와 표본 비단조성

**① 그림 10** — 에폭 방향 이중 하강: (a) ResNet18 CIFAR-10 (b) ResNet18 CIFAR-100 (c) 5층 CNN CIFAR-10 (폭 128). ResNet은 Adam 0.0001, CNN은 SGD + 역제곱근 학습률.
→ ✍️ (a)에서 잡음 10% 곡선의 최종값이 첫 최솟값보다 낮은지 확인하자.

**② 7절 표본 비단조성** — 모델·절차 고정, 표본 수 $n$을 바꿈. 앞에서는 EMC를 바꿔 임계 영역을 탐색했다면, 이번엔 $n$을 바꿔서. $n$을 늘리면 같은 절차가 **과대 → 과소 매개변수**로 바뀔 수 있다.

**③ 두 효과 ⭐** — 표본을 늘리면 (테스트 오차 vs 복잡도 그래프에서)
1. 곡선 아래 **면적 감소** (예상대로)
2. 곡선이 **오른쪽으로 이동** — 정점이 더 큰 복잡도로
→ 🔎 *"shifting the curve to the right"* 에 밑줄.

**④ 그림 11(a)** — 5층 CNN, CIFAR-10: 위) 표본 **2배**가 테스트 오차를 개선하지 못하는 모델 크기 범위(초록), 아래) **4배**도 개선 못 하는 범위(빨강).
**그림 11(b)** — IWSLT'14 트랜스포머 두 크기: 표본을 늘리면 **손실이 커지는** 구간이 존재 (그림 3과 같은 설정).

→ ✍️ "곡선이 아래로 내려가면서 동시에 오른쪽으로 이동"하는 두 효과를 직접 그려 보고, 두 곡선이 **교차**하는 곳이 "더 많은 데이터가 해로운" 지점임을 표시해 보자.

# p.9 해설 — 표본 방향 정리와 결론

**① 두 효과의 상쇄** — 어떤 모델 크기 범위에선 효과가 **상쇄**되어 표본 **4배**가 도움이 안 됨(끝까지 학습 시). 충분히 작거나 큰 모델에선 표본이 도움.

**② 그림 12 ⭐** — 왼쪽: 5층 CNN, CIFAR-10 + 20% 잡음, (모델 크기 × 표본 수) 평면의 테스트 오차. **높은 오차의 능선**이 다시 **보간 임계점**을 따라 놓임. 오른쪽: 세 단면 — 작은/큰 모델은 데이터가 도움, **임계 근처**(초록)는 도움 안 됨.
→ 🔎 *the ridge of high test error again lies along the interpolation threshold* 에 밑줄.

**③ 더 많은 데이터가 해롭다** — 두 효과가 결합해 그런 영역이 생김 (그림 3, 11b). DNN만의 현상이 아님 — **선형 모델**에서도 (부록 D).

**④ 8절 결론 ⭐** — 일반화된 이중 하강 가설: EMC가 학습 표본 수와 **비슷할 때** 비정형적 행동. 현대 딥러닝에서 광범위한 증거. 모델 방향(큰 모델이 나쁜 영역 특정), **에폭 방향**(저자들이 아는 한 **최초 제안**), 더 많은 데이터가 해로운 영역. 정규화 양에 대해서도 이중 하강(그림 22).

**⑤ 실무자를 위한 사고법** — 모델과 절차가 학습 데이터를 **겨우** 맞출 수 있다면, 작은 변화(모델 약간 키우기/줄이기, 정규화 변경)가 **예상 밖의 행동**을 낳을 수 있다.

**⑥ 조기 종료** — 많은 현상이 **최적 조기 종료**에선 안 나타남 — 이는 가설과 일치(학습 오차 0에 도달하지 않으면 EMC가 $n$에 못 미침).

→ ✍️ ai_life 수업에서 "데이터를 더 모았는데 성능이 떨어졌다"는 학생 질문에 이 쪽을 근거로 답해 보자.

# p.10 해설 — 레이블 잡음, 다른 복잡도 개념

**① 조기 종료 (계속)** — 최적 조기 종료에서도 모델 방향 이중 하강이 일어나는 설정이 적어도 하나 있다(ResNet, CIFAR-100, 무잡음, 그림 19). 최적 조기 종료에서 "더 많은 데이터가 해로운" 경우는 관찰 못 했지만 불가능하다는 이유도 모름 → **열린 문제**.

**② 레이블 잡음 ≠ 본질 ⭐** — 본질은 **모델 오지정**. 사고 실험: 잡음이 진짜 무작위가 아니라 (분류기 계열에 대해) **의사난수**라면, 베이즈 최적 분류기 성능은 그대로(결정적·가역)인데 이중 하강은 똑같이 관찰될 것. → 잡음 추가는 분포를 **"더 어렵게"** 만드는 대리 수단.
→ 🔎 *merely a proxy for making distributions "harder"* 에 밑줄.

**③ 다른 복잡도와의 차이 ⭐** — EMC는 라데마허 복잡도와 관련되지만: (1) **실제 레이블**에 의존, (2) **학습 절차**에 의존.
- 라데마허·VC 차원은 레이블 분포에 무관 → 잡음이 정점을 옮기는 현상 설명 불가
- 모델 계열과 데이터 분포에만 의존 → **에폭 방향**, 데이터 증강 효과 설명 불가
→ ✍️ 지난주 Zhang 외(2017)가 "전통적 복잡도로는 일반화를 설명 못 한다"고 한 주장과 이 단락을 연결해 보자.

**④ 감사의 글** — Belkin과의 초기 논의, Chris Olah의 **(모델 크기 × 에폭)** 시각화 제안이 에폭 방향 이중 하강 발견으로 이어짐.

**⑤ 참고문헌 시작** — Advani & Saxe (2017), **Bartlett 외 (2019) "양성 과적합"**, **Belkin 외 (2018)** (지난주 논문의 arXiv판).

# p.15 해설 — B.3 기계 번역 설정, B.4 세부 사항

**① 번역에서의 분포** — 삼중쌍 $(x,y,i)$: 원문 문장 $x$, 번역 $y$, 예측할 토큰 위치 $i$ (균등분포).

**② 자기회귀 분해 ⭐**
$$p_M(y\mid x)=\prod_{i=1}^{|y|}p_M(y_i\mid y_{<i},x)$$
**학습 오차**:
$$\mathrm{Error}_S(M)=\frac1{|S|}\sum_{(x,y,i)\in S}-\log p_M(y_i\mid y_{<i},x)$$
→ 이것이 번역에서의 "학습 오차" — EMC 정의에 그대로 들어간다.
→ ai_life **04 자연어처리**: "다음 단어 예측"이 곧 확률의 곱이라는 점을 학생에게 보여 주기 좋은 식.

**③ 실제 구성** — 독립 표본이 아니라 $(x,y)$를 뽑고 모든 $(x,y,0..|y|)$를 포함.

**④ 학습** — Vaswani 외 5.3절 재현: **워밍업**(선형 증가) 후 역제곱근 감소. BPE 전처리, fairseq.

# p.17 해설 — 부록 D: 랜덤 특징 사례 연구

**① 그림 14 ⭐** — **랜덤 푸리에 특징**(Rahimi & Recht 2008), Fashion-MNIST. = 활성화 $e^{-ix}$인 **2층 신경망**, 첫 층은 무작위 초기화 후 **고정**, 둘째 층만 **경사 흐름**으로 학습.

**② 설정** — 첫 층 $\mathcal N(0,\frac1d)$ 초기화 후 고정, 폭(임베딩 차원) $d$가 모델 크기. 둘째 층은 0으로 초기화, **MSE 손실**.
→ 지난주 Jacot(NTK)의 "선형화된 신경망"과 같은 계열 — 둘째 층만 배우면 **선형 회귀**!

**③ 핵심 ⭐⭐** — 이 설정에선 **EMC = $d$** (임베딩 차원). 그래서 테스트 오차 정점이 정확히 **$n=d$ 직선**을 따라간다. 격자를 **가로**로 가로지르면 모델 방향, **세로**로 가로지르면 표본 방향 이중 하강.
→ 🔎 *EMC = d* 와 *the peak follows the path of n = d* 에 밑줄.

**④ 그림 15** — 표본 방향 단면 (특징 수 1,000개): 표본이 1,000 근처일 때 테스트 오차 **정점**.

**⑤ 의의** — 모델·표본 방향 이중 하강은 **딥러닝만의 현상이 아니다**.

→ ✍️ ai_life **01 선형회귀**로 직접 재현해 보자: 무작위 특징 $\cos(w_jx+b_j)$ $d$개로 점 $n=20$개를 최소제곱 적합(최소 노름 해)하고, $d=5,10,20,40,100$에서 테스트 오차를 그리면 $d=20$ 근처에서 정점이 보일 것이다.
