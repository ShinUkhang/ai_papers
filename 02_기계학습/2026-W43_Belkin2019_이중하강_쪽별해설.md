# p.1 해설 — 초록: 고전 이론과 현대 실무의 모순

**① 문제 제기** — 기계학습의 중심 원리인 **편향–분산 트레이드오프**가 현대 실무와 **모순**되어 보인다.
- 고전: 모델은 과소적합과 과적합 사이에서 균형을 잡아야 한다 — 데이터 구조를 표현할 만큼 풍부하되, 가짜 패턴을 맞추지 않을 만큼 단순하게.
- 현대: 신경망 같은 매우 풍부한 모델을 데이터에 **정확히 맞추도록(보간, interpolate)** 학습하는데도 테스트 정확도가 높다.
→ 🔎 *interpolate* 에 밑줄. 이 논문의 핵심 단어 = "훈련 데이터를 오차 0으로 통과".

**② 이 논문의 답 ⭐** — 고전 이해와 현대 실무를 **하나의 성능 곡선**으로 통합: **"이중 하강(double descent)"**. 교과서의 U자 곡선을 포함하면서, **보간점을 넘어 용량을 더 키우면 성능이 다시 좋아짐**을 보인다.

**③ 기여** — (a) 다양한 모델과 데이터셋에서 이중 하강의 **존재와 보편성**에 대한 증거, (b) 그 **발생 메커니즘** 제시, (c) 고전 분석의 **한계**를 밝힘.

**④ 저자** — 오하이오 주립대(Belkin, Ma, Mandal), 컬럼비아 대(Hsu). 이 PDF는 PNAS 게재 버전의 arXiv v2 (2019년 9월).

# p.2 해설 — 고전적 관점: U자 곡선

**① 문제 설정** — 표본 $(x_1,y_1),\dots,(x_n,y_n)\in\mathbb R^d\times\mathbb R$ 로 예측기 $h_n:\mathbb R^d\to\mathbb R$ 학습. **경험적 위험 최소화(ERM)**:
$$\min_{h\in\mathcal H}\ \frac1n\sum_{i=1}^n \ell(h(x_i),y_i)$$
손실: 제곱 $\ell(y',y) = (y'-y)^2$ 또는 0-1 손실.

**② 일반화의 핵심 긴장** — ERM의 목표(경험적 위험 최소화 = **최적화**)와 기계학습의 목표(**진짜 위험** $\mathbb E_{(x,y)\sim P}[\ell(h(x),y)]$ 최소화)의 **불일치**.

**③ 편향–분산의 통념**
1. $\mathcal H$가 너무 작으면 → **과소적합**: 경험적 위험이 크고 새 데이터에서도 나쁨
2. $\mathcal H$가 너무 크면 → **과적합**: 가짜 패턴까지 맞춤 (경험적 위험 작음, 진짜 위험 큼)
→ "스위트 스팟"을 찾아야 한다. 이것이 Figure 1(a)의 **U자 곡선**.

**④ 교과서의 따름정리** — "훈련 오차가 0인 모델은 과적합된 것이고 보통 일반화가 나쁘다" (Hastie 외, 『통계적 학습의 요소』 221쪽).
→ 🔎 이 인용문에 밑줄. 이 논문이 반박하는 대상!

**⑤ 현대 실무의 반례** — 큰 신경망은 훈련 위험 0에 가까워도 정확하다. 딥러닝의 모범 관행: 망은 **손쉽게 손실 0을 달성할 만큼 커야** 한다. 더구나 레이블에 **잡음이 많아도** 보간하는 신경망과 커널 기계가 거의 최적의 테스트 성능 (이번 주 Zhang 외 논문 인용 [42]).

**⑥ 주 발견** — Figure 1(b)의 이중 하강 곡선이 U자 곡선을 **보간점 너머로 확장**한다.

# p.3 해설 — Figure 1과 메커니즘 ⭐ 가장 중요한 쪽

**① Figure 1 ⭐ 논문의 전부가 이 그림에**
- 점선 = 훈련 위험, 실선 = 테스트 위험
- **(a)** 고전적 U자 곡선
- **(b)** 이중 하강: "고전" 영역(U자) + **보간 임계점** + "현대" 보간 영역
→ ✍️ 두 그림을 노트에 직접 그려 보세요.

**② 용량의 정의** — 이 논문에서 함수 클래스의 용량 = 함수를 지정하는 데 필요한 **파라미터 수**.

**③ 곡선 해석** — 보간 임계점 아래: 고전적 U자. 용량을 충분히 키우면 학습된 예측기가 훈련 데이터를 (거의) 완벽히 맞춤 = 보간. 임계점에서는 위험이 높지만, **그 너머로 용량을 늘리면 위험이 감소**하여 보통 고전 영역의 스위트 스팟보다 **낮아진다**.

**④ 왜? — 귀납적 편향 ⭐** — 임계점 오른쪽의 모든 예측기는 훈련 위험 0. 그런데 왜 더 풍부한 클래스가 더 좋은가? 클래스의 용량이 문제에 맞는 **귀납적 편향**을 반영하지 않기 때문. 적절한 귀납적 편향 = 어떤 함수 공간 노름으로 잰 **정칙성(매끄러움)**.
- 데이터를 완벽히 맞추는 함수 중 **가장 매끄러운 것**을 고르기 = **오컴의 면도날**
- 클래스가 클수록 후보가 많아져 **노름이 더 작은("더 단순한")** 보간 함수를 찾을 수 있다
→ 🔎 *Occam's razor* 에 밑줄.

**⑤ 관련 이론** — **마진 이론**: 큰 클래스가 더 큰 마진의 분류기를 허용. 하지만 회귀에는 적용 안 되고 두 번째 하강을 예측하지 못함. ERM 기반이 아닌 일부 보간 예측기는 통계적으로 (거의) 최적임이 증명됨.

# p.4 해설 — 무작위 푸리에 특징(RFF) 실험

**① RFF 모델** — 첫 층 가중치가 **고정된 2층 신경망**으로 볼 수 있는 모델 클래스. $N$개 (복소) 파라미터:
$$h(x) = \sum_{k=1}^N a_k\,\phi(x;v_k),\qquad \phi(x;v) = e^{\sqrt{-1}\langle v,x\rangle}$$
$v_1,\dots,v_N$ 은 표준 정규분포에서 독립 추출. $N\to\infty$ 이면 **가우시안 커널의 RKHS** $\mathcal H_\infty$ 에 점점 가까워진다.
→ 🔎 *Reproducing Kernel Hilbert Space* 에 밑줄. 커널 방법과 신경망의 연결고리.

**② 학습 절차** — 제곱 손실 ERM. 해가 유일하지 않을 때($N>n$ 이면 항상) 계수 $(a_1,\dots,a_N)$ 의 **$\ell_2$ 노름이 최소인 해**를 선택 (RKHS 노름 $\|h\|_{\mathcal H_\infty}$ 의 근사).

**③ Figure 2 결과 (다음 쪽)** — MNIST 부분집합에서 작은 $N$일 때 고전적 U자, **보간 임계점 $N=n$ 에서 정점**. 통계 분석은 $N\propto\sqrt n\log n$ 을 권장.

**④ 보간 영역 ($N\ge n$)** — 가장 적은 파라미터로 보간하는 $N=n$ 이 **가장 부정확** (분류에서는 예측력이 없을 정도). $N$을 더 늘리면 정확도가 **극적으로 개선**되어 U자 바닥을 넘어선다. 커널 기계 $h_{n,\infty}$ 가 모든 유한 $N$보다 좋다.

**⑤ 메커니즘 (시작)** — $N\ll n$ 이면 고전 통계 논리로 훈련 위험 ≈ 테스트 위험 → 특징 추가가 둘 다 개선. $N$이 $n$에 가까워지면...

# p.5 해설 — Figure 2: MNIST에서의 이중 하강

**① Figure 2 ⭐ 세 그래프를 위아래로 비교하세요**
- **위**: 테스트 위험 (로그 스케일, 0-1 손실과 제곱 손실)
- **가운데**: 계수의 $\ell_2$ 노름 (로그 스케일)
- **아래**: 훈련 위험
- 설정: MNIST 부분집합 $n = 10^4$, 10 클래스. **보간 임계점 $N = 10^4$**.

**② 읽는 법**
1. 아래 그래프에서 훈련 위험이 **0이 되는 지점** = 보간 임계점을 찾는다.
2. 같은 $N$에서 위 그래프의 테스트 위험이 **정점**인지 확인한다.
3. 가운데 그래프에서 노름도 **같은 곳에서 정점**이고, 오른쪽으로 갈수록 **감소**하는지 확인한다.
→ 🔎 "노름의 정점 = 테스트 위험의 정점" — 이것이 메커니즘의 증거.

**③ 수평선** — 커널 기계 $h_{n,\infty}$ (무한 특징)의 성능. 모든 유한 $N$의 곡선이 이 선 위에 있다 → 무한 폭 극한이 최선.
→ 이번 주 **NTK 논문**과 연결: 무한 폭 신경망 = 커널 기계!

**✍️ 직접 해보기** — Python으로 `np.linalg.pinv` (최소 노름 해)를 써서 특징 수 $N$을 $1$부터 $3n$까지 늘려 보세요. 이 그림을 재현할 수 있습니다.

# p.6 해설 — Figure 3과 두 번째 하강의 메커니즘

**① Figure 3 ⭐ 직관적인 1차원 예** — 데이터 10개(빨간 원)를 무작위 ReLU 특징 $\phi(x;(v_1,v_2)) = \max(v_1x+v_2,0)$ 으로 맞춤.
- $N = 40$ (파란 점선): 계수 노름 ≈ **695**, 구불구불
- $N = 4000$ (검은 실선): 계수 노름 ≈ **159**, 훨씬 매끄러움
→ 🔎 둘 다 10개 점을 **정확히 통과**하지만, 특징이 많을수록 더 매끄럽다.

**② 임계점의 정점 설명** — 임계점에 가까워지면 데이터에 없거나 약하게만 있는 특징들이 훈련 데이터를 **억지로** 거의 완벽히 맞추게 된다 → 고전적 과적합, 정점에서 가장 두드러짐.

**③ 두 번째 하강 설명 ⭐** — 임계점 오른쪽은 모두 훈련 위험 0. 가장 정칙적인 최소 노름 보간 함수 $h_{n,\infty}$ 가 유한 $\mathcal H_N$ 에 들어 있다는 보장은 없지만, $N$을 늘리면 그것에 **점점 더 가까운 근사**를 만들 수 있다. 따라서 노름은 임계점에서 최대이고 $N$과 함께 **단조 감소** → 두 번째 하강.
→ 수학적 직관: 임계점 $N=n$ 에서는 특징 행렬이 정사각에 가까워 **최소 특이값이 0에 가깝고**, 의사역행렬의 노름이 폭발한다.

**④ 추가 증거** — 부록 C.1(다른 데이터셋), 무작위 ReLU 특징, C.4(1차원 합성 모델) 모두 같은 이중 하강.

**⑤ 신경망과 역전파** — 일반 다층망에서는 SGD+역전파로 **모든 가중치**를 조정. 표현력은 커지지만 ERM이 더 어려워진다.

# p.7 해설 — 신경망에서의 이중 하강, 3절 트리 시작

**① 2층 신경망 (Figure 4)** — 완전연결 2층망의 파라미터를 늘리면 RFF와 질적으로 비슷한 곡선. 임계점 너머의 개선은 신경망 학습 알고리즘의 **"작은 노름" 귀납적 편향** 추측과 부합. 이전에도 관찰됨 — 특히 [37]은 입자계의 **"재밍(jamming)" 상전이**와 연결.

**② 신경망에서 관찰이 어려운 이유** — 과소 파라미터 영역($N\ll n$)에서는 ERM이 **비볼록**이라 SGD가 **초기화에 민감**. 최적이 아닌 해만 찾으면 망을 키워도 훈련 위험이 줄지 않을 수 있고, 이 변동성이 이중 하강을 **가린다**.

**③ 보간에 필요한 파라미터 수 ⭐** — 출력 하나면 최소 데이터 수만큼, 출력이 $K$개면 **$n\times K$** 개. 예: ImageNet ($\sim10^6$ 표본, $\sim10^3$ 클래스) → **$\sim10^9$ 파라미터**가 있어야 보간 → 당시 많은 ImageNet 모델보다 큼. 그런 경우엔 **고전 U자 영역**이 일반화를 이해하는 데 더 적절. 작은 데이터셋에서는 큰 망이 확실히 과대 파라미터 영역.
→ 🔎 *∼10^9 parameters* 에 밑줄. 이후 GPT 시대에 이 규모가 현실이 되었다!

**④ 3절: 결정 트리와 앙상블** — 이중 하강은 신경망 외에도 나타날까? **부스팅**과 **랜덤 포레스트**도 비슷한 행동. Wyner 외: 최대 크기(보간) 트리를 쓰는 AdaBoost와 랜덤 포레스트가 얕은 트리보다 **잡음에 강건**. 보간 트리들을 **평균**하면 개별 트리보다 훨씬 매끄러운 함수.

# p.8 해설 — Figure 4: 완전연결 신경망

**① Figure 4 ⭐** — MNIST 부분집합 ($n = 4\cdot10^3$, $d = 784$, $K = 10$), 은닉층 하나에 $H$개 유닛.
- 파라미터 수: $(d+1)\cdot H + (H+1)\cdot K$
- **보간 임계점** (검은 점선): $n\cdot K = 4\times10^4$
- 위: 테스트 위험(0-1, 제곱 손실), 아래: 훈련 위험

**② 계산 연습 ✍️** — $d=784$, $K=10$ 일 때 파라미터가 $n\cdot K = 40{,}000$ 이 되는 $H$는?
$$785H + 10(H+1) = 40000 \Rightarrow H\approx 50$$
→ 은닉 유닛 약 50개에서 정점. 그래프에서 확인해 보세요.

**③ 읽는 법** — RFF(Figure 2)와 모양을 비교하세요. 신경망은 모든 층을 학습하므로 더 복잡하지만, **같은 이중 하강 패턴**이 나타난다. 이것이 "보편성" 주장의 근거.

**④ 실험 세부 (부록 C.3)** — 과소 파라미터 영역에서는 **가중치 재사용**(작은 망의 가중치로 큰 망 초기화)으로 SGD의 초기화 민감성을 완화. 과대 파라미터 영역에서는 일반 무작위 초기화.

# p.9 해설 — Figure 5: 랜덤 포레스트

**① Figure 5 ⭐** — MNIST 부분집합 ($n = 10^4$, 10 클래스)에서 랜덤 포레스트의 이중 하강. 복잡도를 두 단계로 조절:
- **1단계 (임계점 전)**: 트리 하나의 **최대 잎 수** $N^{\max}_{\text{leaf}}$ 를 늘림
- **2단계 (임계점 후)**: 보간하는 트리의 **개수** $N_{\text{tree}}$ 를 늘림

**② x축 읽는 법** — 왼쪽 절반은 "잎 수 / 트리 1개", 오른쪽 절반은 "잎 수 최대 / 트리 여러 개". 두 종류의 용량을 하나의 축에 이어 붙인 **하이브리드 용량 척도**.

**③ 관찰** — 잎 수가 늘어나면 고전적 U자, 트리 하나가 데이터를 보간하는 지점에서 정점, 이후 트리를 더 많이 평균할수록 테스트 위험 **감소**.
→ 🔎 신경망이 아닌 모델에서도 같은 현상 → 이중 하강은 신경망만의 특성이 아니라 **기계학습 일반의 현상**.

**④ 귀납적 편향의 차이** — 신경망·RFF: **최소 노름**. 랜덤 포레스트: **평균화**. 다른 메커니즘이지만 둘 다 "보간하는 해 중 매끄러운 것"을 고른다.

# p.10 해설 — 트리의 용량, 4절 결론: 왜 지금까지 몰랐나

**① 트리의 용량** — 잎이 2개인 트리 = 축에 평행한 경계의 2조각 상수 함수, 잎이 $n$개 = $n$개 표본 보간 가능. 그 너머는 보간 트리 여러 개의 **앙상블(평균)** 로 용량을 늘림 (부트스트랩 재표본 없이 — PERT 방법과 유사). $L_2$ 부스팅에서도 같은 현상 (부록 E).

**② 결론** — 이중 하강 곡선은 편향–분산의 U자 곡선과 현대 실무를 **화해**시킨다. 메커니즘은 공통 귀납적 편향에 기반하므로 기계학습 전반에 **보편적**일 것이다.

**③ 역사적 부재: 왜 지금까지 못 봤나? ⭐ 과학사적으로 흥미로운 문단**
1. **고전 통계**: 작은 고정 특징 집합 → 용량 고정
2. **비모수 통계**: 풍부한 함수 클래스를 쓰지만 거의 항상 **평활화와 정규화** → 보간을 막고 정점을 가림
3. **RFF**: 원래 커널 기계의 **계산 대안**으로 제안 → 계산 이점은 $N\ll n$ 에서만 → 임계점 근처는 보통 안 봄
4. **신경망**: 정점이 **좁은 범위**에서만 나타나 놓치기 쉽고, **조기 종료**의 강한 정규화 효과가 정점을 가림
→ 🔎 *early stopping has a strong regularizing effect* 에 밑줄.

**④ 귀납적 편향 시작** — RFF·무작위 ReLU 특징은 특징 공간에서 **최소 노름 선형 회귀**로 해를 명시적으로 구성.

# p.11 해설 — 귀납적 편향과 최적화

**① RKHS의 최소 노름 해** — 특징 수 → ∞ 이면 RKHS의 **최소 함수 노름 해**에 접근: 보간 제약 아래 **함수의 매끄러움을 최대화**하는 해.

**② 신경망의 귀납적 편향** — 학습 절차(보통 SGD)에서 비롯. 마지막 층만 학습하면(RFF처럼) **0에서 시작한 SGD는 최소 노름 해로 수렴**. 일반 신경망은 완전히 이해되지 않았지만 비슷한 편향의 경험적·이론적 증거가 있음 ([20] 행렬 분해의 암묵적 정규화).

**③ 세 방법이 같은 해로 ⭐ 아름다운 사실** — 커널 기계에서는 다음 세 방법이 모두 **같은 최소 노름 해** $h_{n,\infty}$ 를 준다:
1. 명시적 노름 최소화 (선형 연립방정식 풀기)
2. SGD
3. 가우시안 과정 궤적의 평균 (사후 평균)
→ 🔎 최적화·확률·선형대수의 세 관점이 한 점에서 만난다.

**④ 최적화 관점** — 적절한 "현대" 모델이 보통 최적의 "고전" 모델보다 낫다. 게다가 과대 파라미터 모델은 **최적화도 쉽다**: SGD 같은 국소 방법이 훈련 위험의 **전역 최솟값**으로 수렴. 임계점 왼쪽과 오른쪽의 모델은 최적화 성질도 질적으로 다를 것.

**⑤ 전망** — 고전 U자 곡선은 모델 선택에 대한 우리의 시각을 형성해 왔다. 이 연구는 고전 분석의 한계를 보이고, 고전·현대 영역의 계산·통계·수학적 성질을 비교하는 새 연구 방향을 연다.

# p.14 해설 — 참고문헌 끝, 부록 A: 정리 1

**① 남은 참고문헌** — [36] Soltanolkotabi 외: 과대 파라미터 얕은 망의 최적화 지형, [37] Spigler 외: **재밍 전이**, [38] Vapnik, [40] Wendland 『산재 데이터 근사』(정리 증명에 사용), [41] Wyner 외: AdaBoost와 랜덤 포레스트를 보간 분류기로 설명, [42] **Zhang 외** (이번 주 함께 읽는 논문).

**② 부록 A: 잡음 없는 경우의 정리 ⭐** — 설정: $x_i$ 를 콤팩트 영역에서 균등 추출, $y_i = h^*(x_i)$, $h^*\in\mathcal H_\infty$ (잡음 없음).
> **정리 1.** 절대 상수 $A,B>0$ 가 있어, 데이터를 보간하는 임의의 $h\in\mathcal H_\infty$ 에 대해 높은 확률로
$$|h(x) - h^*(x)| < A\,e^{-B(n/\log n)^{1/d}}\big(\|h^*\|_{\mathcal H_\infty} + \|h\|_{\mathcal H_\infty}\big)$$

→ 🔎 오차 상한이 **$\|h\|$ 에 비례**한다! 그러므로 보간 함수 중 **노름이 작은 것**이 더 좋다.
→ 지수 $1/d$ 에 주목: 차원 $d$가 크면 수렴이 느려진다 (차원의 저주 — Cybenko 논문 p.313과 연결).

**③ 증명 스케치 시작** — 점들 $x_1,\dots,x_n$ 의 **채움 거리(fill)**:
$$\kappa_n = \max_{x\in\Omega}\ \min_{j}\ \|x - x_j\|$$
= 점들이 영역을 얼마나 잘 덮는가.

# p.15 해설 — 증명 마무리, 부록 B: 실험 설정

**① 증명 마무리** — 격자 분할과 합집합 상한으로 높은 확률로 $\kappa_n = O\big((\log n / n)^{1/d}\big)$. $f = h - h^*$ 로 두면 $f(x_i) = 0$ 이고 삼각부등식으로 $\|f\|\le\|h^*\|+\|h\|$. Wendland의 정리 11.22를 적용하면 결과. ∎

**② 해석 ⭐** — 최소 노름 보간 함수 $h_{n,\infty}$ 는 정의상 노름이 $\|h^*\|$ 이하이므로 **정리 1의 가장 작은 상한**을 달성한다. 잡음 없는 경우에만 적용되지만, **작은 노름을 고르는 귀납적 편향**의 정당화가 된다. 실험적으로는 레이블 잡음이 많아도 최소 노름 보간 해가 잘 일반화.

**③ 부록 B: 데이터셋**
| 데이터 | 종류 | 전처리 |
|---|---|---|
| MNIST, CIFAR-10, SVHN | 이미지 | 흑백 변환, $[0,1]$ 스케일 |
| TIMIT | 음성 | z-점수 정규화 |
| 20-Newsgroups | 텍스트 | BoW → GloVe 임베딩 합 |
다중 클래스는 **원-핫 인코딩**(일대다).

**④ 학습** — 모두 **제곱 손실** 최소화. 정규화 없이 용량이 임계점을 넘으면 보간. 신경망·앙상블은 5회 반복 평균, RFF·무작위 ReLU는 결과가 안정적이라 1회.
→ ai_life **05 음성인식** 단원과 연결: TIMIT은 대표적인 음성 데이터셋.

# p.19 해설 — C.2 ReLU 특징, C.3 완전연결 신경망

**① C.2 모델**
$$h(x) = \sum_{k=1}^N a_k\,\phi(x;v_k),\qquad \phi(x;v) = \max(\langle v,x\rangle,\ 0)$$
$v_k$ 는 **단위 구면 위의 균등분포**에서 추출, $a_k$ 는 선형 회귀로 학습. 결과 곡선과 노름 곡선이 RFF와 매우 비슷.

**② C.3 완전연결 신경망** — 은닉층 하나, **은닉 유닛 수**로 용량 조절, SGD로 ERM. RFF보다 어려운 이유: **해석적 해가 없고 비볼록** → SGD가 초기화에 민감.

**③ 가중치 재사용 기법 ⭐** — 과소 파라미터 영역($N<n$)에서: 은닉 유닛 $H_1$개인 작은 망을 먼저 학습 → $H_2>H_1$ 인 큰 망의 **처음 $H_1$개 유닛을 그 가중치로 초기화**, 나머지는 평균 0·분산 0.01 정규분포. → 파라미터가 늘 때 훈련 위험이 **단조 감소**하도록 보장. 과대 파라미터 영역에서는 일반 무작위 초기화.
→ 🔎 이번 주 ResNet 논문의 "깊은 망 = 얕은 망 + 항등 층" 사고 실험과 비슷한 발상!

**④ 학습 세부** — 모멘텀 0.95 SGD (Keras). 가장 작은 망은 Glorot 균등 초기화. 임계점 아래: 500 에폭마다 스텝 10% 감소, 분류 오류 0 또는 6000 에폭에서 멈춤. 임계점 위: 고정 스텝, 6000 에폭.

**⑤ 가중치 재사용 없이 (Figure 9c)** — 분산이 훨씬 크고 훈련 손실이 단조 감소하지 않지만 이중 하강은 **여전히 분명**.

**② C.4 1차원 합성 모델 ⭐ 수학적으로 가장 깔끔한 예** — 원 위의 RFF 버전. $[0,2\pi]$ 위의 주기 함수, 기저 $e_k(x) = e^{\sqrt{-1}kx}$.
- 양의 정수 위의 확률분포 $p$에서 서로 다른 지표 $k_1,\dots,k_N$ 을 뽑아 $\mathcal H_N = \mathrm{span}(e_{k_1},\dots,e_{k_N})$
- 데이터: $y_i = h^*(x_i) + \varepsilon_i$, $\varepsilon_i\sim N(0,\sigma^2)$, $x_i$ 는 $\{2\pi j/M\}$ ($M=4096$)에서 균등 추출
- $p_k \propto 1/k^2$ (낮은 진동수를 더 자주 뽑음)
- ERM = $N$차원 최소제곱. $N\ge n$ 이면 **최소 노름** 보간 함수 선택

**③ 결과 예고** — $n=256$ 에서 20회 반복 평균: 정점이 $N=n$, 오른쪽 끝이 U자 바닥보다 **낮음**, 노름도 $N=n$ 에서 정점 후 감소.

# p.22 해설 — Figure 12, 부록 D·E: 앙상블

**① Figure 12** — $L_2$-부스팅 트리의 이중 하강. 먼저 부스팅 트리 수 $N_{\text{tree}}$ 를 늘려 숲을 만들고, 그다음 그런 숲 여러 개 $N_{\text{forest}}$ 를 평균. 각 트리는 잎 **10개 이하**.

**② 부록 D: 랜덤 포레스트** — Breiman의 표준 랜덤 포레스트(회귀). 노드 분할 시 전체 특징 수의 **제곱근**만큼 무작위 선택. 트리 깊이 제한 없음. 보간을 위해 부트스트랩 끄기 (= Cutler 외의 "완벽한 무작위 트리 앙상블"). 제곱 손실과 0-1 손실 모두 이중 하강 (0-1 손실에서는 U자가 덜 뚜렷). 부트스트랩을 켜도 비슷.

**③ 부록 E: $L_2$-부스팅** — Friedman의 기울기 부스팅. 트리 수가 늘면 점차 보간, 낮은 축소율(0.85)로 빠르게 보간. 임계점을 넘기 위해 같은 하이퍼파라미터로 만든 **여러 숲의 예측을 평균**.
