# p.1 해설 — 초록과 서론: 무엇이 어려운가

**① 핵심 질문** — 연속 잠재변수의 **사후분포를 계산할 수 없고(intractable)**, 데이터가 **큰** 상황에서, 유향 확률 모델의 추론과 학습을 어떻게 효율적으로 할까?

**② 두 가지 기여 ⭐**
1. 변분 하한을 **재매개변수화**하면 표준 확률적 경사법으로 바로 최적화할 수 있는 하한 추정량이 나온다.
2. i.i.d. 데이터에서 데이터점마다 연속 잠재변수가 있으면, 계산 불가능한 사후분포에 **근사 추론 모델(인식 모델)** 을 맞춰 사후 추론을 특히 효율적으로 할 수 있다.
→ 🔎 *reparameterization of the variational lower bound* 에 밑줄.

**③ 서론** — 변분 베이즈(VB)는 계산 불가능한 사후분포의 **근사**를 최적화한다. 하지만 흔한 평균장(mean-field) 방법은 근사 사후분포에 대한 기댓값을 **해석적으로** 풀어야 해서 일반적으로는 불가능.
→ 이 논문의 **SGVB** (확률적 경사 변분 베이즈) 추정량은 미분 가능한 **불편 추정량**이라 거의 모든 연속 잠재변수 모델에 쓸 수 있다.

**④ AEVB와 VAE** — 데이터점마다 연속 잠재변수가 있는 경우의 알고리즘이 **AEVB** (자동 인코딩 VB). 데이터점마다 비싼 반복 추론(MCMC)이 필요 없다. 인식 모델로 **신경망**을 쓰면 = **변분 오토인코더(VAE)**.

**⑤ 2절 방법 시작** — i.i.d. 데이터, (전역) 파라미터는 최대우도(ML)·최대사후(MAP), 잠재변수는 변분 추론.

# p.2 해설 — Figure 1과 2.1 문제 상황

**① Figure 1 ⭐** — 실선: 생성 모델 $p_\theta(z)\,p_\theta(x|z)$. 점선: 계산 불가능한 사후분포 $p_\theta(z|x)$ 의 **변분 근사** $q_\phi(z|x)$. 변분 파라미터 $\phi$ 와 생성 파라미터 $\theta$ 를 **함께** 학습.
→ ✍️ 이 그림을 그리고 "$z\to x$ = 생성(디코더)", "$x\to z$ = 추론(인코더)" 라고 적어 두세요.

**② 데이터 생성 과정** — 관측 안 된 연속 확률변수 $z$:
1. 사전분포 $p_{\theta^*}(z)$ 에서 $z^{(i)}$ 생성
2. 조건부분포 $p_{\theta^*}(x|z)$ 에서 $x^{(i)}$ 생성
진짜 파라미터 $\theta^*$ 와 잠재변수 $z^{(i)}$ 는 **모른다**.

**③ 어려움 1: 계산 불가능성 ⭐**
- 주변 우도 $p_\theta(x) = \int p_\theta(z)\,p_\theta(x|z)\,dz$ 계산 불가
- 사후분포 $p_\theta(z|x) = p_\theta(x|z)p_\theta(z)/p_\theta(x)$ 계산 불가 → **EM 알고리즘 사용 불가**
- 평균장 VB의 적분도 불가
→ 예: $p_\theta(x|z)$ 가 비선형 은닉층이 있는 신경망이면 흔히 생기는 일.

**④ 어려움 2: 큰 데이터** — 배치 최적화는 너무 비싸다. 미니배치로 업데이트하고 싶다. 몬테카를로 EM은 데이터점마다 샘플링 루프가 있어 너무 느리다.

**⑤ 풀고 싶은 세 문제**
1. 파라미터 $\theta$ 의 효율적 근사 ML/MAP 추정 → 가짜 데이터 **생성**
2. 주어진 $x$에 대한 잠재변수 $z$ 의 근사 사후 추론 → **표현·부호화**
3. $x$ 의 근사 주변 추론 → 잡음 제거, 복원, 초해상도

# p.3 해설 — 2.2 변분 하한, 2.3 SGVB ⭐ 가장 중요한 쪽

**① 인식 모델** — $q_\phi(z|x)$: 진짜 사후분포의 근사. 평균장과 달리 **인수분해될 필요 없고**, 파라미터 $\phi$ 를 닫힌 형식 기댓값으로 계산하지 않고 $\theta$ 와 **함께 학습**.

**② 부호화 이론 관점** — $z$ = 잠재 **코드**. $q_\phi(z|x)$ = **확률적 인코더** ($x$ → 코드의 분포), $p_\theta(x|z)$ = **확률적 디코더** (코드 → $x$의 분포).

**③ 변분 하한 유도 ⭐ 반드시 손으로**
$$\log p_\theta(x^{(i)}) = D_{KL}\big(q_\phi(z|x^{(i)})\,\|\,p_\theta(z|x^{(i)})\big) + \mathcal L(\theta,\phi;x^{(i)}) \tag{1}$$
KL ≥ 0 이므로 $\mathcal L$ 은 **하한**:
$$\log p_\theta(x^{(i)}) \ge \mathcal L = \mathbb E_{q_\phi(z|x)}\big[-\log q_\phi(z|x) + \log p_\theta(x,z)\big] \tag{2}$$
$$\mathcal L = -D_{KL}\big(q_\phi(z|x^{(i)})\,\|\,p_\theta(z)\big) + \mathbb E_{q_\phi(z|x^{(i)})}\big[\log p_\theta(x^{(i)}|z)\big] \tag{3}$$
→ ✍️ (1)은 $\log p(x) = \mathbb E_q[\log p(x)]$ 에 $\frac{p(x,z)}{p(z|x)}$ 를 넣고 $q$ 를 곱하고 나눠서 유도됩니다.

**④ 순진한 경사 추정의 문제** — $\nabla_\phi\mathbb E_{q_\phi}[f(z)] = \mathbb E_{q_\phi}[f(z)\nabla_\phi\log q_\phi(z)]$ (점수 함수 추정량)는 **분산이 매우 커서** 실용성이 없다.
→ 🔎 *exhibits very high variance* 에 밑줄. 이것이 재매개변수화가 필요한 이유.

**⑤ 2.3 SGVB 추정량** — $z\sim q_\phi(z|x)$ 를 보조 잡음 $\epsilon$ 의 **미분 가능한 변환**으로:
$$z = g_\phi(\epsilon, x),\quad \epsilon\sim p(\epsilon) \tag{4}$$
$$\mathbb E_{q_\phi(z|x)}[f(z)] = \mathbb E_{p(\epsilon)}[f(g_\phi(\epsilon,x))] \simeq \frac1L\sum_{l=1}^L f(g_\phi(\epsilon^{(l)},x)) \tag{5}$$
식 (2)에 적용한 것이 일반 SGVB 추정량 $\tilde{\mathcal L}^A$ (식 6).

# p.4 해설 — Algorithm 1, 오토인코더와의 연결, 재매개변수화

**① Algorithm 1 (미니배치 AEVB)** — 반복: 미니배치 $M$개 추출 → 잡음 $\epsilon$ 추출 → 추정량의 경사 계산 → SGD나 **AdaGrad**로 $\theta,\phi$ 업데이트. 실험 설정 $M = 100$, $L = 1$.

**② 두 번째 추정량 $\tilde{\mathcal L}^B$ (식 7)** — 식 (3)의 KL 항은 보통 **해석적으로 적분 가능**(부록 B) → 재구성 오차만 샘플링:
$$\tilde{\mathcal L}^B = -D_{KL}\big(q_\phi(z|x^{(i)})\|p_\theta(z)\big) + \frac1L\sum_{l=1}^L\log p_\theta(x^{(i)}|z^{(i,l)})$$
보통 일반 추정량보다 **분산이 작다**. KL 항은 근사 사후분포를 사전분포 쪽으로 끌어당기는 **정규화**.

**③ 미니배치 추정 (식 8)** — 전체 $N$개에 대해 $\mathcal L(X) \simeq \frac NM\sum_{i=1}^M\tilde{\mathcal L}(x^{(i)})$. $M$이 충분히 크면(예: 100) 데이터점당 샘플 $L = 1$ 이면 충분.

**④ 오토인코더와의 연결 ⭐**
- 첫째 항 (KL) = **정규화**
- 둘째 항 = **음의 재구성 오차**: $x$ → (인코더) → $z$ 샘플 → (디코더) → $x$ 의 확률
→ 🔎 *negative reconstruction error in auto-encoder parlance* 에 밑줄. 확률 모델이 그대로 오토인코더가 된다!

**⑤ 2.4 재매개변수화 트릭** — 연속 확률변수 $z\sim q_\phi(z|x)$ 를 결정적 변수 $z = g_\phi(\epsilon,x)$ 로 표현 ($\epsilon$ 은 독립 보조 변수). 그러면 기댓값의 몬테카를로 추정이 **$\phi$ 에 대해 미분 가능**.
**증명**: 변수변환 $q_\phi(z|x)\prod_i dz_i = p(\epsilon)\prod_i d\epsilon_i$ 이므로
$$\int q_\phi(z|x)f(z)\,dz = \int p(\epsilon)f(g_\phi(\epsilon,x))\,d\epsilon$$

# p.5 해설 — 가우시안 예시와 3절 VAE

**① 1변수 가우시안 예 ⭐ 가장 쉬운 이해**
$z\sim N(\mu,\sigma^2)$ 이면 $z = \mu + \sigma\epsilon$, $\epsilon\sim N(0,1)$:
$$\mathbb E_{N(z;\mu,\sigma^2)}[f(z)] = \mathbb E_{N(\epsilon;0,1)}[f(\mu+\sigma\epsilon)] \simeq \frac1L\sum_l f(\mu+\sigma\epsilon^{(l)})$$
→ ✍️ 이제 $\frac{\partial}{\partial\mu}$, $\frac{\partial}{\partial\sigma}$ 를 **연쇄법칙**으로 바로 계산할 수 있습니다. 무작위성이 $\epsilon$ 으로 빠졌기 때문!

**② 재매개변수화가 가능한 분포들**
| 방법 | 원리 | 예 |
|---|---|---|
| 역누적분포함수 | $\epsilon\sim U(0,1)$, $g = F^{-1}$ | 지수, 코시, 로지스틱, 굼벨 등 |
| 위치–척도족 | $g = $ 위치 $+$ 척도 $\cdot\epsilon$ | 가우시안, 라플라스, 스튜던트 t 등 |
| 합성 | 보조 변수들의 변환 | 로그정규, 감마, 디리클레, 베타, 카이제곱 |

**③ 3절: 변분 오토인코더 ⭐**
- 사전분포: $p_\theta(z) = N(z;0,I)$ — 파라미터 없음
- 디코더 $p_\theta(x|z)$: 가우시안(실수 데이터) 또는 **베르누이**(이진 데이터), 파라미터는 MLP가 계산
- 인코더: 대각 공분산 가우시안
$$\log q_\phi(z|x^{(i)}) = \log N\big(z;\ \mu^{(i)},\ \sigma^{2(i)}I\big)$$
$\mu^{(i)}, \sigma^{(i)}$ 는 인코딩 MLP의 출력.

**④ 샘플링과 최종 추정량 (식 10)** — $z^{(i,l)} = \mu^{(i)} + \sigma^{(i)}\odot\epsilon^{(l)}$, $\epsilon^{(l)}\sim N(0,I)$:
$$\mathcal L \simeq \frac12\sum_{j=1}^J\Big(1 + \log(\sigma_j^{(i)})^2 - (\mu_j^{(i)})^2 - (\sigma_j^{(i)})^2\Big) + \frac1L\sum_{l=1}^L\log p_\theta(x^{(i)}|z^{(i,l)})$$
→ 🔎 이 식이 오늘날 VAE 코드의 **손실 함수 그 자체**입니다.

# p.6 해설 — 4절 관련 연구, 5절 실험 시작

**① 웨이크–슬립 알고리즘** — 같은 종류의 연속 잠재변수 모델에 쓸 수 있는 유일한 다른 온라인 방법. 인식 모델을 쓰는 점은 같지만, **두 목적함수를 동시에** 최적화해야 하고 그 조합이 주변 우도(의 하한)에 대응하지 않는다. 장점: 이산 잠재변수에도 적용 가능.

**② 확률적 변분 추론** — 순진한 경사 추정량의 분산을 줄이는 **제어 변량(control variate)** 기법들, 비슷한 재매개변수화를 쓴 연구 [SK13].

**③ PCA와의 연결 ⭐** — 선형 오토인코더와 선형–가우시안 생성 모델의 관계는 오래 알려졌다. [Row98]: **PCA** = 사전분포 $p(z) = N(0,I)$, $p(x|z) = N(x; Wz, \epsilon I)$ 에서 $\epsilon\to0$ 인 경우의 최대우도 해.
→ 🔎 VAE는 **비선형 확률적 PCA**로 볼 수 있다.

**④ 오토인코더 연구** — 정규화 없는 오토인코더의 학습 기준 = 입력과 잠재 표현 사이 **상호정보량**의 하한 최대화 (infomax). 하지만 재구성 기준만으로는 유용한 표현을 배우기에 **부족** → 잡음 제거·수축·희소 오토인코더 같은 정규화가 제안됨. SGVB는 변분 하한이 **정규화 항을 자동으로** 정해 주므로 별도의 정규화 하이퍼파라미터가 필요 없다.

**⑤ 독립적인 동시 연구** — [RMW14] Rezende, Mohamed, Wierstra도 같은 재매개변수화로 오토인코더와 변분 추론을 연결 (독립적으로 개발).

**⑥ 5절 실험** — MNIST와 Frey Face 데이터로 이미지 생성 모델 학습, 변분 하한과 추정 주변 우도로 비교. Frey Face는 연속값이라 가우시안 디코더 (평균은 시그모이드로 $(0,1)$ 제한).

# p.7 해설 — Figure 2와 실험 세부

**① Figure 2 ⭐** — AEVB vs 웨이크–슬립, 잠재 공간 차원 $N_z$ 별로 하한 최적화 비교. 세로축: 데이터점당 평균 변분 하한, 가로축: 평가한 학습 데이터 수.
- AEVB가 **훨씬 빨리 수렴**하고 **더 좋은 해**에 도달
- 흥미롭게도 잠재변수가 **많아도 과적합이 더 생기지 않음** → 하한의 **정규화 효과**
→ 🔎 *more latent variables does not result in more overfitting* 에 밑줄.

**② 계산 비용** — 인텔 제온 CPU 하나로 학습 데이터 100만 개당 약 20~40분.

**③ 학습 설정**
- 확률적 경사 **상승** (하한을 최대화하므로) + 작은 가중치 감쇠 = 사전분포 $p(\theta) = N(0,I)$ → 근사 MAP
- 모든 파라미터 $N(0, 0.01)$ 로 초기화
- 스텝 크기는 **AdaGrad** (전역 스텝 0.01, 0.02, 0.1 중 선택)
- $M = 100$, $L = 1$
→ 이 논문은 Adam 이전이라 AdaGrad를 썼다. 1년 뒤 같은 저자가 **Adam**을 만들어 VAE로 실험한다 (Adam 논문 Figure 4).

**④ 하한 실험** — 은닉 유닛: MNIST 500개, Frey Face 200개 (작은 데이터라 과적합 방지).

**⑤ 주변 우도 실험** — 잠재 차원이 아주 낮으면 MCMC로 주변 우도 추정 가능. 은닉 100개, 잠재변수 **3개**. AEVB, 웨이크–슬립, 몬테카를로 EM(MCEM, 해밀토니안 몬테카를로 샘플러) 비교.

# p.8 해설 — Figure 3, 6절 결론, 7절 향후 연구

**① Figure 3** — 추정 주변 우도 비교, 학습 데이터 수가 작을 때와 클 때. MCEM은 **온라인 알고리즘이 아니라** 전체 MNIST에 효율적으로 적용할 수 없다 (AEVB와 웨이크–슬립은 가능).

**② 고차원 데이터 시각화** — 잠재 공간을 **2차원**으로 하면 학습된 인코더로 고차원 데이터를 저차원 **다양체**에 사영할 수 있다 (부록 A, p.10).

**③ 6절 결론** — 변분 하한의 새 추정량 **SGVB**: 표준 확률적 경사법으로 바로 미분·최적화. i.i.d. 데이터와 데이터점별 연속 잠재변수에 대해 **AEVB** 알고리즘.

**④ 7절 향후 연구 ⭐ 모두 실현되었다**
1. 인코더·디코더에 **깊은 신경망(합성곱 망 등)** 을 쓴 계층적 생성 구조
2. 시계열 모델 (동적 베이즈 네트워크)
3. 전역 파라미터에 SGVB 적용
4. 잠재변수가 있는 지도학습 모델
→ 🔎 1번은 이후 **잠재 확산 모델(Stable Diffusion)** 의 VAE 인코더로 이어진다.

# p.10 해설 — Figure 4, 5와 부록 B: KL의 닫힌 형식 ⭐

**① Figure 4 ⭐ 유명한 그림** — 2차원 잠재 공간으로 학습한 (a) Frey Face, (b) MNIST 다양체. 사전분포가 가우시안이므로 단위 정사각형 위의 **등간격 좌표**를 가우시안의 **역누적분포함수**로 변환해 $z$ 값을 만들고, 각 $z$에 대한 $p_\theta(x|z)$ 를 그렸다.
→ 🔎 숫자가 한 모양에서 다른 모양으로 **연속적으로** 변하는 것 — 잠재 공간이 의미 있는 **연속 구조**를 가진다는 증거.

**② Figure 5** — 잠재 차원 2, 5, 10, 20 에서 학습한 MNIST 모델의 무작위 샘플. 차원이 커질수록 샘플이 더 다양하고 선명.

**③ 부록 B: $-D_{KL}$ 의 가우시안 해 ⭐ 직접 계산하기** — 사전분포 $N(0,I)$, 근사 사후분포 $N(\mu,\sigma^2)$, $z$의 차원 $J$:
$$\int q(z)\log p(z)\,dz = -\frac J2\log(2\pi) - \frac12\sum_{j=1}^J(\mu_j^2 + \sigma_j^2)$$
→ ✍️ 가우시안의 2차 모멘트 $\mathbb E[z^2] = \mu^2 + \sigma^2$ 만 알면 유도됩니다.

# p.11 해설 — 부록 B 마무리, C: MLP 인코더·디코더, D 시작

**① 부록 B 계속**
$$\int q(z)\log q(z)\,dz = -\frac J2\log(2\pi) - \frac12\sum_{j=1}^J(1 + \log\sigma_j^2)$$
두 식을 빼면
$$-D_{KL}\big(q\|p\big) = \frac12\sum_{j=1}^J\big(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\big)$$
→ 🔎 이 결과가 p.5 식 (10)의 첫 항. **샘플링 없이 정확히** 계산된다.

**② C.1 베르누이 MLP 디코더** — 이진 데이터용, 은닉층 하나:
$$\log p(x|z) = \sum_{i=1}^D x_i\log y_i + (1-x_i)\log(1-y_i),\quad y = f_\sigma\big(W_2\tanh(W_1z+b_1)+b_2\big)$$
→ = **이진 교차 엔트로피**. 로지스틱 회귀의 손실과 같다.

**③ C.2 가우시안 MLP** — 대각 공분산:
$$\log p(x|z) = \log N(x;\ \mu,\ \sigma^2 I),\quad \mu = W_4h + b_4,\ \log\sigma^2 = W_5h + b_5,\ h = \tanh(W_3z + b_3)$$
인코더로 쓸 때는 $z$와 $x$를 **바꾸고**, 가중치가 변분 파라미터 $\phi$ 가 됨.
→ 🔎 분산 대신 **$\log\sigma^2$** 를 출력하는 이유: 항상 양수가 되도록.

**④ 부록 D: 주변 우도 추정량** — 표본 공간 차원이 낮을 때(5 미만) 좋은 추정.

# p.12 해설 — 부록 D, E: MCEM, F: 완전 변분 베이즈 시작

**① 부록 D 주변 우도 추정 3단계**
1. 기울기 기반 MCMC(하이브리드 몬테카를로)로 사후분포에서 $z^{(l)}$ 샘플: $\nabla_z\log p_\theta(z|x) = \nabla_z\log p_\theta(z) + \nabla_z\log p_\theta(x|z)$
2. 샘플들에 밀도 추정량 $q(z)$ 를 맞춤
3. 새 샘플로 다음 추정량 계산:
$$p_\theta(x^{(i)}) \simeq \left(\frac1L\sum_{l=1}^L\frac{q(z^{(l)})}{p_\theta(z)\,p_\theta(x^{(i)}|z^{(l)})}\right)^{-1}$$
→ 조화 평균형 추정량. 왜 성립하는지 기댓값으로 확인해 보세요.

**② 부록 E: 몬테카를로 EM** — 인코더 없이 사후분포에서 직접 샘플링: HMC 도약(leapfrog) 10단계 (채택률 90%로 자동 조정) + 가중치 업데이트 5단계. 주변 우도는 학습·테스트 각 처음 1000개 데이터로, 데이터점마다 50개 샘플.

**③ 부록 F: 완전 변분 베이즈** — 잠재변수 $z$ 뿐 아니라 **파라미터 $\theta$ 에도** 변분 추론. 초사전분포 $p_\alpha(\theta)$:
$$\log p_\alpha(X) = D_{KL}\big(q_\phi(\theta)\|p_\alpha(\theta|X)\big) + \mathcal L(\phi;X) \tag{13}$$
$$\mathcal L(\phi;X) = \int q_\phi(\theta)\big(\log p_\theta(X) + \log p_\alpha(\theta) - \log q_\phi(\theta)\big)\,d\theta \tag{14}$$
→ 🔎 식 (1)과 **똑같은 구조**가 한 층 위에서 반복된다.

# p.13 해설 — 부록 F 계속: 두 층의 재매개변수화

**① 데이터점별 하한 (식 16)**
$$\mathcal L(\theta,\phi;x^{(i)}) = \int q_\phi(z|x)\big(\log p_\theta(x^{(i)}|z) + \log p_\theta(z) - \log q_\phi(z|x)\big)\,dz$$
세 개의 기댓값으로 나뉘고, 둘째·셋째는 가우시안이면 해석적으로 풀린다.

**② 두 가지 재매개변수화**
- 잠재변수: $z = g_\phi(\epsilon, x)$, $\epsilon\sim p(\epsilon)$ (식 17–18)
- 파라미터: $\theta = h_\phi(\zeta)$, $\zeta\sim p(\zeta)$ (식 19–20)

**③ 통합 함수 (식 21)**
$$f_\phi(x,z,\theta) = N\cdot\big(\log p_\theta(x|z) + \log p_\theta(z) - \log q_\phi(z|x)\big) + \log p_\alpha(\theta) - \log q_\phi(\theta)$$

**④ 몬테카를로 추정** — $\mathcal L(\phi;X) \simeq \frac1L\sum_l f_\phi\big(x^{(l)}, g_\phi(\epsilon^{(l)},x^{(l)}), h_\phi(\zeta^{(l)})\big)$. 추정량이 $\phi$ 와 무관한 $p(\epsilon)$, $p(\zeta)$ 의 샘플에만 의존하므로 **$\phi$ 에 대해 미분 가능**.
→ 🔎 재매개변수화의 핵심을 다시 한번: "무작위성을 파라미터와 **분리**한다."

**⑤ 가우시안 예 시작** — $p_\alpha(\theta) = N(0,I)$, $p_\theta(z) = N(0,I)$, 근사 사후분포는 대각 공분산 가우시안.

# p.14 해설 — Algorithm 2와 전체 정리

**① Algorithm 2** — 확률적 경사 계산: 데이터에서 $x$ 추출 → $\epsilon\sim p(\epsilon)$, $\zeta\sim p(\zeta)$ 추출 → $g \leftarrow \nabla_\phi f_\phi(x, g_\phi(\epsilon,x), h_\phi(\zeta))$.

**② 가우시안 재매개변수화**
$$\theta = \mu_\theta + \sigma_\theta\odot\zeta,\qquad z = \mu_z + \sigma_z\odot\epsilon,\qquad \zeta,\epsilon\sim N(0,I)$$
네 분포가 모두 가우시안이라 $f_\phi$ 의 **네 항을 해석적으로** 풀 수 있어 분산이 더 작은 추정량을 만들 수 있다 (p.11의 KL 공식이 두 번 쓰임).
