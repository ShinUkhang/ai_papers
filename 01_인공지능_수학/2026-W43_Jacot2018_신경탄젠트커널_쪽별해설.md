# p.1 해설 — 초록: 학습도 커널로 설명된다

**① 출발점** — 초기화 시점의 신경망은 **무한 폭 극한에서 가우시안 과정(GP)** 과 같다 → 커널 방법과 연결된다 (Neal 1996 등).

**② 주장 ⭐** — 학습 **도중**의 신경망 변화도 커널로 설명된다. 파라미터에 대해 경사하강을 하면, 네트워크 함수 $f_\theta$ 는 함수 공간의 비용(**볼록**!)에 대해 새 커널 = **신경 탄젠트 커널(NTK)** 방향의 **커널 경사**를 따른다.
→ 🔎 *which is convex, in contrast to the parameter cost* 에 밑줄. 파라미터 공간에서는 비볼록, 함수 공간에서는 볼록!

**③ 핵심 결과 요약**
- NTK는 초기화 때 무작위이고 학습 중에 변하지만, 무한 폭에서는 **명시적인 극한 커널로 수렴**하고 **학습 내내 일정**
- 학습의 수렴 ⟺ 극한 NTK의 **양정치성**. 데이터가 구 위에 있고 비선형 함수가 다항식이 아니면 양정치임을 증명
- 최소제곱 회귀: 무한 폭에서 $f_\theta$ 는 **선형 미분방정식**을 따른다. NTK에 대한 **커널 주성분** 방향일수록 빨리 수렴 → **조기 종료**의 이론적 동기
- 수치 실험으로 넓은 망이 극한에 가깝게 행동함을 확인

**④ 서론 시작** — 충분한 은닉 뉴런이 있으면 신경망은 어떤 함수든 근사할 수 있다(**보편 근사**, 이번 주 Cybenko!). 하지만 **최적화가 무엇으로 수렴하는지**는 모른다. 손실 곡면은 매우 비볼록하고 안장점이 많다. 충분히 넓은 망에는 "나쁜" 국소 최솟값이 적다는 결과들이 있다.

**⑤ 학회** — NeurIPS 2018, 몬트리올. 저자: EPFL(스위스 로잔 연방공대).

# p.2 해설 — 동기와 기여, 2절 신경망 설정

**① 일반화의 미스터리** — 신경망은 과대 파라미터화되어도 일반화를 잘한다. 무작위 레이블도 맞출 수 있으면서 진짜 데이터에서는 테스트 정확도가 좋다 — **이번 주 Zhang 외 논문** [23]. 커널 방법도 같은 성질을 가진다 — **Belkin 외** [1].
→ 🔎 이번 주 논문 세 편(Cybenko, Zhang, Belkin)이 모두 이 논문에서 만난다!

**② 네 가지 기여**
1. 경사하강 중 $f_\theta$ 는 극한 커널에 대한 **커널 경사하강**을 따른다. 그 커널은 **깊이, 비선형 함수, 초기화 분산에만** 의존.
2. 수렴 성질은 무한 폭 NTK의 **양정치성**과 연결. 학습 집합 밖에서의 $f_\theta$ 값도 NTK가 결정 → **일반화** 이해의 열쇠.
3. 최소제곱에서 $f_\theta$ 는 **선형 미분방정식**, 야코비안의 고유함수 = 입력 데이터의 **커널 주성분**.
4. 단위원 위의 인공 데이터와 MNIST로 수치 확인.

**③ 2절 설정** — 층 0(입력)부터 $L$(출력)까지, 뉴런 수 $n_0,\dots,n_L$. 비선형 함수 $\sigma$ 는 립시츠이고 두 번 미분 가능, 2계 도함수 유계.

**④ 실현 함수** — $F^{(L)}:\mathbb R^P\to\mathcal F$, 파라미터 $\theta$ → 함수 $f_\theta$. 파라미터 = 연결 행렬 $W^{(\ell)}\in\mathbb R^{n_\ell\times n_{\ell+1}}$, 편향 $b^{(\ell)}$. 모두 **i.i.d. $N(0,1)$** 로 초기화.

**⑤ 함수 공간의 내적** — 입력 분포 $p^{in}$ 에 대해
$$\langle f,g\rangle_{p^{in}} = \mathbb E_{x\sim p^{in}}\big[f(x)^\top g(x)\big]$$

# p.3 해설 — NTK 매개변수화와 3절 커널 경사

**① 유한 데이터** — $p^{in}$ = 데이터 $x_1,\dots,x_N$ 의 경험분포 $\frac1N\sum_i\delta_{x_i}$.

**② 신경망 정의 ⭐ NTK 매개변수화**
$$\tilde\alpha^{(\ell+1)}(x;\theta) = \frac{1}{\sqrt{n_\ell}}W^{(\ell)}\alpha^{(\ell)}(x;\theta) + \beta b^{(\ell)},\qquad \alpha^{(\ell)} = \sigma\big(\tilde\alpha^{(\ell)}\big)$$
$\tilde\alpha$ = 전활성(preactivation), $\alpha$ = 활성.

**③ 주의 1: 고전적 정의와의 차이** — 보통은 $\frac1{\sqrt{n_\ell}}$ 과 $\beta$ 가 없고 대신 가중치를 분산 $1/n_\ell$ (LeCun 초기화)로 초기화. **표현 가능한 함수 집합은 같지만**, 파라미터에 대한 **미분의 크기**가 달라진다. $\frac1{\sqrt{n_\ell}}$ 인수가 폭 → ∞ 일 때 **일관된 극한**을 얻는 열쇠. 부작용으로 연결 가중치의 영향이 줄어들어 $\beta$ 로 편향과 균형. 실험: $\beta = 0.1$, 학습률 1.0 (≈ 폭 100짜리 고전 망의 학습률 0.01).

**④ 비볼록 vs 볼록 ⭐** — 함수 공간의 비용 $C$ 가 볼록이어도 합성 비용 $C\circ F^{(L)}$ 은 파라미터 공간에서 매우 비볼록. 이 논문은 **함수 공간**에서 학습을 연구한다.

**⑤ 3절: 커널** — 다차원 커널 $K:\mathbb R^{n_0}\times\mathbb R^{n_0}\to\mathbb R^{n_L\times n_L}$, $K(x,x') = K(x',x)^\top$. 쌍선형 형식 $\langle f,g\rangle_K = \mathbb E_{x,x'}[f(x)^\top K(x,x')g(x')]$. **양정치**: $\|f\|_{p^{in}} > 0 \Rightarrow \|f\|_K > 0$.

**⑥ 쌍대 공간** — $\mathcal F^*$ = $\mu = \langle d,\cdot\rangle_{p^{in}}$ 꼴의 선형 형식들. 사상 $\Phi_K:\mathcal F^*\to\mathcal F$, $f_{\mu,i}(x) = \langle d, K_{i,\cdot}(x,\cdot)\rangle_{p^{in}}$.
→ 이번 주 Cybenko 논문의 **쌍대 공간** 개념이 여기서도 핵심 도구로 쓰인다.

# p.4 해설 — 커널 경사하강과 3.1 무작위 함수 근사

**① 커널 경사** — 비용의 함수 미분 $\partial^{in}_f C|_{f_0}\in\mathcal F^*$, 대응 원소 $d|_{f_0}$. **커널 경사** $\nabla_K C|_{f_0} = \Phi_K\big(\partial^{in}_f C|_{f_0}\big)$.
→ 🔎 비용은 데이터 위에서만 정의되지만, 커널 경사는 커널 덕분에 **데이터 밖의 $x$로 일반화**된다!

**② 커널 경사하강** — $\partial_t f(t) = -\nabla_K C|_{f(t)}$. 비용의 변화:
$$\partial_t C|_{f(t)} = -\big\langle d|_{f(t)},\ \nabla_K C|_{f(t)}\big\rangle_{p^{in}} = -\|d|_{f(t)}\|_K^2$$
→ $K$ 가 **양정치**이면 비용이 엄격히 감소 → 임계점 수렴 보장. 비용이 볼록이고 아래로 유계이면 **전역 최솟값**으로 수렴.

**③ 3.1 무작위 함수 근사 ⭐ 직관을 주는 장난감 모델** (Rahimi & Recht의 무작위 특징에서 영감 — Belkin 논문의 RFF!) — 공분산이 $K$ 인 분포에서 무작위 함수 $f^{(p)}$ 를 $P$개 뽑아 선형 매개변수화:
$$F^{lin}(\theta) = \frac{1}{\sqrt P}\sum_{p=1}^P\theta_p f^{(p)}$$

**④ 경사하강 = 커널 경사하강** — 파라미터 경사하강은 함수 공간에서 **탄젠트 커널**
$$\tilde K = \sum_{p=1}^P\partial_{\theta_p}F^{lin}(\theta)\otimes\partial_{\theta_p}F^{lin}(\theta) = \frac1P\sum_p f^{(p)}\otimes f^{(p)}$$
에 대한 커널 경사하강과 같다. $P\to\infty$ 이면 **큰수의 법칙**으로 $\tilde K\to K$.
→ ✍️ 연쇄법칙으로 $\partial_t F^{lin}(\theta(t)) = -\nabla_{\tilde K}C$ 를 직접 유도해 보세요.

# p.5 해설 — 4절 NTK 정의, 초기화 시 극한 ⭐

**① NTK 정의 ⭐ 이 논문의 주인공**
$$\partial_t f_{\theta(t)} = -\nabla_{\Theta^{(L)}}C|_{f_{\theta(t)}},\qquad \Theta^{(L)}(\theta) = \sum_{p=1}^P\partial_{\theta_p}F^{(L)}(\theta)\otimes\partial_{\theta_p}F^{(L)}(\theta)$$
→ 🔎 NTK = **"출력의 파라미터 기울기들의 내적"**. 두 입력 $x, x'$ 에서 기울기 벡터가 얼마나 같은 방향인가.

**② 어려움** — $F^{lin}$ 과 달리 $F^{(L)}$ 은 **비선형** → NTK가 $\theta$ 에 의존 → 초기화 때 무작위이고 학습 중 변한다.

**③ 명제 1: 초기화 시 가우시안 과정** — 립시츠 $\sigma$, $n_1,\dots,n_{L-1}\to\infty$ 이면 출력 $f_{\theta,k}$ 들은 공분산 $\Sigma^{(L)}$ 인 **i.i.d. 중심 가우시안 과정**으로 (분포) 수렴:
$$\Sigma^{(1)}(x,x') = \frac1{n_0}x^\top x' + \beta^2,\qquad \Sigma^{(L+1)}(x,x') = \mathbb E_{f\sim N(0,\Sigma^{(L)})}\big[\sigma(f(x))\sigma(f(x'))\big] + \beta^2$$

**④ 정리 1 ⭐ 첫 번째 핵심 결과** — 같은 극한에서 NTK $\Theta^{(L)}$ 은 **결정적 극한** $\Theta^{(L)}_\infty\otimes\mathrm{Id}_{n_L}$ 로 확률 수렴:
$$\Theta^{(1)}_\infty = \Sigma^{(1)},\qquad \Theta^{(L+1)}_\infty(x,x') = \Theta^{(L)}_\infty(x,x')\,\dot\Sigma^{(L+1)}(x,x') + \Sigma^{(L+1)}(x,x')$$
$$\dot\Sigma^{(L+1)}(x,x') = \mathbb E_{f\sim N(0,\Sigma^{(L)})}\big[\dot\sigma(f(x))\dot\sigma(f(x'))\big]$$
→ ✍️ 이 점화식을 노트에 옮겨 쓰세요. $\dot\sigma$ = $\sigma$ 의 도함수.

**⑤ 주의 3** — 라데마허 정리로 $\dot\sigma$ 는 측도 0인 집합 밖에서 정의됨. 극한 NTK는 **$\sigma$, 깊이, 초기화 분산**에만 의존.

# p.6 해설 — 정리 2: 학습 중 불변, 양정치성, 5절 시작

**① 일반화된 학습** — 파라미터가 $\partial_t\theta_p = \langle\partial_{\theta_p}F^{(L)}, d_t\rangle_{p^{in}}$ 를 따른다. 경사하강이면 $d_t = -d|_{f_\theta(t)}$. (GAN처럼 방향이 다른 망에서 올 수도 있음.) 가정: $\int_0^T\|d_t\|_{p^{in}}dt$ 가 확률적으로 유계.

**② 정리 2 ⭐ 두 번째 핵심 결과** — 폭 → ∞ 이면 $t\in[0,T]$ 에서 균등하게
$$\Theta^{(L)}(t)\to\Theta^{(L)}_\infty\otimes\mathrm{Id}_{n_L}$$
→ NTK가 학습 내내 **변하지 않는다**. 따라서
$$\partial_t f_{\theta(t)} = \Phi_{\Theta^{(L)}_\infty\otimes\mathrm{Id}}\big(\langle d_t,\cdot\rangle_{p^{in}}\big)$$

**③ 주의 4 ⭐ 깊은 통찰** — 넓을수록 **개별** 은닉 활성의 변화는 줄어든다. 하지만 **집단적** 변화는 의미 있다 → 아래층 파라미터도 학습한다. 정리 1 공식에서 둘째 항 $\Sigma^{(L+1)}$ = 마지막 층의 학습, 첫째 항 = **아래층들의 학습**.

**④ 양정치성** — 수렴은 양정치 커널에서 보장. 마지막 층 전활성들의 생성 공간이 $\mathcal F$ 에서 **조밀**해지면 양정치 — 보편 근사 정리(Hornik, Leshno 등)와 연결!

**⑤ 명제 2** — **다항식이 아닌** 립시츠 $\sigma$ 에 대해, 극한 NTK를 단위 구 $S^{n_0-1}$ 로 제한하면 **양정치** (증명: 부록 A.4).
→ 🔎 "다항식이 아니면" — Leshno 외(1993) 보편 근사 조건과 **같은 조건**!

**⑥ 5절 최소제곱 회귀** — $C(f) = \frac12\|f - f^*\|^2_{p^{in}}$. 학습 방향의 노름이 감소하므로 정리 1·2 적용 가능. 커널 경사하강: $\partial_t f_t = \Phi_K(\langle f^* - f_t,\cdot\rangle_{p^{in}})$.

# p.7 해설 — 선형 미분방정식의 해와 조기 종료 ⭐

**① 해** — 사상 $\Pi: f\mapsto\Phi_K(\langle f,\cdot\rangle_{p^{in}})$ 를 쓰면
$$f_t = f^* + e^{-t\Pi}(f_0 - f^*),\qquad e^{-t\Pi} = \sum_{k=0}^\infty\frac{(-t)^k}{k!}\Pi^k$$
$\Pi$ 가 고유함수 $f^{(i)}$, 고윳값 $\lambda_i$ 로 대각화되면 $e^{-t\Pi}$ 의 고윳값은 $e^{-t\lambda_i}$.
→ ✍️ 행렬 지수함수를 $2\times2$ 대각 행렬로 계산해 보세요.

**② 유한 데이터에서** — $\Pi(f)_k(x) = \frac1N\sum_i\sum_{k'}f_{k'}(x_i)K_{kk'}(x_i,x)$. 양의 고유함수는 최대 $Nn_L$ 개 = 데이터의 **커널 주성분**, 고윳값 = 그 성분이 설명하는 분산.

**③ 고유공간 분해**
$$f_t = f^* + \Delta^0_f + \sum_{i=1}^{Nn_L}e^{-t\lambda_i}\Delta^i_f$$

**④ 조기 종료의 이론적 근거 ⭐** — **큰 고윳값** 방향일수록 빨리 수렴. 조기 종료 = 가장 중요한 커널 주성분에 집중하고, 작은 고윳값 방향(보통 **잡음이 많은** 방향, 예: RBF 커널에서는 **고주파** 함수)은 맞추지 않는 것.
→ 🔎 *Early stopping hence focuses the convergence on the most relevant kernel principal components* 에 밑줄. Zhang 논문의 "암묵적 정규화"에 대한 하나의 답!

**⑤ 극한 $t\to\infty$** — $f_0$ 가 가우시안이면 $f_t$ 도 항상 가우시안. 그람 행렬이 가역이면
$$f_{\infty,k}(x) = \kappa_{x,k}^\top\tilde K^{-1}y^* + \big(f_0(x) - \kappa_{x,k}^\top\tilde K^{-1}y_0\big)$$
첫째 항(평균) = 가우시안 사전분포 아래 **MAP 추정** = 정규화 → 0인 **커널 릿지 회귀**. 둘째 항 = 데이터점에서 분산이 사라지는 중심 가우시안.
→ Belkin 논문의 **최소 노름 보간**과 같은 해!

**⑥ 6절 수치 실험 설정** — 모든 은닉층 폭 $n$ 동일, **ReLU**, $n_0 = 2$, 입력은 **단위원** 위 (고차원 데이터는 중심화하면 노름이 거의 같다 — 각주 2: $N(0,I)$ 에서 노름 ≈ $\sqrt{n_0}$), $n_L = 1$, $\beta = 0.1$.

# p.8 해설 — Figure 1, 2: 실험으로 확인하기

**① Figure 1 ⭐ NTK가 고정된 극한으로 수렴** — 깊이 $L = 4$, 폭 $n = 500$ vs $10000$. $x_0 = (1,0)$ 고정, $x = (\cos\gamma, \sin\gamma)$ 에 대해 $\Theta^{(4)}(x_0, x)$ 를 그림. 초기화 10번, $t = 0$ 과 200 스텝 후 (학습률 1.0, 목표 $f^*(x) = x_1x_2$).

- 두 폭의 NTK **기댓값은 매우 비슷**
- 200 스텝 후 NTK가 **"부풀어 오름"(inflate)** — 좁은 망($n=500$)에서 뚜렷, 넓은 망($n=10000$)에서는 거의 고정
→ 🔎 정리 2를 눈으로 보는 그림.

**② Figure 2** — 폭 $n = 50, 1000$, 각 10번 초기화, 단위원 위 **4개 점**으로 1000 스텝 학습. 큰 폭 망($n=10000$)으로 $\Theta^{(4)}_\infty$, $\Sigma^{(4)}$ 를 근사하여 $t\to\infty$ 극한 가우시안의 10, 50, 90 백분위수를 그림.
- 두 폭 모두 평균과 분산이 **극한 분포에 가까움**

**③ 6.3 주성분 방향의 수렴 (MNIST)** — $28\times28$ 이미지, $n_0 = 784$. $N = 512$ 개 숫자에 대해 폭 10000 망의 NTK로 첫 3개 주성분을 **거듭제곱 반복법**으로 계산: $\lambda_1 = 0.0457$, $\lambda_2 = 0.00108$, $\lambda_3 = 0.00078$. 중심화하지 않은 커널 PCA라 첫 성분은 거의 **상수 함수**.

# p.11 해설 — 참고문헌 끝, 부록 A 시작

**① 남은 참고문헌** — [17] Pascanu 외 (안장점), [18] Pennington & Bahri (무작위 행렬 이론으로 본 손실 곡면), [19] **Rahimi & Recht 무작위 특징** (3.1절, Belkin 논문의 RFF), [20] Sagun 외 (과대 파라미터 망의 헤시안), [21] Schölkopf 외 (**커널 PCA**), [22] Shawe-Taylor & Cristianini (커널 방법 교과서), [23] **Zhang 외 (이번 주 논문)**.

**② 부록 A: 증명 개요** — 명제 1, 정리 1·2를 증명. 극한을 **순차적으로** 취한다: 먼저 $n_1\to\infty$, 그다음 $n_2\to\infty$, ... → 증명이 훨씬 간단해짐. ($\min(n_1,\dots,n_{L-1})\to\infty$ 로 강화 가능할 것.)

**③ 커널의 작용소 노름**
$$\|K\|_{op} = \max_{\|f\|_{p^{in}}\le1}\Big(\mathbb E_{x,x'}\big[f(x)^\top K(x,x')f(x')\big]\Big)^{1/2}$$
유한 데이터에서는 $Nn_L\times Nn_L$ **그람 행렬의 최대 고윳값**. 따라서 작용소 노름 수렴 = 데이터 위 점별 수렴.

**④ A.1 초기화 시 점근 — 명제 1 증명 시작** — **귀납법**. $L = 1$ 이면 은닉층이 없고 $f_\theta$ 는 입력의 무작위 아핀 함수 → 공분산 $\Sigma^{(1)} = \frac1{n_0}x^\top x' + \beta^2$ 인 가우시안.

# p.12 해설 — 명제 1 증명, 정리 1 증명 시작

**① 명제 1 귀납 단계 ⭐** — $(L+1)$층 망 = $L$층 망 (입력 → 전활성 $\tilde\alpha^{(L)}$) + 비선형 $\sigma$ + 무작위 아핀 사상.
1. 귀납 가정: $\tilde\alpha^{(L)}_i$ 는 공분산 $\Sigma^{(L)}$ 인 i.i.d. 가우시안 과정
2. $\alpha^{(L)}$ 이 주어지면 출력은 조건부로 공분산 $\tilde\Sigma^{(L+1)} = \frac1{n_L}\alpha^{(L)}(x)^\top\alpha^{(L)}(x') + \beta^2$ 인 i.i.d. 가우시안
3. **큰수의 법칙**: $n_L\to\infty$ 이면 $\tilde\Sigma^{(L+1)}\to\Sigma^{(L+1)} = \mathbb E[\sigma(f(x))\sigma(f(x'))] + \beta^2$
4. 극한 공분산이 **결정적**이라 $\alpha^{(L)}$ 과 독립 → 조건부 분포 = 무조건부 분포 ∎
→ ✍️ "큰수의 법칙 + 조건부 가우시안" — 확률론의 기본 도구만으로 끝나는 우아한 증명.

**② 정리 1 증명 시작** — 역시 귀납법. $L = 1$: NTK는 $W^{(0)}$, $b^{(0)}$ 성분들의 합
$$\Theta^{(1)}_{kk'}(x,x') = \frac1{n_0}x^\top x'\delta_{kk'} + \beta^2\delta_{kk'} = \Sigma^{(1)}(x,x')\delta_{kk'}$$
→ 극한을 취할 필요 없음.

**③ 귀납 단계 설정** — 파라미터를 처음 $L$층의 $\tilde\theta$ 와 마지막 층 $(W^{(L)}, b^{(L)})$ 로 나눈다.

<div style="page-break-after: always"></div>

# p.13 해설 — 정리 1 증명 완료, A.2 학습 중 점근

**① NTK를 두 부분으로** — 아래층 파라미터 $\tilde\theta$ 의 기여 + 마지막 층 $W^{(L)}, b^{(L)}$ 의 기여.

**② 아래층 기여 (연쇄법칙)**
$$\partial_{\tilde\theta_p}f_{\theta,k}(x) = \frac1{\sqrt{n_L}}\sum_{i=1}^{n_L}\partial_{\tilde\theta_p}\tilde\alpha^{(L)}_i(x;\theta)\,\dot\sigma\big(\tilde\alpha^{(L)}_i(x;\theta)\big)W^{(L)}_{ik}$$
귀납 가정으로 $\frac1{n_L}\sum_i\Theta^{(L)}_\infty(x,x')\dot\sigma(\tilde\alpha_i(x))\dot\sigma(\tilde\alpha_i(x'))W^{(L)}_{ik}W^{(L)}_{ik'}$ 로 수렴 → 큰수의 법칙으로 $\Theta^{(L)}_\infty(x,x')\dot\Sigma^{(L+1)}(x,x')\delta_{kk'}$.

**③ 마지막 층 기여** → $\Sigma^{(L+1)}\delta_{kk'}$. 둘을 더하면 정리 1의 점화식 ∎
→ 🔎 점화식의 두 항이 **어디서 오는지** 이제 명확: 곱셈 항 = 아래층 (연쇄법칙의 $\dot\sigma$ 두 개), 덧셈 항 = 마지막 층.

**④ A.2 학습 중** — 학습 방향 $t\mapsto d_t$ 가 주어지면 파라미터는 i.i.d. $N(0,1)$ 로 시작해 $\partial_t\theta_p(t) = \langle\partial_{\theta_p}F^{(L)}(\theta(t)), d_t\rangle_{p^{in}}$ 를 따른다.

**⑤ 정리 2 재진술과 증명 시작** — 귀납법. $L = 1$ 이면 NTK가 파라미터에 의존하지 않으므로 **자명하게** 상수. 귀납 단계: $(L+1)$층 망을 $L$층 부분망 + 마지막 층으로 나누고, 부분망의 학습 방향이 확률적으로 유계임을 보여야 함 → $\|\frac1{\sqrt{n_L}}W^{(L)}(t)\|_{op}$ 를 유계로 해야 함.

# p.14 해설 — 보조정리 1과 그론월 부등식

**① 보조정리 1 ⭐** — 깊이 $L+1$ 망에서 모든 $\ell = 1,\dots,L$ 에 대해 확률 수렴:
$$\lim_{n_L\to\infty}\cdots\lim_{n_1\to\infty}\ \sup_{t\in[0,T]}\ \frac{1}{\sqrt{n_\ell}}\big\|W^{(\ell)}(t) - W^{(\ell)}(0)\big\|_{op} = 0$$
→ 🔎 가중치 행렬이 (정규화된 크기로) **거의 움직이지 않는다** = **"게으른 학습(lazy training)"** 의 수학적 진술.

**② 초기 가중치 유계** — 큰수의 법칙으로 $W^{(L)}(0)$ 의 각 행의 노름이 유계 → $\|\frac1{\sqrt{n_L}}W^{(L)}(0)\|_{op}$ 유계. 따라서 귀납 가정을 부분망에 적용 가능 → 부분망은 **상수 커널** $\Theta^{(L)}_\infty$ 로 학습.

**③ 마지막 층 가중치의 변화** — 코시–슈바르츠로 열 $W^{(L)}_i(t)$ 의 변화와 활성 $\alpha^{(L)}_i(t)$ 의 변화를 함께 상한하는 양 $A(t)$ 를 정의.

**④ 그론월 보조정리 ⭐ 미분방정식 부등식의 핵심 도구**
$$A(t) \le A(0)\exp\Big(\frac{\text{상수}}{\sqrt{n_L}}\int_0^t\|d_s\|_{p^{in}}ds\Big)$$
지수 안의 값이 $n_L\to\infty$ 이면 0으로 수렴 → $A(t)\to A(0)$. 활성과 가중치의 변화가 $O(1/\sqrt{n_L})$ 로 0에 수렴.
→ ✍️ 그론월 부등식: $u'(t)\le\beta(t)u(t)$ 이면 $u(t)\le u(0)\exp\int_0^t\beta$. 직접 증명해 보세요 ($\frac{d}{dt}[u e^{-\int\beta}]\le0$).

<div style="page-break-after: always"></div>

# p.15 해설 — 정리 2 증명 완료와 흥미로운 해석

**① NTK의 변화 통제** — 마지막 층 편향에 대한 미분은 상수 $\delta_{jj'}$. 연결 가중치에 대한 미분 $\frac1{\sqrt{n_L}}\alpha^{(L)}_i(x;\theta)\delta_{jj'}$ — 활성이 $O(1/\sqrt{n_L})$ 로 변하므로 이 기여는 $n_L^{-3/2}$ 속도로 변한다.

**② 아래층 기여** — 귀납 가정으로 부분망 NTK는 $\Theta^{(L)}_\infty$ 로 수렴. 남은 것은 $\dot\sigma(\tilde\alpha_i)W_{ij}$ 들이 $1/\sqrt{n_L}$ 속도로 변한다는 것 → $\ddot\sigma$ 가 유계이므로 성립 ∎

**③ 반직관적 결론 ⭐ 꼭 생각해 볼 문단** — 폭이 커지면 은닉층 활성 $\alpha^{(\ell)}$ 의 학습 중 변화가 **0으로 간다**. 보통 은닉층의 목적은 데이터의 **"좋은 표현"을 학습**하는 것이라고 여기는데! 하지만 개별 활성의 변화는 작아도 **뉴런 수가 늘어** 집단적 효과는 크다.
→ 🔎 *It is somewhat counterintuitive* 문단 전체에 표시.
→ ✍️ 비판적 질문: 그렇다면 NTK 영역에서는 **특징 학습(feature learning)** 이 일어나지 않는다. 실제 유한 폭 망이 커널 방법보다 나은 이유는? (힌트: 평균장 극한 [15], μP)

**④ 각주 4** — 결과적으로 전활성은 학습 중에도 **같은 공분산 $\Sigma^{(\ell)}$ 의 가우시안**으로 남는다.

# p.16 해설 — 보조정리 1 증명 (1)

**① 전략** — 모든 $\ell$ 에 대해 **동시에** 증명. 활성 $\alpha^{(\ell)}$ 의 변화를 아래층으로 **역전파된 학습 방향** $d^{(1)},\dots,d^{(L)}$ 과 부분망의 NTK로 표현.

**② 1단계: 층별 진화 방정식** — 전활성과 가중치의 시간 변화를 층별 학습 방향으로 쓴다. 층별 방향은 위층에서 아래층으로 점화식으로 정의 (= 역전파!). 부분망 NTK는
$$\Theta^{(\ell+1)} = \frac1{n_\ell}\dot\sigma(\cdot)W^{(\ell)\top}\Theta^{(\ell)}W^{(\ell)}\dot\sigma(\cdot) + \frac1{n_\ell}\alpha^{(\ell)}\otimes\alpha^{(\ell)} + \beta^2$$
꼴의 점화식을 만족.

**③ 2단계: 재귀적 상한** — 활성 크기 $a^{(\ell)}(t)$, 가중치 크기 $w^{(\ell)}(t)$, 립시츠 상수 $c$ 로
$$\|\Theta^{(1)}\|_{op}\le(a^{(0)}(t))^2 + \beta^2,\qquad \|\Theta^{(\ell+1)}\|_{op}\le c^2(w^{(\ell)}(t))^2\|\Theta^{(\ell)}\|_{op} + (a^{(\ell)}(t))^2 + \beta^2$$
→ 모든 부분망 NTK가 $a, w$ 들의 **다항식 $P$** 로 상한된다.

**④ 3단계 준비** — 변화량들의 합
$$A(t) = \sum_k a^{(k)}(0) + w^{(k)}(0) + \tilde a^{(k)}(t) + \tilde w^{(k)}(t)$$
를 통제하면 모든 것을 통제할 수 있다.

<div style="page-break-after: always"></div>

# p.17 해설 — 보조정리 1 증명 (2)과 A.4 시작

**① 3단계: $A(t)$ 의 미분 상한**
$$\partial_t A(t)\le\frac{1}{\sqrt{\min\{n_1,\dots,n_L\}}}\,Q\big(w^{(1)}(t),\dots,a^{(L)}(t)\big)\,\|d_t\|_{p^{in}}$$
$Q$ 는 양의 계수를 가진 다항식 → $A(t)$ 자신의 다항식으로 상한.

**② 4단계: 비선형 그론월** — $A(0)$ 은 극한에서 확률적으로 유계 ($w^{(\ell)}\to0$, $a^{(\ell)}$ 은 명제 1로 수렴). 비선형 그론월 보조정리 [8]로 $A(t)$ 는 $[0,\tau]$ 에서 균등 유계이고, 앞의 $\frac1{\sqrt{\min n}}$ 인수 덕분에 $\tau\to T$. 따라서 $\partial_tA\to0$ 균등 수렴, $A(t)\to A(0)$ ∎
→ 🔎 핵심 아이디어 한 줄: **"변화율이 $1/\sqrt{\text{폭}}$ 에 비례하므로 폭 → ∞ 이면 변화 없음."**

**③ A.4 극한 NTK의 양정치성** — 명제 2 증명.

**④ 보조정리 2 (Daniely 외 [4])** — 립시츠 함수 $\mu$ 의 **쌍대** $\hat\mu(\rho) = \mathbb E_{(X,Y)}[\mu(X)\mu(Y)]$, $(X,Y)$ 는 분산 1, 공분산 $\rho$ 인 중심 가우시안. $\mu$ 를 **에르미트 다항식** $h_i$ 로 전개 $\mu = \sum_i a_ih_i$ 하면
$$\hat\mu(\rho) = \sum_{i=0}^\infty a_i^2\rho^i$$
→ ✍️ 에르미트 다항식은 가우시안 가중치에 대한 **직교 다항식**. 확률론과 직교 함수의 만남.

# p.18 해설 — 쇤베르크 정리와 명제 2 증명

**① 정리 3 (쇤베르크 정리의 일반화, Gneiting [9])** — $f(\rho) = \sum_{n=0}^\infty b_n\rho^n$ ($b_n\ge0$) 에 대해 커널 $K(x,x') = f(x^\top x')$ 가 **모든 차원** $n_0\ge1$ 의 구 위에서 양정치 ⟺ $b_n$ 이 **무한히 많은 짝수 $n$** 과 **무한히 많은 홀수 $n$** 에서 엄격히 양수.
→ 🔎 구 위의 양정치 함수를 **거듭제곱급수 계수**로 판정하는 고전 정리.

**② 명제 2 증명**
1. **분해**: $\Theta^{(L+1)}_\infty = \dot\Sigma^{(L+1)}\Theta^{(L)}_\infty + \Sigma^{(L+1)}$. 첫째 항은 두 양반정치 커널의 곱이라 **양반정치** → $\Sigma^{(L+1)}$ 이 양정치면 $\Theta^{(L+1)}_\infty$ 도 양정치.
2. **위로 전파**: 계수 $c_i$ 와 서로 다른 점 $x_i$ 에 대해
$$\sum_{i,j}c_ic_j\Sigma^{(L+1)}(x_i,x_j) = \mathbb E\Big[\Big(\sum_i c_i\sigma(f(x_i))\Big)^2\Big] + \beta^2\Big(\sum_i c_i\Big)^2$$
$\Sigma^{(L)}$ 이 양정치면 가우시안 $(f(x_i))$ 가 비퇴화 → 좌변이 0이려면 모든 $c_i = 0$ ($\sigma$ 가 상수가 아니므로). 귀납으로 $\Sigma^{(2)}$ 의 양정치성만 보이면 충분.
3. **$\Sigma^{(2)}$ 로 환원**: 단위 구 위에서 변수변환하면 $\Sigma^{(2)}(x,x') = \hat\mu(x^\top x') + \beta^2$ 꼴 (보조정리 2의 쌍대).

# p.19 해설 — 증명 마무리와 전체 정리

**① 4단계** — $\mu$ 를 에르미트 다항식으로 전개. $\sigma$ 가 **다항식이 아니므로** $\mu$ 도 다항식이 아니고, **무한히 많은** 0 아닌 계수 $a_i$ 를 가진다.

**② 5단계** — $\Sigma^{(2)}(x,x') = \nu(x^\top x')$, $\nu(\rho) = \beta^2 + \sum_i a_i^2\rho^i$. $\nu$ 의 거듭제곱급수는 0 아닌 **짝수 항과 홀수 항을 무한히** 가진다 → 정리 3으로 $\Sigma^{(2)}$ 양정치 ∎

**③ 주의 5 (역)** — $\sigma$ 가 **다항식이면** 어떤 입력 차원에서 $\Theta^{(2)}$ 가 양정치가 **아니다**.
→ 🔎 "다항식 활성화는 왜 안 되는가?" — Cybenko·Leshno의 보편 근사 조건과 NTK의 수렴 조건이 **같은 이유**로 연결된다.
