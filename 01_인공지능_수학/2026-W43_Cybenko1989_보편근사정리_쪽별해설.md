# p.303 해설 — 초록과 서론: 문제 설정

> 스캔본이라 수식 기호가 흐릿합니다. 그리스 문자 대응: 원문의 $\sigma$(시그마) = 활성화 함수, $y_j$ = 가중치 벡터, $\theta_j$ = 편향, $\alpha_j$ = 출력 계수.

**① 초록** — 고정된 일변수 함수와 **아핀 범함수**($y^\top x + \theta$)의 합성들의 **유한 선형결합**이 단위 초입방체 위의 임의의 $n$변수 연속함수를 **균등하게 근사**할 수 있음을 보인다. 단층 은닉층 신경망의 표현 가능성에 대한 **열린 문제를 해결**. 특히 **임의의 결정 영역**도 근사 가능.
→ 🔎 *uniformly approximate any continuous function* 에 밑줄.

**② 식 (1) ⭐ 이 논문의 주인공**
$$\sum_{j=1}^{N}\alpha_j\,\sigma\!\left(y_j^\top x + \theta_j\right)$$
$y_j \in \mathbb R^n$, $\alpha_j, \theta_j \in \mathbb R$ 는 고정. = **은닉층 하나짜리 신경망**의 출력.

**③ 시그모이드의 정의**
$$\sigma(t) \to 1\ (t\to+\infty),\qquad \sigma(t)\to 0\ (t\to-\infty)$$
→ 단조 증가는 요구하지 않음에 주목!

**④ 주 결과 예고** — $\sigma$가 **연속 시그모이드**이면 (1) 꼴의 합들은 단위 정육면체 위 연속함수 공간에서 **조밀(dense)** 하다.

**⑤ 각주** — 1988년 10월 접수, 1989년 2월 수정. 저자 소속: 일리노이 대학 슈퍼컴퓨팅 연구개발센터.

# p.304 해설 — 배경: 왜 이 문제가 중요한가

**① 신경망 = 합성과 중첩** — 신경망은 단순한 비선형 함수 하나를 **합성(composition)** 하고 **중첩(superposition, 선형결합)** 한 것. 가장 단순한 비자명한 경우가 은닉층 하나 = 식 (1).

**② 응용과 질문** — 패턴 분류, 시계열 예측 등에서 원하는 응답을 내도록 합성을 고른다. 그렇다면 **신경망이 실현할 수 있는 함수의 집합은 무엇인가?**

**③ 공학적 비유 ⭐** — 디지털 신호처리의 기본 결과: **단위 지연 + 상수 곱셈기**로 만든 디지털 필터는 임의의 연속 전달함수를 근사한다. 이 논문은 신경망도 **같은 종류의 보편성**을 가짐을 보인다.

**④ 정확한 표현은 너무 큰 요구 — 콜모고로프 정리** — 힐베르트의 13번째 문제의 해결로, 콜모고로프는 모든 $n$변수 연속함수가 **일변수 함수들의 유한 합성·중첩으로 정확히 표현**됨을 보였다. 하지만 거기선 **서로 다른** 비선형 함수들이 쓰인다.
→ 🔎 *Kolmogorov* 와 *Hilbert's 13th problem* 에 밑줄. 신경망 이론의 숨은 뿌리!

**⑤ 이 논문의 입장** — **같은** 일변수 함수만 쓰고, 정확한 표현 대신 **근사**에 만족. 이렇게 보면 (1)은 **유한 푸리에 급수 근사의 일반화**.

**⑥ 증명 도구의 두 계열** — (a) 함수 대수 → **스톤–바이어슈트라스** 정리, (b) 평행이동 불변 부분공간 → **타우버 정리**. 이 논문은 둘 다 예시.

**⑦ 결정 영역 문제** — Nilsson은 $M$개 점을 임의의 두 부분집합으로 나누는 단층망이 존재함을 보였다. 일반 이론은 없었다.

# p.305 해설 — 관련 연구, 증명 전략, 2절 시작

**① 결정 영역** — Makhoul 외는 단층으로 **정확히** 만들 수 있는 결정 영역을 기하학적으로 분석. 이 논문은 $\mathbb R^n$의 **서로소인 콤팩트 집합들을 임의 정밀도로 구별**할 수 있음을 보인다 (정리 3).

**② 동시대 연구들**
| 연구 | 방법 |
|---|---|
| Hornik, Stinchcombe, White | **단조** 시그모이드의 완비성 |
| Carroll & Dickinson | **라돈 변환**으로 구성적 증명 |
| Jones | 유계 시그모이드의 구성적 증명 |
| Funahashi | 푸리에 해석, 페일리–위너 이론 |
| Cybenko (이전) | 은닉층 **2개**면 충분 |

**③ 증명 전략 요약 ⭐ 이 문단이 논문의 지도**
1. (1) 꼴의 유한합들은 연속함수 공간의 **부분공간**을 이룬다.
2. **한–바나흐 + 리스 표현 정리** → 이 부분공간을 **소멸시키는 유한 측도**가 존재.
3. 그 측도는 (1)의 **모든 항**도 소멸시켜야 하고, 이것이 $\sigma$에 대한 조건이 된다.
→ 🔎 *Hahn-Banach and Riesz Representation Theorems* 에 밑줄.

**④ 2절 기호**
- $I_n = [0,1]^n$, $C(I_n)$ = 연속함수 공간, $\|f\|$ = **상한(균등) 노름**
- $M(I_n)$ = 유한 **부호** 정칙 보렐 측도의 공간

**⑤ 목표** — $G(x) = \sum_j \alpha_j\sigma(y_j^\top x + \theta_j)$ 가 상한 노름에 대해 $C(I_n)$에서 조밀할 조건.

# p.306 해설 — 정의와 정리 1 ⭐ 가장 중요한 쪽

**① 정의: 판별적(discriminatory)** — 측도 $\mu \in M(I_n)$ 에 대해
$$\int_{I_n}\sigma(y^\top x + \theta)\,d\mu(x) = 0\quad \forall\, y\in\mathbb R^n,\ \theta\in\mathbb R \;\Longrightarrow\; \mu = 0$$
이면 $\sigma$를 **판별적**이라 한다.
→ 직관: $\sigma$로 만든 "탐침"들로 **모든 측도를 구별**할 수 있다.

**② 정리 1** — $\sigma$가 연속이고 판별적이면, $G(x)$ 꼴의 합들은 $C(I_n)$에서 조밀하다. 즉 $\forall f\in C(I_n),\ \forall\varepsilon>0$, $\exists G$:
$$|G(x) - f(x)| < \varepsilon\quad \forall x\in I_n$$

**③ 증명 ✍️ 한 줄씩 노트에 옮기기**
1. $S$ = $G$ 꼴 함수 전체 → $C(I_n)$의 **선형 부분공간**.
2. **귀류법**: $S$의 폐포 $R$이 전체가 아니라고 가정 → $R$은 닫힌 **진부분공간**.
3. **한–바나흐**: $L \ne 0$ 이지만 $L(R) = L(S) = 0$ 인 유계 선형범함수 $L$ 존재.
4. **리스 표현**: 어떤 $\mu\in M(I_n)$ 로 $L(h) = \int_{I_n} h\,d\mu$.
5. $\sigma(y^\top x+\theta) \in R$ 이므로 모든 $y,\theta$에 대해 $\int \sigma(y^\top x+\theta)\,d\mu = 0$.
6. $\sigma$가 판별적 → $\mu = 0$ → $L = 0$. **모순**. ∎

→ 🔎 3번과 4번이 핵심. "닫힌 진부분공간이면 그것을 죽이는 0 아닌 범함수가 있다"는 한–바나흐의 따름정리.

# p.307 해설 — 보조정리 1: 시그모이드는 판별적이다

**① 단조성 불필요** — 실제 신경망의 시그모이드는 보통 단조 증가이지만, 이 결과에는 **단조성이 필요 없다**.

**② 보조정리 1** — 유계·가측 시그모이드 함수는 판별적이다. 특히 연속 시그모이드는 판별적.

**③ 증명 1단계: 계단함수로의 극한 ⭐**
$\sigma_\lambda(x) = \sigma\big(\lambda(y^\top x+\theta)+\varphi\big)$ 에서 $\lambda\to+\infty$ 이면
$$\sigma_\lambda(x)\to\gamma(x) = \begin{cases}1 & y^\top x+\theta>0\\ 0 & y^\top x+\theta<0\\ \sigma(\varphi) & y^\top x+\theta=0\end{cases}$$
→ 시그모이드를 가파르게 하면 **반공간의 지시함수**가 된다! 그림을 그려 보세요.

**④ 2단계: 유계 수렴 정리** — $\Pi_{y,\theta}$ = 초평면 $\{y^\top x+\theta=0\}$, $H_{y,\theta}$ = 열린 반공간 $\{y^\top x+\theta>0\}$. 르베그 유계 수렴 정리로
$$0 = \int\sigma_\lambda\,d\mu \to \int\gamma\,d\mu = \sigma(\varphi)\,\mu(\Pi_{y,\theta}) + \mu(H_{y,\theta})$$

**⑤ 남은 과제** — "모든 반공간의 측도가 0 ⇒ $\mu=0$" 을 보여야 한다. $\mu$가 **양의 측도라면 자명**하지만, **부호 측도**라서 어렵다.
→ 🔎 *This would be trivial if μ were a positive measure but here it is not* 에 밑줄.

**⑥ 3단계 준비** — $y$를 고정하고 유계 가측함수 $h$에 대해 $F(h) = \int_{I_n} h(y^\top x)\,d\mu(x)$ 정의 → $L^\infty(\mathbb R)$ 위의 유계 선형범함수.

<div style="page-break-after: always"></div>

# p.308 해설 — 푸리에 변환으로 마무리, 정리 2

**① 3단계: 지시함수에서 단순함수로** — $h$ = 구간 $[\theta,\infty)$의 지시함수 → $F(h) = \mu(\Pi) + \mu(H) = 0$. 열린 구간도 마찬가지 → 선형성으로 **모든 구간의 지시함수**, 따라서 모든 **단순함수**에 대해 $F=0$. 단순함수는 $L^\infty$에서 조밀 → $F = 0$.

**② 4단계: 푸리에 변환 ⭐ 아름다운 마무리**
$h = \cos(m\cdot)$, $\sin(m\cdot)$ 를 넣으면
$$F(c + is) = \int_{I_n}\exp(i\,m^\top x)\,d\mu(x) = 0\quad\forall m$$
→ $\mu$의 **푸리에 변환이 0** → $\mu = 0$. 따라서 $\sigma$는 판별적. ∎
→ 🔎 푸리에 변환의 **단사성**이 결정적. 이 증명은 "근사 이론 = 조화 해석"임을 보여줌.

**③ 3절: 신경망에 적용** — 정리 1 + 보조정리 1 = **노드 수와 가중치 크기에 제한이 없다면**, 은닉층 하나 + 임의의 연속 시그모이드로 연속함수를 임의 정밀도로 근사.
→ 🔎 *no constraints are placed on the number of nodes or the size of the weights* — 이 단서가 정리의 한계.

**④ 정리 2 ⭐ (보편 근사 정리)** — $\sigma$가 연속 시그모이드이면 $G(x)=\sum_j\alpha_j\sigma(y_j^\top x+\theta_j)$ 들은 $C(I_n)$에서 조밀하다.

**⑤ 결정 함수** — $I_n$을 $k$개의 서로소 가측 집합 $P_1,\dots,P_k$로 분할하고 $f(x) = j \iff x\in P_j$ 로 정의 → **분류 문제**.

# p.309 해설 — 정리 3: 분류 문제

**① 정리 3** — 임의의 유한 가측 분할의 결정 함수 $f$와 $\varepsilon>0$ 에 대해, $G$와 집합 $D\subset I_n$ 이 존재하여
$$m(D) > 1-\varepsilon,\qquad |G(x)-f(x)|<\varepsilon\ \ (x\in D)$$
($m$ = 르베그 측도)

**② 증명 — 루진 정리 활용** — 루진 정리: 가측 함수는 **거의 모든 곳에서 연속함수와 같다**. 즉 연속 $h$와 $m(D)>1-\varepsilon$ 인 $D$가 있어 $D$ 위에서 $h=f$. 정리 2로 $|G-h|<\varepsilon$ 인 $G$를 찾으면 $D$ 위에서 $|G-f|<\varepsilon$. ∎
→ 🔎 *Lusin's theorem* 에 밑줄. 짧지만 강력한 증명.

**③ 해석** — 연속 함수로 불연속 결정을 하므로 **어떤 점들은 반드시 틀린다**. 하지만 틀린 점들의 **전체 측도**는 원하는 만큼 작게 할 수 있다. → 이런 종류로는 가장 강한 결과.

**④ 닫힌 집합 하나의 경우 (구성적 논의)** — $\Delta(x,D) = \min_{y\in D}|x-y|$ (거리 함수, 연속)로
$$f_\varepsilon(x) = \max\!\Big(0,\ \frac{\varepsilon - \Delta(x,D)}{\varepsilon}\Big)$$
를 만들면 $D$ 위에서 1, $D$에서 $\varepsilon$보다 먼 곳에서 0인 연속함수. $|G - f_\varepsilon|<\tfrac12$ 인 $G$로 판정하면, **$D$ 안의 점과 $D$에서 충분히 먼 점은 모두 정확히 분류**된다.
→ 정리 3은 "틀리는 양"을, 이 논의는 "틀리는 위치"(경계 근처)를 알려준다.

# p.310 해설 — 4절: 다른 활성화 함수 (1)

**① 불연속 시그모이드** — **계단 함수(hard limiter)**: $\sigma(x)=1\ (x>0)$, $0\ (x<0)$. 좋은 학습 알고리즘이 없어 잘 쓰이지 않지만, 고전적 **퍼셉트론**과 관련 있어 이론적으로 중요.
→ 역전파는 미분이 필요하므로 계단 함수는 학습이 어렵다. 이것이 **연속** 시그모이드가 쓰이는 실용적 이유.

**② 정리 4** — $\sigma$가 유계 가측 시그모이드이면 $G$ 꼴의 합들은 $L^1(I_n)$에서 조밀:
$$\|G-f\|_{L^1} = \int_{I_n}|G(x)-f(x)|\,dx < \varepsilon$$
증명은 정리 1·2와 같은 틀. 차이점: 연속함수 → 적분가능 함수, **$L^\infty$가 $L^1$의 쌍대공간**임을 사용.
→ 🔎 균등 수렴 대신 **$L^1$ 수렴** — 더 약한 의미의 근사.

**③ 판별성의 변형** — $h\in L^\infty$ 에 대해 $\int\sigma(y^\top x+\theta)h(x)\,dx=0\ \forall y,\theta \Rightarrow h=0$ a.e. $h(x)dx$ 꼴 측도가 $M(I_n)$에 속하므로 보조정리 1이 그대로 적용.

**④ 정리 5** — $L^1$ 수렴은 **측도 수렴**을 함의하므로 정리 3의 유사 결과가 일반 시그모이드에도 성립.

**⑤ 스톤–바이어슈트라스 예고** — 다른 활성화 함수들도 이 정리로 비슷한 성질을 보일 수 있다.

# p.311 해설 — 4절: 다른 활성화 함수 (2)

**① 스톤–바이어슈트라스로 되는 경우**
- **사인·코사인**: $\sin(mt), \cos(mt)$의 선형결합 = 삼각다항식 → $C(I_n)$에서 완비.
- **지수함수** $\exp(mt)$: 마찬가지 (Palm의 연구).
→ 🔎 보조정리 1에서 푸리에 변환의 단사성을 쓴 것이 사실 **삼각다항식의 완비성을 암묵적으로 사용**한 것이라는 지적.

**② 위너 타우버 정리로 되는 경우 ⭐** — $\sigma \in L^1(\mathbb R)$ 이고 $\int\sigma(t)\,dt \ne 0$ 이면 (1) 꼴의 합들은 $L^1$에서 조밀.
→ 시그모이드가 아니어도 된다! 예: 가우시안 모양의 "범프" 함수.

**③ 증명 스케치**
1. $F(g) = \int_{I_n} g(y^\top x)h(x)\,dx$ 정의.
2. $g_{\theta,s}(t) = \sigma(st+\theta)$ — $\sigma$의 **평행이동과 확대축소**. 가정에 의해 $F(g_{\theta,s})=0$.
3. 푸리에 변환: $\hat g_{\theta,s}(z) = e^{iz\theta/s}\hat\sigma(z/s)/s$. 확대축소 때문에 모두가 동시에 0이 될 수 있는 곳은 $z=0$뿐인데, $\hat\sigma(0)=\int\sigma\ne0$.
4. **위너 타우버 정리** → $g_{\theta,s}$들이 $L^1(\mathbb R)$에서 조밀 → $F=0$ → $h$의 푸리에 변환이 0 → $h=0$.

**④ 신기한 예시 시작** — $\sigma(x)$ = 축에 평행한 고정 직사각형의 지시함수, $U$ = 직교행렬 → $\sigma(Ux+y)$ = **임의로 회전·이동한 직사각형**.

# p.312 해설 — 직사각형 예시, 5절 요약, Table 1

**① 직사각형 활성화** — 크기 조정 없이 **강체 운동(회전+이동)만** 허용해도 $\sum_j\alpha_j\sigma(U_jx+y_j)$ 가 $L^1(\mathbb R^n)$에서 조밀. 이유: $\sigma$의 푸리에 변환이 원점을 포함하지 않는 **격자** 위에서만 0이고, 모든 회전의 격자들의 교집합은 **공집합**.
→ 🔎 고전적 **폼페이우 문제(Pompeiu problem)** 와 연결. 저자는 직사각형 대신 "모서리가 있는 임의의 볼록 집합"도 될 것이라 추측.

**② 5절 요약** — 판별적 일변수 함수의 유한 중첩은 단위 초입방체 위 연속함수를 균등 근사. 연속 시그모이드는 판별적. 따라서 **은닉층 하나 + 연속 시그모이드**로 임의의 연속함수를 근사(정리 2), 결정 함수도 근사(정리 3).

# p.313 해설 — 한계와 열린 문제 ⭐ 꼭 읽기

**① 존재성만 증명했다** — 이 결과들은 **존재성**에 관한 것. 남은 중요한 질문은 **실현 가능성**:
- 주어진 정확도에 **몇 개의 항(뉴런)** 이 필요한가?
- 근사할 함수의 **어떤 성질**이 필요한 뉴런 수를 결정하는가?

**② 저자의 예상** — 대부분의 근사 문제는 **천문학적인 수의 항**을 필요로 할 것이다. 근거: 다차원 근사 이론과 통계를 괴롭히는 **차원의 저주**.
→ 🔎 *astronomical numbers of terms* 와 *curse of dimensionality* 에 밑줄.
→ ✍️ 생각해볼 것: 그런데 실제 딥러닝은 고차원(이미지 수백만 차원)에서 잘 작동한다. 왜일까? (힌트: Barron 1993 — 함수의 푸리에 성질이 좋으면 뉴런 수가 차원에 덜 의존. 또 실제 데이터는 저차원 다양체 위에 있다.)

**③ 관련 연구** — Baum & Haussler(일반화를 위한 망 크기), Blumer 외(**VC 차원**), Valiant(**PAC 학습**). → 표현력에서 **학습 가능성**으로 넘어가는 다리.

**④ 참고문헌 시작** — [A] Ash 『실해석과 확률』: 이 논문에 쓰인 함수해석 도구의 출처.

| 핵심 용어 | 뜻 |
|---|---|
| existence vs feasibility | 존재성 vs 실현 가능성 |
| curse of dimensionality | 차원의 저주 |
