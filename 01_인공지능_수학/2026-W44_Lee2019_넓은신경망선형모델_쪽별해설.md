# p.1 해설 — 초록과 서론: 무한 폭이라는 극한

**① 초록 ⭐** — 딥러닝 연구의 오랜 목표: 학습과 일반화를 **정확히** 기술하기. 복잡한 손실 지형 때문에 어려웠다. 이 논문: **넓은** 신경망에선 학습 동역학이 크게 단순해지고, **무한 폭 극한**에선 초기 매개변수 주변의 **1차 테일러 전개**로 얻은 **선형 모델**이 지배한다.
→ 🔎 *governed by a linear model obtained from the first-order Taylor expansion* 에 밑줄.

**② 가우시안 과정 대응** — 넓은 베이즈 신경망 ↔ GP 대응처럼, 제곱 손실로 경사하강 학습한 넓은 신경망의 테스트 예측도 특정 **합성 커널**의 GP에서 뽑힌 것.

**③ 유한 폭에서도** — 이론은 무한 폭에서만 정확하지만, 실제 크기 신경망에서도 원래 신경망과 선형화 버전이 **매우 잘 일치**. 구조·최적화 방법·손실에 걸쳐 견고.

**④ 서론: 극한으로 단순화** — 물리학처럼 시스템의 **극한**을 보면 어려운 문제가 풀린다. 신경망의 극한 = **무한 폭**(완전연결층의 은닉 유닛 수, 합성곱층의 채널 수 → ∞).

**⑤ 알려진 사실** — 무한 폭에서 초기 출력은 **GP에서 뽑힌 표본**, 제곱 손실의 정확한 베이즈 학습 후에도 GP [4–8]. 실용적으로도 넓은 신경망이 더 잘 일반화.

**⑥ 이 논문** — 경사하강 아래 넓은 신경망의 학습 동역학: 가중치 공간 기술이 놀랍게 단순 — 폭이 커지면 신경망을 **초기값에서의 1차 테일러 전개**로 대체 가능 → 경사하강이 **해석적으로** 풀림.

→ ✍️ 지난주 Jacot 리뷰의 "lazy training" 💡 상자를 다시 읽고, 이 쪽의 주장과 같은 이야기임을 확인하자.

# p.2 해설 — 여섯 가지 기여와 관련 연구

**① 닫힌 해와 GP** — 제곱 손실이면 학습 동역학이 닫힌 해 → 예측 분포의 진화를 GP로 기술. "샘플 후 최적화" 사후 샘플링[12]의 딥러닝 확장. 서로 다른 초기화의 유한 폭 **앙상블** 예측 변동을 정확히 모델링.

**② 기여 목록 ⭐**
| 기여 | 내용 |
|---|---|
| 매개변수 공간 동역학 | 넓은 신경망 학습 = 모든 매개변수에 대해 **아핀**인 모델의 학습. 손실 무관. 제곱 손실이면 시간의 닫힌 함수 |
| 선형화 충분조건 | 임계 학습률 $\eta_{critical}$보다 작으면 궤적이 선형화 궤적의 $O(n^{-1/2})$ 근방에 머묾 (정리 2.1) |
| 출력 분포 동역학 | 무한 폭에서 학습 내내 예측이 GP (정리 2.2), Jacot[13] 확장. 경사하강은 **어떤 확률 모델의 사후분포도 아님** |
| 대규모 실험 | Wide ResNet 등 실제 구조에서 정확 |
| 매개변수화 독립 | 표준·NTK 매개변수화 모두 → 효과는 **폭 증가** 때문 |
| 해석적 커널 | ReLU, erf의 NTK 계산 |
→ 🔎 *gradient descent does not generate samples from the posterior of any probabilistic model* 에 밑줄.

**③ 코드** — Neural Tangents 라이브러리 + Colab 노트북 (가중치 공간·함수 공간 선형화).
→ ✍️ 각주의 Colab 노트북을 열어 실제로 돌려 보자 (무료).

**④ 관련 연구** — Jacot 외[13]: 함수 공간의 **커널 경사하강**(NTK). 이 논문은 실제 갱신이 일어나는 **매개변수 공간**에서의 함의를 본다. Daniely 외: 초기화 시 유한 폭 커널과 무한 폭 커널 차이 $O(1/\sqrt n)$. Saxe 외: **깊은 선형 신경망**(입력에 선형, 매개변수엔 비선형).

# p.3 해설 — 관련 연구(계속)와 설정

**① 대조 ⭐** — Saxe의 깊은 선형망은 **입력**에 선형, 이 논문의 넓은 신경망은 **매개변수 갱신**에 선형(입력엔 보통 비선형).
→ 🔎 이 대조 문장에 밑줄. 헷갈리기 쉬운 포인트!

**② 전역 수렴 연구** — Du 외, Allen-Zhu 외, Zou 외: 가우시안 초기화의 충분히 넓은 신경망은 SGD 중 매개변수가 초기값에서 **조금만** 움직인다 → 이 논문 효과의 핵심.

**③ 평균장(mean field) 연구** — Mei 외, Chizat & Bach 등: 매개변수 분포를 **PDE**로. 은닉층 1개, 스케일 $1/n$ (이 논문은 $1/\sqrt n$, 현대 신경망의 관례).
→ ✍️ $1/n$ vs $1/\sqrt n$ 스케일의 차이가 "특징 학습 vs 게으른 학습"을 가른다 — 다음에 읽을 μP 논문의 주제.

**④ Chizat 외 [28]** — 무한 폭 신경망은 **"게으른 학습"** 영역이라 실제 신경망에 적용하기엔 너무 단순할 수 있다고 주장. 이 논문은 그래도 실험적으로 잘 맞음을 보인다.

**⑤ 2.1 설정** — 학습 집합 $\mathcal D$, 입력 $\mathcal X$, 레이블 $\mathcal Y$. 은닉층 $L$개, 폭 $n_l$, 출력 $k$.

**⑥ 식 (1) NTK 매개변수화 ⭐**
$$\mathbf h^{l+1}=\mathbf x^lW^{l+1}+\mathbf b^{l+1},\ \ \mathbf x^{l+1}=\phi(\mathbf h^{l+1}),\ \ W^l_{ij}=\frac{\sigma_\omega}{\sqrt{n_l}}\omega^l_{ij},\ \ b^l_j=\sigma_b\beta^l_j$$
$\omega,\beta\sim\mathcal N(0,1)$이 학습 변수. 표준 매개변수화는 순전파만, NTK는 **역전파도** 정규화. 둘은 층별 학습률 배율만 다르다.

**⑦ 기호** — $\theta$ = 모든 매개변수 벡터, $f_t(x)\equiv\mathbf h^{L+1}(x)$ = 시각 $t$의 출력(로짓), 손실 $\mathcal L=\sum_{(x,y)\in\mathcal D}\ell(f_t(x,\theta),y)$ (평균 대신 **합**).

# p.4 해설 — 동역학, 선형화, 닫힌 해 ⭐⭐

**① 연속시간 경사하강 (식 2–3)**
$$\dot\theta_t=-\eta\nabla_\theta f_t(\mathcal X)^\top\nabla_{f_t(\mathcal X)}\mathcal L,\qquad\dot f_t(\mathcal X)=-\eta\hat\Theta_t\nabla_{f_t(\mathcal X)}\mathcal L$$
**식 (4)** 탄젠트 커널 $\hat\Theta_t=\nabla_\theta f_t(\mathcal X)\nabla_\theta f_t(\mathcal X)^\top=\sum_l\nabla_{\theta^l}f\,\nabla_{\theta^l}f^\top$ ($k|\mathcal D|\times k|\mathcal D|$). 유한 폭에선 초기화에 의존 → **경험적** 탄젠트 커널. 이산 경사하강은 $e^{-\eta\hat\Theta_0t}$ 를 $(1-\eta\hat\Theta_0)^i$ 로.

**② 식 (5) 선형화 ⭐**
$$f^{lin}_t(x)\equiv f_0(x)+\nabla_\theta f_0(x)|_{\theta=\theta_0}\,\omega_t,\qquad\omega_t\equiv\theta_t-\theta_0$$
→ 🔎 크게 밑줄. (초기 출력, 변하지 않음) + (학습 중 변화).

**③ 식 (6)–(7)** — $\nabla_\theta f_0$ 가 **고정** → 동역학이 단순. 커널이 $\hat\Theta_0$ 로 고정.

**④ MSE의 닫힌 해 (식 8–11) ⭐⭐**
$$\omega_t=-\nabla_\theta f_0(\mathcal X)^\top\hat\Theta_0^{-1}(I-e^{-\eta\hat\Theta_0t})(f_0(\mathcal X)-\mathcal Y)$$
$$f^{lin}_t(\mathcal X)=(I-e^{-\eta\hat\Theta_0t})\mathcal Y+e^{-\eta\hat\Theta_0t}f_0(\mathcal X)$$
임의의 점: $f^{lin}_t(x)=\mu_t(x)+\gamma_t(x)$, $\mu_t=\hat\Theta_0(x,\mathcal X)\hat\Theta_0^{-1}(I-e^{-\eta\hat\Theta_0t})\mathcal Y$.
→ **경사하강을 돌리지 않고** $\hat\Theta_0$, $f_0$만으로 전 과정 계산!
→ ✍️ 식 (9)를 유도하자: $\mathbf g=f^{lin}_t(\mathcal X)-\mathcal Y$ 라 두면 $\dot{\mathbf g}=-\eta\hat\Theta_0\mathbf g$ → $\mathbf g(t)=e^{-\eta\hat\Theta_0t}\mathbf g(0)$.

**⑤ 각주 7** — NTK 매개변수화에서 $\eta$는 관례보다 **폭 배** 큼 → 폭과 무관한 보편 학습률.

**⑥ 무한 폭 → GP 시작** — 중심극한정리로 초기 출력 $\{f_0(x)\}$가 다변량 가우시안으로 수렴.

# p.5 해설 — NNGP와 경사하강의 가우시안 과정

**① 왜 가우시안?** — 각 층의 사전활성화 = 가우시안 변수(가중치·편향)의 **합** → 폭이 크면 가우시안 (CLT). 무작위 초기화 신경망 ↔ **NNGP**.

**② 식 (12)–(13) ⭐**
$$K^{i,j}(x,x')=\lim_{\min n_l\to\infty}\mathbb E[f^i_0(x)f^j_0(x')],\qquad f_0(\mathcal X)\sim\mathcal N(0,K)$$
학습 데이터에 조건부:
$$\mu(x)=K(x,\mathcal X)K^{-1}\mathcal Y,\quad\Sigma(x)=K(x,x)-K(x,\mathcal X)K^{-1}K(x,\mathcal X)^\top$$
= 무한 폭 신경망의 **정확한 베이즈 추론** 결과.
→ 🔎 식 (13)에 밑줄 — 가우시안 과정 회귀의 표준 공식.

**③ 2.3.1 마지막 층만 학습** — $\theta^{\le L}$을 고정하고 $\theta^{L+1}$만 최적화하면 원래 신경망 = 선형화. 무한 폭에서 $\hat\Theta_0\to K$, $t\to\infty$에서 식 (10) → 식 (13) **사후분포**. = Matthews 외의 "샘플 후 최적화".

**④ 전체 학습** — $\hat\Theta_0\to\Theta$ (결정적 **해석적 커널**, 점화식으로 계산, ReLU·erf는 정확히). 식 (10)–(11)은 가우시안의 **아핀 변환** → 출력도 가우시안.

**⑤ 따름정리 1 ⭐** — 무한 폭에서 $f^{lin}_t(x)$는
$$\mu(\mathcal X_T)=\Theta(\mathcal X_T,\mathcal X)\Theta^{-1}(I-e^{-\eta\Theta t})\mathcal Y$$
와 식 (15)의 공분산을 갖는 가우시안. $t\to\infty$: 평균 $\Theta(\mathcal X_T,\mathcal X)\Theta^{-1}\mathcal Y$ (식 16).

**⑥ 해석** — 마지막 층만 학습할 때와 달리, 식 (14)–(15)는 **어떤 확률 모델의 사후분포로도 해석되지 않는다** (예외: NNGP 커널과 NTK가 상수배일 때, 예: 항등 활성화·편향 없음).

→ ✍️ NNGP($K$)와 NTK($\Theta$)를 한 줄씩 정의하고 차이를 적자: $K$=초기 출력의 공분산, $\Theta$=기울기의 내적.

# p.6 해설 — 그림 1과 정리 2.1·2.2

**① 그림 1 ⭐** — 은닉층 3개 ReLU, $\eta=1.0$, MNIST 부분집합($|\mathcal D|=128$), $T=2^{17}$ 스텝 후 상대 변화량 vs 폭 $n$:
- 입력·출력층 가중치: $\propto1/\sqrt n$ / 중간층 가중치: $\propto1/n$ (입출력 차원은 $n$과 함께 안 커지므로)
- $\hat\Theta$, $\hat K$의 변화: 상한 $O(1/\sqrt n)$, 실제로는 $O(1/n)$에 가까움
→ 🔎 그림의 두 기울기 선($1/\sqrt n$, $1/n$)에 표시. "넓을수록 가중치가 덜 움직인다"의 증거.

**② 정리 2.1 (비형식) ⭐⭐** — $n_1=\cdots=n_L=n$, $\lambda_{min}(\Theta)>0$, 학습률
$$\eta<\eta_{critical}:=\frac{2}{\lambda_{min}(\Theta)+\lambda_{max}(\Theta)}$$
이면 $\|x\|\le1$인 모든 $x$에 대해 높은 확률로
$$\sup_t\|f_t(x)-f^{lin}_t(x)\|_2,\ \sup_t\frac{\|\theta_t-\theta_0\|_2}{\sqrt n},\ \sup_t\|\hat\Theta_t-\hat\Theta_0\|_F=O(n^{-1/2})\quad(17)$$
→ ✍️ 2차 함수 $\frac12\lambda x^2$의 경사하강 수렴 조건 $\eta<2/\lambda$와 비교. $\eta_{critical}$은 왜 $\lambda_{max}$만이 아니라 $\lambda_{min}+\lambda_{max}$일까? (모든 고유방향에서 수축률 $|1-\eta\lambda|$를 균형 있게)

**③ 정리 2.2** — $\eta<\eta_{critical}$이면 $f_t(x)$가 식 (14)–(15)의 가우시안으로 분포수렴.

**④ 증명 두 단계** — (1) 과대 매개변수 신경망의 **전역 수렴** + NTK **안정성** (보충 G, Jacot보다 깔끔한 자체 증명), (2) **그론월형** 부등식으로 $f_t$와 $f^{lin}_t$의 차이를 $\|\hat\Theta_t-\hat\Theta_0\|_F$ 로 상계 (보충 H).

**⑤ 핵심 통찰 ⭐** — 개별 가중치 갱신은 무한 폭에서 **사라지지만**, 그것들이 **합심하여** 출력에 유한한 변화를 만든다.
→ 🔎 *they collectively conspire to provide a finite change* 에 밑줄.

# p.8 해설 — 그림 3: 유한 폭에서도 선형 모델과 일치

**① 그림 3 ⭐** — 이진 CIFAR, MSE, ReLU 완전연결 은닉층 5개, 폭 $n=2048$, $\eta=0.01$, $|\mathcal D|=256$. 네 칸: (1) 출력 동역학 (2) **개별 가중치** 동역학 (3) 학습·테스트 손실 (4) 두 모델의 테스트 RMSE. 경험적 커널 $\hat\Theta$가 더 정확.
→ 🔎 둘째 칸(개별 가중치까지 일치!)에 밑줄.

**② 예측 분포** — 앙상블의 평균·분산이 식 (14)–(15)를 잘 따름. NNGP(정확한 베이즈)는 비슷하지만 경사하강 학습 끝의 분포와 **눈에 띄게 다름**.

**③ 왜 경험적 커널이 더 정확한가 ⭐**
$$\|\hat\Theta^{(n)}_T-\hat\Theta^{(n)}_0\|_F=O(1/n)\ \le\ O(1/\sqrt n)=\|\hat\Theta^{(n)}_0-\Theta\|_F$$
학습 중 커널 **변화**보다 초기 커널의 무한 폭 커널로부터의 **편차**가 더 크다.

**④ 선형 모델을 직접 최적화** — ODE를 푸는 대신 $f^{lin}$의 매개변수를 직접 학습: 미니배치, 가중치 감쇠, 데이터 증강 그대로 적용 가능. 전체 MNIST(5만), 교차 엔트로피, 모멘텀(그림 S3).

**⑤ 교차 엔트로피 주의** — 소프트맥스 로짓은 후반에 **무한히 커짐**(MSE는 목표값에 수렴) → 초반에 두 모델이 많이 벌어지면 후반 오차가 커짐(그림 S4).

**⑥ Wide ResNet** — 합성곱·배치 정규화·건너뛰기 연결·평균 풀링. 블록 구조를 약간 바꿔 채널 수를 **1024**로 일정하게, MSE + SGD 모멘텀, 전체 CIFAR-10 → 강한 일치 (그림 4).

# p.9 해설 — 그림 4, 데이터 크기, 논의

**① 그림 4 ⭐** — Wide ResNet과 선형화가 SGD+모멘텀, MSE, CIFAR-10에서 비슷하게 행동. $N=1$, 채널 1024, $\eta=1.0$, $\beta=0.9$, $k=10$, 배치 8, **전체 5만 장**. 출력, 손실, **정확도 곡선**까지 일치.

**② 데이터 크기 효과** — 폭이 무한하고 데이터가 **유한**할 때 일치. 폭↑ → 오차↓, 데이터↑ → 오차↑ (그림 S5). 데이터가 늘면 모델도 키워 상쇄 가능.

**③ 4절 논의 ⭐** — 무한 폭에서 깊은 비선형 신경망의 매개변수 공간 동역학이 선형 모델로 **정확히** 기술됨. 완전연결·합성곱·Wide ResNet, 경사하강·모멘텀·미니배치, MSE·교차 엔트로피에서 실험과 일치. "놀랍도록 많은 실제 신경망이 이 영역에서 작동할지도". (층을 **재초기화**엔 강하지만 **재무작위화**엔 약하다는 Zhang 외[43]와 일치)

**④ 미래 방향** — 동역학이 커널 $\hat\Theta$와 목표 신호로 완전히 결정되므로, $\hat\Theta$의 성질로 **학습 가능성과 일반화**를 연구. $K$와 $\Theta$로 경사하강의 **귀납적 편향** 이해.

**⑤ 한계 ⭐** — 현대 신경망의 어떤 층은 선형화 영역에서 **멀리** 있을 수 있다. 유한 vs 무한 폭 성능 비교는 **구조 의존적**: 완전연결은 무한 폭이 비슷하거나 더 좋지만, **풀링 없는 CNN**은 반대. 무엇이 격차를 결정하는지는 열린 문제.
→ 🔎 *Some layers of modern neural networks may be operating far from the linearized regime* 에 밑줄.

# p.16 해설 — 보충 B: 모멘텀의 연속 극한, 교차 엔트로피, C: ReLU 커널

**① 연속시간 모멘텀 (S3–S4)** — Qian, Su 외처럼 $t=i\sqrt\eta$, $\tilde\beta=(\beta-1)/\sqrt\eta$ 로 연속 극한 → **2계** 미분방정식. MSE면 해석적 처리 가능.

**② B.2 다차원 출력·교차 엔트로피** — 닫힌 해는 없지만 **초기값 문제**로 ODE 풀이 가능.
$$\ell(f,y)=-\sum_iy^i\log\sigma(f^i),\quad\sigma(f^i)=\frac{e^{f^i}}{\sum_je^{f^j}},\quad\frac{\partial\ell}{\partial\hat y^i}=\sigma(\hat y^i)-y^i$$
$$\dot f_t(\mathcal X)=-\eta\hat\Theta_t(\mathcal X,\mathcal X)\big(\sigma(f_t(\mathcal X))-\mathcal Y\big)\quad(S8)$$
선형화는 $\hat\Theta_t\to\hat\Theta_0$ (S10–S11). dopri5 적분기 사용.
→ ✍️ 소프트맥스 교차 엔트로피의 기울기가 "예측 확률 − 정답"으로 깔끔하다는 것을 직접 유도해 보자.

**③ 보충 C: ReLU의 NTK ⭐** — Cho & Saul의 공식:
$$k_n(x,y)=\frac1\pi\|x\|^n\|y\|^nJ_n(\theta),\quad\theta=\arccos\frac{x\cdot y}{\|x\|\|y\|}$$
$$J_0(\theta)=\pi-\theta,\qquad J_1(\theta)=\sin\theta+(\pi-\theta)\cos\theta$$
→ 🔎 $J_0$, $J_1$에 밑줄 — "arc-cosine 커널". 두 입력 사이 **각도**만으로 커널이 결정됨.

<div style="page-break-after: always"></div>

# p.17 해설 — ReLU·erf 커널, 보충 D: 마지막 층만 학습

**① ReLU (S14–S15)** — $u=(x\cdot w,y\cdot w)$가 공분산 $\Sigma$의 가우시안일 때
$$\mathcal T(\Sigma)=\frac{1}{2\pi}\|x\|\|y\|J_1(\theta),\qquad\dot{\mathcal T}(\Sigma)=\frac1{2\pi}J_0(\theta)$$
(원문 식의 상수 계수를 직접 확인하자.)

**② erf (S16–S17)** — Williams(1997):
$$\mathcal T(\Sigma)=\frac2\pi\sin^{-1}\frac{2x\cdot y}{\sqrt{(1+2x\cdot x)(1+2y\cdot y)}},\qquad\dot{\mathcal T}(\Sigma)=\frac4\pi\det(I+2\Sigma)^{-1/2}$$

**③ 보충 D ⭐** — 마지막 층만 학습하면 앙상블에 대해 출력이 학습 내내 GP이고, **GP 사전분포와 사후분포 사이의 보간**.
$$\mathbb E[f_t(x^*)]=K(x^*,\mathcal X)K^{-1}(I-e^{-\eta Kt})\mathcal Y\quad(S22)$$
$$\mathrm{Var}[f_t(x^*)]=K(x^*,x^*)-K(x^*,\mathcal X)K^{-1}(I-e^{-2\eta Kt})K(x^*,\mathcal X)^\top\quad(S23)$$
$t\to\infty$: NNGP **사후분포**(식 13)와 **동일** → 마지막 층만 학습하면 **사후 샘플링**을 하는 셈.
→ 🔎 *the optimized neural network is performing posterior sampling* 에 밑줄.
→ ✍️ (S23)에서 $t=0$이면 분산이 $K(x^*,x^*)$ (사전), $t\to\infty$이면 식 (13)의 $\Sigma$ (사후)임을 확인하자.

**④ 보충 E 시작** — NNGP·탄젠트 커널의 점화식 (Lee 외 [5], Jacot 외 [13]).

<div style="page-break-after: always"></div>

# p.18 해설 — 보충 E: 커널 점화식, F: 표준 매개변수화

**① 핵심 함수 (S24)** — $(u,v)\sim\mathcal N(0,\Sigma)$:
$$\mathcal T(\Sigma)=\mathbb E[\phi(u)\phi(v)],\qquad\dot{\mathcal T}(\Sigma)=\mathbb E[\phi'(u)\phi'(v)]$$

**② NNGP 점화식 ⭐ (S26–S27)**
$$\mathcal K^l(x,x')=\sigma_\omega^2\,\mathcal T\!\begin{pmatrix}\mathcal K^{l-1}(x,x)&\mathcal K^{l-1}(x,x')\\\mathcal K^{l-1}(x,x')&\mathcal K^{l-1}(x',x')\end{pmatrix}+\sigma_b^2,\qquad\mathcal K^1=\frac{\sigma_\omega^2}{n_0}x^\top x'+\sigma_b^2$$

**③ NTK 점화식 ⭐⭐ (S29)**
$$\Theta^l(x,x')=\mathcal K^l(x,x')+\sigma_\omega^2\,\Theta^{l-1}(x,x')\,\dot{\mathcal T}(\cdots),\qquad\Theta^1=\mathcal K^1$$
→ 🔎 "NTK = (이번 층의 NNGP) + (이전 층 NTK) × (활성화 도함수의 상관)" — 지난주 Jacot 논문의 핵심 공식.

**④ 증명 아이디어 (S30–S35)** — $J^l(x)=\nabla_{\theta^{\le l}}h^l_0(x)$를 이번 층과 이전 층으로 쪼갬 → 첫 항은 NNGP로, 둘째 항은 **연쇄법칙** + 귀납 가정으로.

**⑤ 보충 F** — 표준 매개변수화: $W^l_{ij}\sim\mathcal N(0,\sigma_\omega^2/n_l)$ (S36). 함수 공간 결과가 표준 매개변수화에도 전이되는 이유 스케치.

→ ✍️ ReLU, 은닉층 1개, $\sigma_b=0$일 때 $\Theta^2$를 $\mathcal K^1$, $\mathcal T$, $\dot{\mathcal T}$로 직접 써 보자.

# p.19 해설 — NTK vs 표준 매개변수화, 보충 G 가정

**① 그림 S7** — MNIST·CIFAR, ReLU/tanh, 교차 엔트로피/MSE 조합에서 **NTK(원)** 와 **표준(삼각형)** 매개변수화가 정규화된 학습률 $\eta_{std}=\eta_{NTK}/n$에서 비슷한 정확도.

**② 두 매개변수화의 관계 ⭐** — 표현하는 함수는 같지만 경사하강 동역학은 다름. 그러나 층별 학습률을
$$\eta^l_{NTK,w}=\frac{n_l}{n_{max}}\eta_0,\qquad\eta^l_{NTK,b}=\frac{1}{n_{max}}\eta_0\quad(S37)$$
로 고르면 **동일**. 표준 신경망은 폭에 따라 학습률을 $1/n$로 줄여야 함.
→ 🔎 *learning dynamics are identical for networks with NTK and standard parameterizations* 에 밑줄.

**③ 보충 G** — NTK로 경사하강의 **전역 수렴**과 NTK **안정성**을 간단히 증명 (표준 매개변수화 기준).

**④ 가정 1–4 ⭐**
1. 은닉층 폭 동일 $n_1=\cdots=n_L=n$
2. 해석적 NTK $\Theta$가 **최대 계수**: $0<\lambda_{min}\le\lambda_{max}<\infty$, $\eta_{critical}=2(\lambda_{min}+\lambda_{max})^{-1}$
3. 학습 집합이 콤팩트 집합 안, 입력이 서로 다름
4. 활성화: $|\phi(0)|$, $\|\phi'\|_\infty$, $\phi'$의 립시츠 상수 유한

→ ✍️ 가정 2가 성립하지 않으면(어떤 고유값이 0) 무슨 일이? 그 방향으로는 학습이 일어나지 않는다 — $e^{-\eta\Theta t}$에서 고유값 0인 성분은 줄지 않음.

# p.20 해설 — 그림 S8, 기호와 MSE 설정

**① 그림 S8 ⭐** — **표준 매개변수화**에서도 원래 신경망과 선형화의 동역학이 거의 동일 (출력), 가중치도 비슷. MSE, ReLU 은닉층 5개, 폭 2048, $\eta=0.005/2048$, $|\mathcal D|=256$. 첫 행: 출력·가중치 동역학, 둘째 행: 손실·정확도·RMSE.

# p.21 해설 — 보조정리 1과 정리 G.1·G.2

**① 초기 잔차 유계 (S44)** — $f(\theta_0)$가 공분산 $K$의 가우시안으로 수렴하므로, 확률 $1-\delta_0$ 이상으로 $\|g(\theta_0)\|_2<R_0$.

**② 갱신식** — 경사하강 $\theta_{t+1}=\theta_t-\eta J(\theta_t)^\top g(\theta_t)$ (S45), 경사 흐름 $\dot\theta_t=-\eta J^\top g$ (S46).

**③ 보조정리 1 ⭐ (야코비안의 국소 립시츠성)** — 초기값 근방 $B(\theta_0,Cn^{-1/2})$에서
$$\frac1{\sqrt n}\|J(\theta)-J(\tilde\theta)\|_F\le K\|\theta-\tilde\theta\|_2,\qquad\frac1{\sqrt n}\|J(\theta)\|_F\le K\quad(S47)$$
→ 🔎 증명의 **유일한 기술적 열쇠**. "근방에서 기울기가 천천히 변한다".

**④ 정리 G.1 (경사하강) ⭐** — $\eta_0<\eta_{critical}$이면 높은 확률로
$$\|g(\theta_t)\|_2\le\Big(1-\frac{\eta_0\lambda_{min}}{3}\Big)^tR_0,\qquad\sum_j\|\theta_j-\theta_{j-1}\|_2\le\frac{3KR_0}{\lambda_{min}}n^{-1/2}$$
→ 잔차는 **지수적으로** 0, 매개변수의 총 이동거리는 $O(n^{-1/2})$.

**⑤ 정리 G.2 (경사 흐름)** — $\|g(\theta_t)\|_2\le e^{-\eta_0\lambda_{min}t/3}R_0$, 이동거리도 $O(n^{-1/2})$.

**⑥ 일반화 (비고 1)** — (1) 경험적 NTK가 양정치 극한으로 수렴, (2) 야코비안 국소 립시츠 — 이 둘만 성립하면 다른 구조에도 적용.

→ ✍️ $\lambda_{min}/3$의 "3"은 어디서? 경험적 커널이 해석적 커널과 $\lambda_{min}/3$ 이내라서 생기는 여유분이다 (다음 쪽).

# p.22 해설 — 정리 G.1의 증명: 귀납법

**① 출발** — 높은 확률로 $\|g(\theta_0)\|_2<R_0$ (S53), 보조정리 1 성립.

**② 귀납 가정** — $t$까지 (S49) 성립한다고 가정.

**③ 이동량 (S54)** — $\|\theta_{t+1}-\theta_t\|_2\le\eta\|J(\theta_t)\|_{op}\|g(\theta_t)\|_2\le K\eta_0(1-\frac{\eta_0\lambda_{min}}3)^tR_0\,n^{-1/2}$ → 기하급수 합으로 $\|\theta_j-\theta_0\|\le\frac{3KR_0}{\lambda_{min}}n^{-1/2}$.

**④ 잔차 감소 (S55–S59) ⭐** — **평균값 정리**:
$$g(\theta_{t+1})=g(\theta_t)+J(\tilde\theta_t)(\theta_{t+1}-\theta_t)=\big(1-\eta J(\tilde\theta_t)J(\theta_t)^\top\big)g(\theta_t)$$
$$\|g(\theta_{t+1})\|_2\le\|1-\eta J(\tilde\theta_t)J(\theta_t)^\top\|_{op}\,\|g(\theta_t)\|_2$$
→ 🔎 이 한 줄이 "선형 회귀의 경사하강"과 똑같은 구조!

**⑤ 남은 일 (S60)** — $\|1-\eta J(\tilde\theta_t)J(\theta_t)^\top\|_{op}\le1-\frac{\eta_0\lambda_{min}}3$.
- $\eta_0<\frac{2}{\lambda_{min}+\lambda_{max}}$ ⇒ $\|1-\eta_0\Theta\|_{op}\le1-\eta_0\lambda_{min}$ (S62)
- 삼각부등식: (해석적 커널 오차 $\le\frac{\eta_0\lambda_{min}}3$) + (경험적 초기 커널 오차) + (근방에서 야코비안 변화 $\le$ 보조정리 1)
- 세 오차의 합을 $\frac{2\eta_0\lambda_{min}}{3}$ 이하로 → $1-\eta_0\lambda_{min}+\frac{2\eta_0\lambda_{min}}3=1-\frac{\eta_0\lambda_{min}}3$ ✓

→ ✍️ (S62)를 직접 확인하자: $\Theta$의 고유값 $\lambda\in[\lambda_{min},\lambda_{max}]$에 대해 $|1-\eta_0\lambda|\le\max(|1-\eta_0\lambda_{min}|,|1-\eta_0\lambda_{max}|)$, 그리고 $\eta_0<\frac2{\lambda_{min}+\lambda_{max}}$ 이면 이 최댓값이 $1-\eta_0\lambda_{min}$.

# p.23 해설 — 커널 안정성, 정리 G.2 증명, 무작위 행렬

**① (S50) 커널 안정성 (S69–S72)** — 
$$\frac1n\|J(\theta_0)J(\theta_0)^\top-J(\theta_t)J(\theta_t)^\top\|_F\le2K^2\|\theta_0-\theta_t\|_2\le\frac{6K^3R_0}{\lambda_{min}}n^{-1/2}$$
→ 학습 내내 **경험적 NTK가 $O(n^{-1/2})$ 이내로 고정**. 매개변수가 거의 안 움직이니 커널도 안 변한다.

**② G.2 경사 흐름 증명 ⭐** — **"처음 벗어나는 시각"** 논법:
$$t_1=\inf\{t:\|\theta_t-\theta_0\|_2\ge\frac{3KR_0}{\lambda_{min}}n^{-1/2}\}$$
$t\le t_1$ 동안 $\hat\Theta_t\succ\frac13\lambda_{min}I$ 이므로
$$\frac{d}{dt}\|g(t)\|_2^2=-2\eta_0g^\top\hat\Theta_tg\le-\frac23\eta_0\lambda_{min}\|g\|_2^2\quad(S77)$$
→ $\|g(t)\|_2\le e^{-\eta_0\lambda_{min}t/3}R_0$ → 이동거리가 경계에 **도달하지 못함** → 모순 → $t_1=\infty$.
→ 🔎 (S77)에 밑줄 — 잔차 제곱이 지수적으로 감소하는 미분부등식.

**③ G.3 보조정리 1의 증명 도구** — 정리 G.3 (Vershynin): $N\times n$ 표준정규 무작위 행렬 $A$는 확률 $1-2e^{-t^2/2}$ 이상으로
$$\sqrt N-\sqrt n-t\le\lambda_{min}(A)\le\lambda_{max}(A)\le\sqrt N+\sqrt n+t$$
→ 무작위 가중치 행렬의 연산자 노름이 $O(\sqrt n)$ → 정규화하면 $O(1)$.

→ ✍️ "처음 벗어나는 시각" 논법을 그림으로: 반경 $r$인 공 안에서 출발한 점이 공 안에 있는 동안은 속도가 지수적으로 줄어 총 이동이 $r$보다 작다 → 영원히 공 안에 머문다.

# p.24 해설 — 보조정리 1의 증명, NTK 매개변수화판

**① 역전파 신호 (S82–S83)** — $\delta^l(\theta,x)=\nabla_{h^l}f^{L+1}(\theta,x)$ — 층 $l$의 사전활성화에 대한 출력의 기울기.

**② 가중치 노름 (S84)** — 근방 $B(\theta_0,C/\sqrt n)$의 두 점 모두 높은 확률로 $\|W^1\|_{op}\le3\sigma_\omega\frac{\sqrt n}{\sqrt{n_0}}$, $\|W^l\|_{op}\le3\sigma_\omega$ (정리 G.3 + 삼각부등식).

**③ 두 추정 (S85–S86)** — 활성화 가정(S38)으로 귀납적으로
$$\frac1{\sqrt n}\|x^l(\theta,\mathcal X)\|_2,\ \|\delta^l(\theta,\mathcal X)\|_2\le K_1,\qquad\text{차이는}\ \le K_1\|\tilde\theta-\theta\|_2$$
(각주 13: $x^l$은 $l=1$부터 앞으로, $\delta^l$은 $l=L$부터 뒤로 귀납 — **순전파와 역전파**!)

**④ 야코비안 노름 (S87–S92) ⭐** — 가중치에 대한 기울기 = (이전 층 활성화) × (역전파 신호)$^\top$:
$$\|J(\theta)\|_F^2=\sum_l\big(\|J(W^l)\|_F^2+\|J(b^l)\|_F^2\big)\le2(L+1)K_1^4\,n$$
→ $\frac1{\sqrt n}\|J\|_F\le K$. 차이도 같은 방식 (S93–S96).
→ 🔎 *$x^{l-1}\delta^{lT}$* 구조에 밑줄 — 역전파 공식 "$\partial L/\partial W=$ 입력 × 오차신호"와 같다.

**⑤ G.4 NTK 매개변수화** — 정리 G.4: 같은 결론 (이동거리 $\le\frac{3KR_0}{\lambda_{min}}$ — $n^{-1/2}$ 인자 없이, 매개변수화가 다르므로).

# p.25 해설 — 보조정리 2, 보충 H: 선형화와의 차이

**① 보조정리 2 (NTK 매개변수화)** — 근방 $B(\theta_0,C)$에서 $\|J(\theta)-J(\tilde\theta)\|_F\le\frac{K}{\sqrt n}\|\theta-\tilde\theta\|$, $\|J\|_F\le K$.

**② 보충 H 목표 ⭐** — 원래 신경망과 선형화의 차이를 상계 (경사 흐름). $g^{lin}(t)=f^{lin}_t(\mathcal X)-\mathcal Y$, $g(t)=f_t(\mathcal X)-\mathcal Y$.

**③ 정리 H.1** — 높은 확률로
$$\sup_t\|g^{lin}(t)-g(t)\|_2,\ \ \sup_t\|g^{lin}(t,x)-g(t,x)\|_2\ \lesssim\ n^{-1/2}R_0^2$$

**④ 핵심 계산 (S101–S105) ⭐** — 적분 인자 $e^{\eta_0\hat\Theta_0t}$ 를 곱해 미분:
$$\frac{d}{dt}\Big[e^{\eta_0\hat\Theta_0t}(g^{lin}-g)\Big]=\eta_0e^{\eta_0\hat\Theta_0t}(\hat\Theta_t-\hat\Theta_0)g(t)$$
적분하고 $g^{lin}(0)=g(0)$ 사용:
$$g^{lin}(t)-g(t)=-\int_0^t\eta_0e^{\eta_0\hat\Theta_0(s-t)}(\hat\Theta_s-\hat\Theta_0)\big[(g^{lin}-g)(s)-g^{lin}(s)\big]ds$$
→ 🔎 차이의 원천은 오직 $(\hat\Theta_s-\hat\Theta_0)$ — 커널의 변화!

**⑤ 노름 잡기 (S106–S112)** — $\hat\Theta_0$의 최소 고유값 $\lambda_0>\frac13\lambda_{min}$, $u(t)=e^{\lambda_0\eta_0t}\|g^{lin}-g\|$ 로 두면 적분부등식으로.

→ ✍️ 1차원 버전으로 연습: $\dot y=-ay+\epsilon(t)$ 의 해를 적분 인자 $e^{at}$로 구해 보자.

# p.26 해설 — 그론월 부등식으로 마무리

**① 적분부등식 (S113)** — $u(t)\le\alpha(t)+\int_0^t\beta(s)u(s)ds$, $\alpha$ 비감소.

**② 그론월 부등식 ⭐ (S114)** —
$$u(t)\le\alpha(t)\exp\Big(\int_0^t\beta(s)ds\Big)$$
→ 🔎 크게 밑줄. "자기 자신에 비례해 커질 수 있는 양은 많아야 지수적으로 커진다".

**③ 선형 모델의 잔차** — $\|g^{lin}(t)\|_2\le e^{-\lambda_0\eta_0t}\|g^{lin}(0)\|_2$ (식 9에서 바로).

**④ 결합 (S118)** — $\sigma_t=\sup_{s\le t}\|\hat\Theta_s-\hat\Theta_0\|_{op}$ 로 두면
$$\|g^{lin}(t)-g(t)\|_2\lesssim\eta_0t\,\sigma_t\,e^{-\lambda_0\eta_0t+\sigma_t\eta_0t}\|g^{lin}(0)\|_2$$

**⑤ 결론 ⭐** — 정리 G.1에서 $\sigma_t\lesssim n^{-1/2}R_0\to0$ (S119). 그러면 $e^{-\lambda_0\eta_0t+\sigma_t\eta_0t}\eta_0t=O(1)$ (S120, 지수 감소가 이김) → $\|g^{lin}-g\|_2\lesssim n^{-1/2}R_0^2\to0$ (S121).

**⑥ 테스트 점** — 같은 방식: 차이의 미분 = (커널 변화) × (선형 잔차) + (커널) × (훈련 차이).

→ ✍️ 이 증명의 논리를 세 줄로: (1) 커널이 거의 안 변한다(보충 G) → (2) 두 ODE의 차이는 커널 변화에 비례 → (3) 그론월로 차이가 $O(n^{-1/2})$.

# p.28 해설 — 그림 S10, 전체 정리

**① 그림 S10** — 은닉층 1개 ReLU의 커널이 몬테카를로 표본 수 $M$과 폭 $n$에 따라 해석적 커널로 수렴하는 2차원 지도 ($\log_2 n$ × $\log_2 M$). 오른쪽 위(넓고 표본 많음)로 갈수록 오차↓.

**✍️ 논문 전체 정리 질문**
