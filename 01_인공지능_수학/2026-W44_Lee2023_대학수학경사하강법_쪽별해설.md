# p.468 해설 — 왜 미적분 수업에 경사하강법이 없나

**① 현재 교재의 문제** — 경사하강법(gradient / steepest descent method)은 수치해석·계산과학에서 **간간이** 소개될 뿐.
- Burden & Faires: 연립방정식·비선형방정식의 반복 해법에서 **부분적으로**만 → **최적화**라는 본질이 안 보임
- Chapra & Canale: 방대한 방법 목록 중 하나 → 교수자에 따라 **빠질 수도**
→ 학생이 대학 내내 수학을 듣고도 경사하강법을 **한 번도 못 볼 수 있다**.

**② 그런데도 중요한 이유** — 형식이 단순해서 **선형회귀, 로지스틱 회귀, 서포트 벡터 머신** 등에 두루 쓰인다.

**③ 미적분 교재의 한계 ⭐** — 최적화 문제는 보통 (1) 임계점 계산 → (2) 이계도함수/헤시안으로 판정. 그런데 함수가 복잡하면 임계점 방정식 자체를 **손으로 못 푼다** → 교재엔 손으로 풀리는 단순한 문제만.
→ 🔎 "지필로 계산하기 어려운 복잡한 함수" 에 밑줄.

**④ 논문 구성** — 경사하강법 소개 → SageMath 코드 → 최소제곱 예시.

**⑤ Ⅱ. 이론적 배경** — 데이터 기반 AI는 **예측값과 관측값의 오차 함수를 최소화**하는 문제. 예: 최소제곱문제
$$\min_{\mathbf x\in\mathbb R^n}\ \|A\mathbf x-\mathbf b\|^2\qquad (A\in\mathbb R^{m\times n},\ \mathbf b\in\mathbb R^m)$$

**⑥ 최솟값 vs 극솟값** — 제약이 없으면 극솟값 중 가장 작은 것이 **최솟값(global minimum)**. 하지만 **비볼록** 다변수 함수는 극솟값이 몇 개인지 몰라 찾은 극솟값이 최솟값인지 알기 어렵다 — 지금도 활발한 연구 분야.

# p.469 해설 — 극솟값 판정법 총정리 (표 Ⅱ-2)

**① 범위 한정** — 이 논문은 **제약 없는 극솟값** 문제만 다룬다.

**② 본질은 하나 ⭐** — 변수 개수와 상관없이:
1. **페르마의 임계점 정리**: 극소점 후보는 $\nabla f(\mathbf a)=\mathbf 0$
2. 임계점에서 **헤시안**의 고윳값이 모두 양수 (또는 선행 주 소행렬식이 모두 양수) → 극소

**③ 1변수** — [1단계] $f'(a)=0$, [2단계] $f''(a)>0$ 이면 극소. 이때 헤시안은 $1\times1$ 행렬 $[f''(a)]$이므로 $f''$의 부호 = 고윳값의 부호 = 소행렬식의 부호.

**④ 2변수** — 헤시안
$$\nabla^2 f=\begin{bmatrix} f_{xx} & f_{xy}\\ f_{yx} & f_{yy}\end{bmatrix}$$
$f_{xx}>0$ 이고 $f_{xx}f_{yy}-f_{xy}^2>0$ 이면 극소. 또는 두 고윳값 $\lambda_1,\lambda_2>0$.

**⑤ $n$변수** — 선행 주 소행렬식 $D_1,\dots,D_n$ 모두 양수, 또는 고윳값 $\lambda_1,\dots,\lambda_n$ 모두 양수.
→ 🔎 "본질은 모두 같다" 에 밑줄.

→ ✍️ $f(x,y)=x^2+xy+y^2$ 의 원점에서 헤시안의 고윳값을 구하고 극소인지 판정해 보자. (헤시안 $\begin{bmatrix}2&1\\1&2\end{bmatrix}$, 고윳값 1, 3)
→ ✍️ 지난주 Jacot(NTK)의 "커널 행렬이 양정치" 조건과 여기 "헤시안이 양정치" 조건을 비교해 보자.

# p.471 해설 — 코시의 논증과 1변수 알고리즘

**① 1차 근사**
$$f(x_0+\alpha,\,y_0+\beta,\,z_0+\gamma,\dots)\approx u_0+X\alpha+Y\beta+Z\gamma+\cdots$$

**② 핵심 한 줄 ⭐⭐** — 작은 $\theta>0$로 $\alpha=-\theta X,\ \beta=-\theta Y,\ \gamma=-\theta Z$:
$$u_1=f(x_0-\theta X,\,y_0-\theta Y,\dots)=u_0-\theta\,(X^2+Y^2+Z^2+\cdots)<u_0$$
→ 🔎 이 식에 크게 밑줄. 제곱합은 항상 양수 → **반드시 감소**. 이를 반복하면 최솟값으로 간다고 코시는 주장(Lemaréchal 2012).

**③ 1변수 문제** — $\min f(x)$, $f$ = 목적함수 = 비용함수 = **손실함수**(이 논문은 AI 용어에 맞춰 '손실함수').

**④ 반복법** — 초기 근사해 $x_1$ → $x_2, x_3,\dots$ → 목표: $f'(x^*)=0$.

**⑤ 표 Ⅲ-1 알고리즘 ⭐**
| 단계 | 내용 |
|---|---|
| 1 | 초기 근사해 $x_1$, 허용오차 $0\le\epsilon\ll1$, 학습률 $\eta>0$, $k:=1$ |
| 2 | $g_k=f'(x_k)$. $|g_k|\le\epsilon$ 이면 멈추고 $x_k$ 반환 |
| 3 | $x_{k+1}=x_k-\eta g_k$, $k:=k+1$, 단계 2로 |

**⑥ 부호로 이해하기** — $g_k<0$ (내리막이 오른쪽) → $-g_k>0$ 이므로 **오른쪽**으로. $g_k>0$ → **왼쪽**으로.
→ ✍️ ai_life **01 선형회귀**의 "기울기 슬라이더" 애니메이션을 이 표의 3단계로 설명하는 교사용 말풍선을 써 보자.

# p.474 해설 — 가장 가파른 방향과 예제 2

**① 증명 한 줄 ⭐**
$$\lim_{h\to0}\frac{f(\mathbf x_k+h\mathbf d)-f(\mathbf x_k)}{h}=\mathbf d\cdot\nabla f(\mathbf x_k),\qquad |\mathbf d\cdot\nabla f|\le\|\mathbf d\|\,\|\nabla f\|$$
단위벡터 $\mathbf d$ 중 $\mathbf d\cdot\nabla f$ 가 가장 작은(가장 음수인) 것은 $\mathbf d=-\nabla f/\|\nabla f\|$.

# p.475 해설 — 경사하강법의 한계와 유한합 최적화

**① 한계 세 가지 ⭐**
1. **비볼록** 함수(그림 Ⅲ-2)면 시작점에 따라 다른 극솟값, 또는 극대도 극소도 아닌 **임계점**으로 수렴 → 보장되는 건 "임계점"뿐
2. 뉴턴법·준뉴턴법보다 이론적 **수렴 속도가 느림**
3. 고정 학습률 → 문제마다 적절한 $\eta$ 선택 필요
→ 🔎 "임계점이라는 것 이외에는 보장하지 못한다" 에 밑줄.

**② 참고 문헌** — Bottou 외 2018, Boyd & Vandenberghe 2004, Nocedal & Wright 2006 등.

**③ 유한합 최적화 ⭐**
$$\min_{\mathbf x\in\mathbb R^n}\ F(\mathbf x)=\frac1m\sum_{i=1}^{m} f_i(\mathbf x)$$
$f_i$ = **성분함수** (데이터 하나에 대한 손실).

**④ 최소제곱도 유한합** — $A$의 $i$번째 행을 $\mathbf a_i^\top$라 하면
$$\frac1{2m}\|A\mathbf x-\mathbf b\|^2=\frac1m\sum_{i=1}^m\tfrac12(\mathbf a_i^\top\mathbf x-b_i)^2$$

**⑤ 문제점** — 전체 그레이디언트 $\nabla F=\frac1m\sum\nabla f_i$ 를 매번 계산·저장하기엔 $m$이 너무 크다. 실제 데이터엔 **중복**도 많아 매 단계 전부 쓰는 것이 비효율.

# p.476 해설 — SGD 알고리즘과 예제 3

**① SGD의 아이디어** — 매 단계 **무작위로 하나**의 성분함수를 골라 $\nabla f_{i_t}(\mathbf x_t)$로 $\nabla F(\mathbf x_t)$를 대신. 계산 비용이 적고 특히 **초반에 매우 효과적**.

**② 표 Ⅲ-5 SGD ⭐**
| 단계 | 내용 |
|---|---|
| 1 | $\tilde{\mathbf x}_1$, $\epsilon$, $\eta$ 설정, $k:=1$ |
| 2 | $\mathbf x_1:=\tilde{\mathbf x}_k$; $t=1..m$ 동안 $\{1,..,m\}$에서 무작위 $i_t$, $\mathbf x_{t+1}=\mathbf x_t-\eta\nabla f_{i_t}(\mathbf x_t)$; $\tilde{\mathbf x}_{k+1}:=\mathbf x_{m+1}$ |
| 3 | $\|\tilde{\mathbf x}_{k+1}-\tilde{\mathbf x}_k\|\le\epsilon$ 이면 멈춤, 아니면 $k:=k+1$ |
→ 🔎 $\mathbf x_{t+1}=\mathbf x_t-\eta\nabla f_{i_t}(\mathbf x_t)$ 에 밑줄. 단계 2의 $m$번 반복 = 딥러닝의 "**1 에폭**".

**③ 예제 3 ⭐** — 점 $(1.2,3.0),(2.0,4.5),(3.1,5.1),(4.6,6.0),(7.2,9.8)$의 최소제곱 직선 $y=a+bx$. $\hat y_i=a+bx_i$ 라 두고
$$E(a,b)=\tfrac12\{(a+1.2b-3.0)^2+(a+2.0b-4.5)^2+(a+3.1b-5.1)^2+(a+4.6b-6.0)^2+(a+7.2b-9.8)^2\}$$

**④ 결과** — 시작 $(0,0)$, $\eta=0.01$, $\epsilon=10^{-6}$, 최대 2,000회 → $a=1.86,\ b=1.05$, 즉 $y=1.86+1.05x$.

→ ✍️ 정규방정식으로 검산해 보자: $\sum x_i=18.1$, $\sum y_i=28.4$, $\sum x_i^2=88.05$, $\sum x_iy_i=126.57$ → $b=\frac{5(126.57)-18.1(28.4)}{5(88.05)-18.1^2}\approx1.055$, $a=\bar y-b\bar x\approx1.862$ — 논문 결과와 일치!

# p.478 해설 — 제곱오차 vs 교차 엔트로피

**① 시그모이드의 성질**
1. 모든 $x$에 대해 $0<f(x)<1$
2. $x>0$이면 $f>0.5$, $x<0$이면 $f<0.5$
3. $f'(x)=\dfrac{e^{-x}}{(1+e^{-x})^2}=f(x)\big(1-f(x)\big)$ — **자기 자신으로 미분** ⭐

**② 로지스틱 모형** $y=f(a+bx)=\dfrac{1}{1+e^{-(a+bx)}}$

**③ 두 손실함수 ⭐⭐**
$$E(a,b)=\sum_{i=1}^n\big[y_i-f(a+bx_i)\big]^2$$
$$CE(a,b)=-\sum_{i=1}^n\big[y_i\log f(a+bx_i)+(1-y_i)\log\big(1-f(a+bx_i)\big)\big]$$
일반적으로는 **교차 엔트로피**를 쓴다. 이유: 제곱오차는 **비볼록**이라 초깃값 설정이 어렵다.
→ 🔎 "오차를 최소화하는 문제에서는 손실함수가 비볼록" 에 밑줄.

**④ 예제 4** — 데이터 10개: $(-1,0),(-0.6,0),(-0.1,1),(0.3,1),(0.8,1),(1.2,1),(1.6,0),(2.1,0),(2.5,1),(3,1)$.

**⑤ 모수 하나로 단순화** — $f(bx)=\dfrac1{1+e^{-bx}}$:
$$CE(b)=-y\log f(bx)-(1-y)\log(1-f(bx))=\log(1+e^{bx})-bxy$$
→ ✍️ 이 정리 과정을 직접 따라가 보자. (힌트: $1-f(bx)=\dfrac{e^{-bx}}{1+e^{-bx}}$, $\log(1+e^{-bx})+bx=\log(1+e^{bx})$)

# p.479 해설 — 볼록성의 증명과 실험 결과

**① 이계도함수 ⭐**
$$\frac{d^2CE}{db^2}=\frac{x^2e^{-bx}}{(1+e^{-bx})^2}\ \ge 0$$
→ $CE$는 **볼록함수**. 모수가 여러 개이거나 데이터가 고차원·대량이어도 같은 방식으로 볼록. → 어떤 초깃값에서도 수렴 조건 만족.
→ ✍️ $CE'(b)=x f(bx)-xy$ 임을 먼저 보이고, 한 번 더 미분해 위 식을 얻자. 이 결과가 $x^2 f(1-f)$ 와 같음도 확인.

**② 그림 Ⅲ-3 vs Ⅲ-4** — 제곱오차 곡면은 **평평한 영역**이 넓고 구불구불(비볼록), 교차 엔트로피 곡면은 대부분 **가파른 그릇** 모양(볼록).
→ 🔎 두 그림을 나란히 형광펜으로 표시.

**③ 실험 ⭐** — 시작 $(10,0)$, $\eta=0.1$, $\epsilon=10^{-6}$, 최대 3,000회:
| 손실 | 결과 |
|---|---|
| 제곱오차 | 3,000회 후 약 $(9.88,-0.07)$, 허용오차 미달, 시작점마다 다른 답 |
| 교차 엔트로피 | **652회** 후 약 $(-0.04,\ 0.50)$, 시작점을 바꿔도 같은 답 |

**④ 신경망과의 연결** — 로지스틱 회귀의 출력 노드를 여러 개 = **단층 퍼셉트론(SLP)**, 은닉층 추가 = **다층 퍼셉트론(MLP)** → 심층학습. 제곱오차를 쓰면 기울기가 0 근처인 영역이 많아 학습이 느려진다. **평균제곱오차**는 1980–90년대에 유행, 이후 **교차 엔트로피**가 대체.
→ ai_life **03 CNN**의 분류 손실이 왜 교차 엔트로피인지 이 쪽으로 설명 가능!
