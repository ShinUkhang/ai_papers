# p.359 해설 — 초록과 서론: 성공은 우연인가?

> 스캔본이라 이 쪽은 텍스트 검색이 안 됩니다. 기호 대응: $\Psi$(프사이) = 찌그러뜨리는 함수, $A$ = 아핀 함수, $\beta$ = 출력 가중치.

**① 초록 ⭐** — 은닉층이 **단 하나**이고 **임의의** 찌그러뜨리는 함수를 쓰는 표준 다층 순방향 신경망은, 은닉 뉴런만 충분하면 한 유한차원 공간에서 다른 유한차원 공간으로 가는 **임의의 보렐 가측 함수**를 원하는 정확도로 근사한다.
→ 🔎 *as few as one hidden layer*, *arbitrary squashing functions*, *any Borel measurable function* 세 곳에 밑줄.

**② 키워드** — 스톤–바이어슈트라스 정리, 찌그러뜨리는 함수, **시그마–파이(ΣΠ) 망**, 역전파 망.

**③ 역사적 배경** — 약 20년 전 **민스키 & 페퍼트(1969)** 는 단순한 2층 퍼셉트론이 아주 좁은 함수 부류밖에 표현 못 함을 보였다. 다층망의 가능성은 열려 있었고, 최근 응용 성공이 "폭발"했다.

**④ 이 논문의 질문** — 지금까지의 성공은 **근본적인 근사 능력**의 반영인가, 아니면 선택적 보고와 운 좋은 문제 선택이 만든 **요행(fluke)** 인가?
→ 🔎 *merely flukes* 에 밑줄. p.364 마지막 문장과 짝을 이룸.

**⑤ 콜모고로프 정리의 한계 (오른쪽 단)** — 신경망 옹호자들은 콜모고로프(1957) 중첩 정리(Lorentz 1976 개선)를 인용하지만, 그 정리는 표현할 함수마다 **다른 미지의 변환**($g$)을 요구한다. 실제로는 로지스틱·tanh 같은 **고정된** 함수를 쓰고 뉴런을 **마음대로**(ad libitum) 늘린다.

→ ✍️ 콜모고로프 방식("함수마다 맞춤 부품")과 신경망 방식("같은 부품 여러 개")의 차이를 레고에 비유해 설명해 보자. 이번 주 **KAN(Liu 외 2024)** 은 콜모고로프 쪽으로 돌아간 시도!

# p.360 해설 — 선행 연구와 기본 정의

**① 선행 연구** — 르쿤(1987), Lapedes & Farber(1988): 은닉층 **두 개**로 충분. Irie & Miyake(1988): 은닉층 하나지만 **연속체(무한)** 개 뉴런 — 이론적으로만 유용. Gallant & White(1988): **코사인 찌그러뜨리개** 망은 **푸리에 망**을 특수한 경우로 품는다 → 푸리에 급수의 근사 성질을 그대로 가짐.

**② 이 논문의 도구 ⭐** — **스톤–바이어슈트라스 정리** + 갈랑–화이트의 **코사인 찌그러뜨리개**.

**③ 실패의 진단 ⭐⭐** — 보편 근사기이므로, 응용의 실패는 (a) **학습 부족**, (b) **은닉 뉴런 부족**, (c) 입력–목표 관계가 결정적이 아닌 **확률적** 관계, 셋 중 하나 탓.
→ 🔎 *inadequate learning, inadequate numbers of hidden units* 에 밑줄. 단, **몇 개가 필요한지는 다루지 않음**.

**④ 정의 2.1 — 아핀 함수** $A(x) = w\cdot x + b$ ($w$ = 입력→은닉 가중치, $b$ = 편향).

**⑤ 정의 2.2 — 단층망 $\Sigma^r(G)$**
$$f(x)=\sum_{j=1}^{q}\beta_j\,G\big(A_j(x)\big)$$

**⑥ 정의 2.3 — 찌그러뜨리는 함수** $\Psi:\mathbb R\to[0,1]$, **비감소**, $\Psi(\lambda)\to1\ (\lambda\to\infty)$, $\to0\ (\lambda\to-\infty)$. 예: 계단 $1\{\lambda\ge0\}$, 램프, 코사인 찌그러뜨리개 $\tfrac12(1+\cos[\lambda+3\pi/2])$ ($-\pi/2\le\lambda\le\pi/2$ 구간).
→ ✍️ 코사인 찌그러뜨리개를 직접 그려 보자. 왜 0에서 1로 매끄럽게 올라가는가?

**⑦ 정의 2.4 — ΣΠ 망** $f(x)=\sum_j\beta_j\prod_{k=1}^{l_j}G(A_{jk}(x))$ — 뉴런 출력의 **곱**을 허용.

# p.361 해설 — 거리, 조밀성, 그리고 정리 2.1

**① 왜 ΣΠ부터?** — ΣΠ로 먼저 증명하고 Σ로 확장. Σ는 모든 $l_j=1$ 인 특수한 경우.

**② 정의 2.5** — $C^r$ = 연속함수, $M^r$ = 보렐 가측함수. 가측이 아닌 함수는 "병적인(pathological)" 것뿐 → 응용에 필요한 거의 모든 함수가 $M^r$에 있음.

**③ 정의 2.6 — 조밀(dense)** — $S$가 $T$에서 $\rho$-조밀 ⇔ 모든 $\varepsilon>0$, 모든 $t\in T$에 대해 $\rho(s,t)<\varepsilon$ 인 $s\in S$가 있다. = "**원하는 만큼 가깝게** 근사 가능".

**④ 정의 2.7 — 콤팩트 위 균등 조밀**
$$\rho_K(f,g)=\sup_{x\in K}|f(x)-g(x)|$$
→ 🔎 *uniformly dense on compacta* 에 밑줄.

**⑤ 정리 2.1 ⭐** — $G$가 **연속·비상수**이면 $\Sigma\Pi^r(G)$는 $C^r$에서 콤팩트 위 균등 조밀. 입력이 **유계**면 콤팩트 조건 성립. $G$는 찌그러뜨리는 함수일 **필요도 없다**!

**⑥ 정의 2.8–2.9 — 확률적 거리** — $\mu$ = 입력 패턴의 **빈도**("입력 공간 환경").
$$\rho_\mu(f,g)=\inf\{\varepsilon>0:\ \mu\{x:|f(x)-g(x)|>\varepsilon\}<\varepsilon\}$$
두 함수가 "크게 다를 **확률**이 작으면" 가깝다.

**⑦ 보조정리 2.1** — 다음은 동치: (a) $\rho_\mu(f_n,f)\to0$, (b) 모든 $\varepsilon$에 대해 $\mu\{|f_n-f|>\varepsilon\}\to0$ (**확률수렴**), (c) $\int\min\{|f_n-f|,1\}\,d\mu\to0$.
→ ✍️ (c)에서 $\min\{\cdot,1\}$로 자르는 이유는? (큰 오차 몇 개가 적분을 지배하지 않게)

# p.362 해설 — 정리 2.2~2.4: 가측함수까지, 불연속 활성화까지

**① 보조정리 2.2** — 콤팩트 위 균등수렴 ⇒ $\rho_\mu$-수렴. (거의 모든 확률이 어떤 콤팩트 집합에 담기므로)

**② 정리 2.2** — 연속 비상수 $G$, 모든 $r$, 모든 확률측도 $\mu$에 대해 $\Sigma\Pi^r(G)$는 $M^r$에서 $\rho_\mu$-조밀. → 차원 $r$, 입력 환경 $\mu$와 **무관하게** 보편 근사.

**③ 정리 2.3** — 연속성 조건은 **계단함수를 배제**한다. 하지만 찌그러뜨리는 함수라면 연속일 **필요 없다**: 모든 찌그러뜨리는 $\Psi$에 대해 $\Sigma\Pi^r(\Psi)$ 는 균등·$\rho_\mu$ 조밀.

**④ 정리 2.4 ⭐⭐ (논문의 주 결과)** — 가장 단순한 **Σ 망**(곱 없음, 은닉층 1개)도, **어떤** 찌그러뜨리는 함수든(연속이든 아니든), 어떤 $r$, $\mu$든:
$$\Sigma^r(\Psi)\ \text{는 } C^r\text{에서 콤팩트 위 균등 조밀, } M^r\text{에서 } \rho_\mu\text{-조밀.}$$
→ 🔎 정리 2.4 전체에 밑줄.

**⑤ Cybenko와의 관계** — 이 결과가 처음 나온 뒤(1988 토론 논문), **Cybenko(1988)** 가 독립적으로 $C^r$ 균등 근사 부분을 얻었다. "매우 다른 접근으로 **한–바나흐 정리**를 우아하게 사용".
→ 🔎 *Hahn-Banach theorem* 에 밑줄 — 지난주 Cybenko 해설과 나란히 놓고 보자.

**⑥ 따름정리 2.1** — 가측함수 $g$에 대해, 확률이 $1-\varepsilon$ 이상인 콤팩트 $K$를 골라 그 위에서 $|f-g|<\varepsilon$. (정리 2.1과 달리 $K$를 **특별히** 골라야 함)

**⑦ 정의 2.10 · 따름정리 2.2** — $\mu(K)=1$인 콤팩트 $K$가 있으면 $\Sigma^r(\Psi)$는 모든 $p\in[1,\infty)$에 대해 $L^p(\mu)$에서 조밀.
→ ✍️ ai_life **01 선형회귀**의 평균제곱오차는 어느 $L^p$ 거리에 해당할까? ($p=2$)

# p.363 해설 — 불 함수, 정확 보간, 다층, 결론

**① 따름정리 2.3–2.4** — $[0,1]^r$ 위에서도 $L^p$ 조밀. $\mu$가 **유한 개 점**에만 질량을 두면 그 점들에서 오차 $<\varepsilon$ 를 확률 1로 달성.

**② 따름정리 2.5** — 모든 **불 함수**($\{0,1\}^r\to\{0,1\}$)를 오차 $<\varepsilon$로 근사. (XOR도 OK — 민스키·페퍼트에 대한 답!)

**③ 정리 2.5 ⭐ — 정확 보간** — 서로 다른 점 $x_1,\dots,x_n$과 임의의 $g$에 대해, $\Psi$가 0과 1에 **도달**하면 은닉 뉴런 **$n$개**로 $f(x_i)=g(x_i)$.
→ 🔎 *with n hidden units* 에 밑줄. Zhang 외(2017)의 "외우기"와 연결.

**④ 다출력·다층** — $\beta_j$를 벡터로 바꾸면 다출력 (따름정리 2.6). $l$층 망의 활성화 규칙 $a_{k}=G_k(A(a_{k-1}))$, 마지막 층은 항등 → 따름정리 2.7: $l\ge2$이면 다층 다출력망도 보편 근사기.

**⑤ 3절 결론 ⭐** — 표준 다층 순방향망은 "매우 구체적이고 만족스러운 의미에서" **보편 근사기**. 실패는 학습 부족·뉴런 부족·비결정적 관계 탓 (p.360과 반복).

**⑥ 학습 가능성으로** — 이 결과는 망이 근사를 달성하는 가중치를 **학습할 수 있음**(일관 추정)을 보이는 기초가 된다. Grenander의 **체(sieve) 방법**, Kolmogorov–Tihomirov의 **거리 엔트로피** → 학습 데이터 수에 따라 은닉 뉴런을 **얼마나 빨리 늘려도 과적합을 피하는지** 비율을 얻음.

# p.364 해설 — 남은 과제, 그리고 정리 2.1의 5줄 증명

**① 남은 과제 1: 근사의 정도** — 차원 $r$ 고정, 뉴런 수가 늘 때 근사가 **얼마나 빨리** 좋아지나?

**② 남은 과제 2: 스케일링** — 원하는 정확도를 위해 필요한 뉴런 수가 입력 차원 $r$에 따라 **얼마나 빨리** 늘어야 하나? (이 논문은 완전히 다루지 않음 → Barron 1993)

**③ 마지막 문장 ⭐** — 지금까지의 성공은 **요행이 아니라** 다층망의 일반적 보편 근사 능력의 반영이다.
→ 🔎 *not just flukes* 에 밑줄 (p.359의 질문에 대한 답).

**④ 교정 중 추가** — Funahashi(같은 학술지 2권)의 관련 연구를 몰랐음을 유감. 이 논문은 **불연속 활성화**를 허용해 확장.

**⑤ 스톤–바이어슈트라스 정리 ⭐** — 콤팩트 $K$ 위 실연속함수의 **대수** $\mathcal A$(덧셈·곱셈·스칼라배에 닫힘)가 (i) **점을 분리**하고 (ii) **어느 점에서도 사라지지 않으면**, $\mathcal A$의 균등 폐포는 $K$ 위 모든 연속함수.

**⑥ 정리 2.1 증명 (단 5줄!)**
- $\Sigma\Pi^r(G)$는 곱에 닫혀 있으니 대수.
- **점 분리**: $G(a)\ne G(b)$인 $a,b$를 고르고 $A(x)=a$, $A(y)=b$가 되게 아핀 함수 선택.
- **사라지지 않음**: $G(b)\neq0$인 $b$로 $A(x)=0\cdot x+b$ (상수함수).
→ ✍️ 이 증명에서 $G$가 "비상수"라는 조건이 정확히 어디에 쓰였나?

**⑦ 보조정리 2.1·2.2 증명** — 체비쇼프 부등식, 측도의 **정칙성**(콤팩트 집합으로 거의 다 덮기).

# p.365 해설 — 코사인 트릭: 곱을 합으로

**① Lemma A.1** — 유한측도에 대해 $C^r$은 $M^r$에서 $\rho_\mu$-조밀 (가측함수를 연속함수로 근사).

**② Lemma A.2 ⭐ — 계단 쌓기** — 연속 찌그러뜨리개 $F$를 **아무** 찌그러뜨리개 $\Psi$의 합으로 근사:
$$H_\varepsilon(\lambda)=\sum_{j=1}^{Q-1}\frac1Q\,\Psi\big(A_j(\lambda)\big)$$
$F$가 $j/Q$ 높이를 지나는 지점마다 $\Psi$를 가파르게 놓아 **높이 $1/Q$짜리 계단**을 쌓는다 ($1/Q<\varepsilon/2$).
→ ✍️ $Q=4$일 때 계단 그림을 그려 보자. Cybenko의 "가파른 시그모이드" 그림과 같은 아이디어!

**③ 정리 2.3 증명** — $\prod_k F(A_k)$의 각 인수를 $H$로 바꿔도 곱의 연속성 때문에 오차가 작다.

**④ Lemma A.3** — 코사인 찌그러뜨리개를 평행이동·덧셈·뺄셈·배율하면 $[-M,M]$ 위의 $\cos$를 얻는다 → 아무 $\Psi$로도 $\cos$ 근사 가능.

**⑤ Lemma A.5 ⭐⭐ (곱 없애기)** — 정리 2.1에 의해 **삼각다항식** $\sum_i\beta_i\prod_k\cos(A_{ik}(x))$ 는 조밀. 곱셈 공식
$$\cos a\cdot\cos b=\tfrac12\big[\cos(a+b)+\cos(a-b)\big]$$
을 반복하면 곱이 **코사인들의 합** $\sum_t\alpha_t\cos(A_t(x))$로 바뀐다 (스캔본의 인쇄된 식은 계수 $\tfrac12$와 부호가 흐릿하니 위 공식으로 확인). 그다음 Lemma A.4로 각 $\cos$를 $\Psi$로 근사 → **정리 2.4** 완성.
→ 🔎 *trigonometric identity* 에 밑줄. 이 논문 증명의 진짜 열쇠.

**⑥ 정리 2.5 증명 (보간)** — 1차원: 점을 정렬, $k$번째 뉴런이 $x_{k-1}$과 $x_k$ 사이에서 0→1로 바뀌게 하고 높이 $g(x_k)-g(x_{k-1})$. 고차원: 모든 점이 다른 값을 갖는 방향 $p$로 **투영**해 1차원 문제로.
